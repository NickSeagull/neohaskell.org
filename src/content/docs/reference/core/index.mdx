## Page plan

This page will organize the Core types and operations that application builders encounter most often. Each documented entry will have a signature, its input and output, a minimal verified example, relevant edge cases, and a link to the canonical definition. Compact tables will help compare related operations; source/output pairs will make behavior explicit. The page will link to [Language essentials](/reference/language/) for syntax and remain an overview until real content justifies separate reference pages, avoiding empty per-function stubs.
