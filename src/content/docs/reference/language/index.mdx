## Page plan

This page will provide the minimum syntax needed while following [Implement the feature](/tutorial/first-feature/), without requiring a Haskell course. It will cover modules, values, functions, types, pattern matching, pipelines, and do blocks through small verified examples with adjacent results. Local bindings will use let statements inside do blocks. Diagnostic examples will explain a common mistake and its correction. Stable section links will let other guides point directly to the needed construct, with [Core library](/reference/core/) covering available operations.
