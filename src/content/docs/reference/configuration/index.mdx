This page will list verified configuration fields, defaults, required values, and environment overrides for the documented framework version. A consistent table and small complete configurations will show how values fit together; invalid examples will include the actual diagnostic and its correction when verified. Entries will link to the relevant task guide rather than repeat its full procedure.
