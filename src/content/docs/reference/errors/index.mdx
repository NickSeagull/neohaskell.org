## Page plan

This page will organize common setup, build, runtime, and agent-workflow failures by the symptom a reader can observe. Each entry will show the original diagnostic, its location, the likely cause, a minimal correction, and a check that confirms recovery. Small before-and-after source or command examples will stay beside the explanation. The page will link to [Neo CLI](/reference/cli/), [Configuration](/reference/configuration/), and [Resources](/resources/) when a problem needs command details, upstream guidance, or community help.
