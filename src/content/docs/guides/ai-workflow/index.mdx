## Page plan

This page will describe a repeatable collaboration process after [setup](/getting-started/): provide the model and project context, request one change, inspect the result, and correct mismatches. It will include copyable task and correction prompts, a focused diff, and examples of useful verification evidence. A short comparison will distinguish a passing technical check from correct application behavior. The [first-feature tutorial](/tutorial/first-feature/) will supply the worked example; this guide will focus on reuse and recovery rather than repeating installation.
