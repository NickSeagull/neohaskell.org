## Page plan

This page will expose an existing feature through the Web transport and inspect its generated routes and OpenAPI contract. A command request, rejected input, and query response will connect the application definition to observable HTTP behavior. Filtering and pagination will follow the [query contract](/reference/framework/queries/). The examples will include transport registration and browser-origin configuration, then link to authentication before opening the interface to untrusted callers.
