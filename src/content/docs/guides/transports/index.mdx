## Page plan

This page will explain how application behavior is exposed through HTTP and MCP, including the configuration and contracts verified for the documented framework version. It will show a command and query through request/response pairs and equivalent tool calls, with an example of inspecting generated OpenAPI. A small boundary diagram will separate transports from decisions. Static examples will include both success and rejection; a live request widget will only be considered once a supported isolated runtime is available.
