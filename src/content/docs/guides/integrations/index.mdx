## Page plan

This page will show how to connect a supported external service while keeping network effects and credentials outside pure decision logic. A source-backed example will cover the provider connection, the application's requested effect, and success or failure handling. A sequence figure will show which component performs each action; paired traces will explain a successful call and an unavailable provider. The guide will link to [Pure decisions and effects](/concepts/pure-decisions/) for the boundary and [Configuration](/reference/configuration/) for required values.
