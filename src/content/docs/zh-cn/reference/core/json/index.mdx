## 页面计划

本页将介绍 `Json` 编码与解码、`FromJSON` 和 `ToJSON` 实例、以 `Result` 表示的格式错误，以及用于描述 API 数据的独立 `Schema` 契约。一个小型记录将配上对应的 JSON 结构和一个无效输入。本页将区分序列化、验证和生成的 API 描述，并用锚点表整理解析器辅助函数；命令载荷的详细信息将链接到传输参考。
