## 页面计划

本页将介绍 `Json` 编码和解码、`FromJSON` 和 `ToJSON` 实例、用 `Result` 表示格式错误的输入，以及用于描述 API 数据的独立 `Schema` 契约。一个小型记录会配上对应的 JSON 形状和一条无效输入。页面会区分序列化、验证和生成的 API 描述，并通过带锚点的表格收录解析器辅助函数，同时将命令载荷细节链接到传输接口参考。
