## 页面计划

本页将介绍 `Task error value`、成功构造、带类型的失败、链式调用、`do` 记法、恢复以及转换为 `Result`。一个简短流程将展示哪些步骤会运行，以及失败后会发生什么；签名表将区分任务的构造与程序边界处的执行。清理和取消将作为高级内容链接；同时明确交叉链接 `Decision`，说明它是用于业务接受和拒绝的独立契约。
