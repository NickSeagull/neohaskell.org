## 页面计划

本页将对比 `Nothing` 和 `Just` 与 `Err` 和 `Ok`，说明何时缺失值不需要解释，何时需要带类型的错误。简明签名和配对案例会介绍 `map`、`andThen`、`withDefault`、`mapError`，以及两种容器之间的转换。解析或查找示例会保留错误，直到调用者主动处理，并链接到 `Task` 中有副作用的失败处理方式。
