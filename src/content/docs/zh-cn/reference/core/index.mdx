## 页面规划

本页将整理应用构建者最常用到的 Core 类型和操作。每个条目都会给出签名、输入和输出、经过验证的最简示例、相关边界情况，以及指向权威定义的链接。简洁的表格将帮助读者比较相关操作；源代码和输出示例将明确展示行为。本页将链接到[语言基础](/reference/language/)介绍语法。在实际内容足以支持独立参考页面之前，本页会保持为概览，避免出现空的逐函数占位页面。
