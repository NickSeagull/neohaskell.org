## 页面计划 <a id="page-plan" />

本页将说明命令记录、`EntityOf`、`getEntityId`、`decide`、`RequestContext`、传输接口权限和派生辅助函数，并将手写函数映射到公开的 `Command` 方法。简明结果表会对比 `acceptNew`、`acceptExisting`、`acceptAny`、`acceptAfter` 和 `reject`。`Counter` 决策案例会为接受和拒绝行为提供具体示例。多租户签名和授权钩子会设有锚点；较长的实现和访问策略说明则由任务指南负责。
