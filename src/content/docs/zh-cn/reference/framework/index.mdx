## 页面计划

本页将把 `EventModel`、`FeatureAction`、`chapter`、`slice`、`entity`、`command`、`produces`、`query` 和 `readsFrom` 映射到源码中的 `Counter` 功能。精简关系图将展示声明、验证和运行时组装，同时避免混淆事件历史与 `query` 行。构建器签名和顺序约束将与模型并列说明。直接组装 `Service.Application` 将作为高级内容链接；本页会保留其公开 API 状态，同时优先介绍当前起始项目的架构。
