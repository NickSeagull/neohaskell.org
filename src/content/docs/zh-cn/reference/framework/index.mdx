## 页面规划

本页将介绍实体、命令、决策、事件、查询和应用组合对应的框架定义，并确保这些定义经过验证。每个条目都会说明其职责、相关类型、必需字段，以及能展示其作用的最小完整源代码示例。一张精简的关系图将展示各部分如何连接，同时将事件记录与查询结果区分开来。条目将链接到[核心概念](/learn/)了解相关说明，并链接到[第一个功能教程](/tutorial/first-feature/)了解如何在一个应用中使用它们。
