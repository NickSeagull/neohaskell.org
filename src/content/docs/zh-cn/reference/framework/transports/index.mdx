## 页面计划

本页将对比 Web、应用 CLI 和 MCP 的注册方式，说明命令必须允许相应传输接口，模型也必须安装该命令。页面会记录路由命名、命令响应、查询处理器输入和模式注册，并给出一种请求与响应形状。高级章节将以锚点形式介绍公开的 Transport 接口。应用 CLI 会与 neo 开发命令参考明确区分。
