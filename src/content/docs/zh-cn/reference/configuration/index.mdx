## 页面计划

本页将定义 `Config` 字段、必需文档、默认值、必需值、环境变量名称、命令标志、嵌套记录和机密信息脱敏。一个优先级表将按命令行、进程环境、dotenv、默认值的顺序展示配置，并配以简单的假设端口示例。本页将说明启动时的加载、配置工厂、注册顺序和不同的存储选项，并将提供方专属设置链接到任务指南；`neo.json` 构建配置则单独放在其页面中。
