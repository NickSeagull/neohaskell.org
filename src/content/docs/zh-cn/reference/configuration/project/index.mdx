## 页面计划

本页将介绍 `neo.json` 中的 name、version、neo-version、project type、metadata、默认 license 和 dependency 条目，并将这些内容与运行时环境设置区分开。完整的小型清单和字段表将说明生成的 Cabal 与 Nix 文件由谁管理，并链接到受支持的依赖项格式。源码选择部分将把本地框架覆盖设置标记为高级开发选项；版本兼容性也会明确说明，不会把 main 等同于某个已发布版本。
