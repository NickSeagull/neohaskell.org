## 页面计划

本页将介绍 `neo.json` 中的名称、版本、neo-version、项目类型、元数据、默认许可证和依赖项，并与运行时环境设置区分开。完整的小型清单和字段表会说明生成的 Cabal 与 Nix 文件由什么管理，并链接到受支持的依赖形式。源码选择部分会将本地框架覆盖项说明为高级开发设置，并明确说明发行版兼容性，不会把 main 分支等同于已发布版本。
