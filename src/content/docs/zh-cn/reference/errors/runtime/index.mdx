## 页面计划

本页将区分启动配置故障、绑定设置无效、监听端口被占用、命令拒绝、授权拒绝和执行失败。简明症状表会将每类问题与相关配置或公开响应类型及一项恢复检查关联。页面会说明，被拒绝的命令是有效的业务结果，不应自动视为服务器缺陷；存储或提供方故障则会链接到相应的维护指南。
