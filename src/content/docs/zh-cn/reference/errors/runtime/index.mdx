## 页面计划

本页将区分启动配置故障、绑定设置无效、监听端口被占用、命令被拒绝、授权被拒绝和执行失败。精简的问题表现表将每种类别对应到相关配置或公开响应类型，并提供一项恢复检查。本页将说明，被拒绝的命令是有效的业务结果，不会自动构成服务器缺陷；存储或提供方故障则链接到维护中的任务指南。
