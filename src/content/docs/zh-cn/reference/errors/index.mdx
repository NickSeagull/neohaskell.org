## 页面计划 <a id="page-plan" />

本页将汇总可观察到的故障，例如缺少工作区、`neo.json` 无效、缺少前置工具、依赖项无效、框架指南不可用或子进程失败。每个条目都会将诊断代码和位置与最小修正及恢复检查配对。带注释的诊断示例会解释源码范围和保留的子进程输出。源码中定义的消息将与实际执行记录区分开，并链接到 CLI 选项和社区问题反馈渠道，供需要更多证据的修正参考。
