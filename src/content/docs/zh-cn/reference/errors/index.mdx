## 页面计划

本页将索引可观察到的故障，例如缺少工作区、`neo.json` 无效、缺少先决工具、依赖项无效、框架指南不可用，以及子进程失败。每项都将把诊断代码和位置与最小修正措施及恢复检查配对。一个带注释的诊断示例将说明源码范围和保留的子进程输出。由源码定义的消息将与实际运行记录区分开，并链接到 CLI 选项和社区反馈渠道，以便在证据不足时继续排查。
