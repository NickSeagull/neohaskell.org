## 页面计划

本页将列出 `neo ide` 的主机和端口设置、`inspect` 筛选条件、`inspect sync`，以及 `validate` 的路径和 JSON 选项。精简表格将区分只读检查、源码到模型的同步，以及 IDE 编辑。本页将记录验证退出代码，并展示未来捕获结果的结构，同时将模型编写任务链接到其他页面。`Command` 契约将以文档所述修订版为准，不假设较旧的二进制文件也包含这些契约。
