## 页面计划

本页将列出 `neo ide` 的主机和端口设置、`inspect` 筛选条件、`inspect sync`，以及 `validate` 的路径和 JSON 选项。简明表格会区分只读检查、从源码同步到模型，以及在 IDE 中编辑。页面会记录验证的退出码，并展示未来捕获结果的结构，同时将模型编写任务链接到其他页面。`Command` 契约将对应文档所述版本，不会假定较旧的二进制文件也支持它。
