## 页面规划

本页将根据指定版本记录 Neo CLI 的用法，包括项目创建、构建、运行和测试命令。每条说明都会说明运行位置、必需参数、选项、预期输出或退出结果，以及具体的恢复步骤。可复制的命令将配有经过验证的结果；只有平台之间确有差异时才会提供替代方式。[设置你的智能体](/getting-started/)将负责介绍完整的首次运行流程；本页则便于后续快速查阅。
