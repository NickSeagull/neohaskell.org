## 页面计划

本页将通过 Web 传输开放现有功能，并检查生成的路由和 OpenAPI 契约。命令请求、被拒绝的输入和查询响应将把应用定义与可观察到的 HTTP 行为关联起来。筛选和分页内容将链接到[查询契约](/reference/framework/queries/)。示例将包含传输注册和浏览器来源配置，然后链接到身份验证指南，再开放接口以供不受信任的调用者使用。
