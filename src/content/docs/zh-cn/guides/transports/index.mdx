## 页面规划

本页将说明如何通过 HTTP 和 MCP 公开应用行为，包括针对文档所述框架版本验证过的配置和契约。页面将通过请求/响应示例和等效的工具调用展示命令和查询，并提供检查生成的 OpenAPI 的示例。一张简短的边界图将传输方式与决策区分开来。静态示例将同时涵盖成功和拒绝的情况；只有在有受支持的隔离运行时后，才会考虑加入实时请求控件。
