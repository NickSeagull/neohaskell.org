## 页面计划

本页将把已接受的事件连接到带类型的出站处理器，执行 HTTP 调用，并将提供方响应转化为后续命令。成功和失败的跟踪示例会展示纯决策与外部副作用之间的边界。示例将使用幂等键，并说明 HTTP 与分发器的重试设置彼此独立，但不会承诺持久投递或恰好执行一次。
