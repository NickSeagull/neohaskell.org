## 页面计划

本页将把已接受的事件连接到带类型的出站处理程序，执行 HTTP 调用，并将提供方响应转换为后续命令。成功和失败流程将展示纯决策与外部操作之间的边界。示例将使用幂等键，并说明 HTTP 和分发器各自的重试设置，但不会承诺持久化投递或恰好一次执行。
