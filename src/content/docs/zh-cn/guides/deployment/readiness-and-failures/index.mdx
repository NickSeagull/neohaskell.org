## 页面计划 <a id="page-plan" />

本页将对比健康检查端点与查询就绪状态，并使用请求标识符和结构化日志跟踪失败操作。简明状态图会展示查询的重建、就绪和失败状态，以及对应的 HTTP 结果。诊断示例会区分存储故障与集成不可用，并把恢复步骤与证据关联起来，而不会把进程正在运行当成所有查询均可用的证明。
