## 页面计划

本页将在获取数据前执行查询级访问检查，并对单项结果检查所有权。本页将对比所有者、另一位已验证用户和匿名调用者执行同一查询的情况，其中包括分页结果。简短的决策表将说明各项检查的执行位置，使读者能够保护返回的数据，而不会误以为命令权限会自动保护查询端点。
