## 页面计划

本页将在获取数据前应用查询级访问检查，并对单条结果进行所有权检查。页面会比较所有者、另一位已验证用户和匿名调用者执行同一查询的情况，其中包括分页结果。简短的决策表会展示每项检查的执行位置，让读者保护返回的数据，而不误以为命令权限会自动保护查询端点。
