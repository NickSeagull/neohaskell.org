[核心概念](/learn/)、[设置你的智能体](/getting-started/)和[资源](/resources/)包含现有指南。下方其他页面介绍的是尚待编写的说明、示例和图示规划。若要查阅目前已有的说明，资源页面链接到上游的语法、CLI、存储、测试和授权指南。

本页将引导读者完成一段简短的入门流程，介绍独立任务指南、更深入的概念说明和结构清晰的参考资料。页面将用带链接的阅读路线图说明每个问题适合在哪里查找。教程将围绕一个商店功能，从规格说明讲到经过测试的后端行为和可调用接口，不要求读者先学习 Haskell。文章会在能解释具体概念时配上示例和图示。
