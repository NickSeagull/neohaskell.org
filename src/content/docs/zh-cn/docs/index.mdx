[从这里开始](../introduction/)、[设置你的智能体](../getting-started/)和[资源](../resources/)下的四个页面包含现有指南。其他页面列出计划编写的说明、示例和图示。资源页面链接到目前可在上游找到的说明。

第一段学习旅程从开发者的判断和业务问题开始，说明事件为何要保留变更的含义，然后介绍命令和查询，最后将它们连接到事件模型中。接着会检查 NeoHaskell 提供的 Counter 起始项目。教程随后会在该项目中构建陶瓷马克杯商店，从第一个决策一直做到经过测试的 HTTP 接口。每个任务指南都会回答一个独立问题；概念页面会解释设计，参考页面则定义语法和 API 契约。
