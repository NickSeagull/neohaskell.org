<p class="docs-lead">运行第一个项目。构建一家马克杯商店。查找所需任务或 API。</p>

[核心概念](/learn/)、[设置你的智能体](/getting-started/)和[资源](/resources/)包含现有指南。其他页面将说明计划撰写的内容，包括解释、示例和图示。资源页面链接到目前上游已有的说明。

第一段学习流程将检查 NeoHaskell 附带的 Counter 起始项目。随后，教程将在该项目中构建一家陶瓷马克杯商店，从第一个决策开始，直至经过测试的 HTTP 接口。每篇任务指南将回答一个独立问题；概念页面将解释设计，参考页面则定义语法和 API 契约。
