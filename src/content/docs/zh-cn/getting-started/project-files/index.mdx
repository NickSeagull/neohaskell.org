## 页面计划

本页将根据读者和其智能体需要作出的决策，梳理生成的项目结构。本页将定位应用的 `Event` Model、`Counter` 功能、命令决策、事件、实体更新、查询和测试，然后区分手动编写的文件与根据 `neo.json` 重新生成的构建文件。精简的目录结构图将说明各个位置的用途。读者将了解应在哪里检查建议的变更，而无需研究每个框架模块。
