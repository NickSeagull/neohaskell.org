## 页面计划 <a id="page-plan" />

本页将把生成的项目文件映射到读者和智能体需要作出的决策。页面会定位应用的 `Event` Model、`Counter` 功能、命令决策、事件、实体更新、查询和测试，然后区分这些手写文件与根据 `neo.json` 重新生成的构建文件。简明目录图会说明各位置的用途。读者将学会在哪里检查提议的变更，而不必研究每个框架模块。
