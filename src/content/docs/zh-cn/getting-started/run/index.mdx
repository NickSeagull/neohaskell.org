## 页面计划

本页将从项目根目录构建并运行生成的 `Counter` 应用，说明本地 HTTP 地址，并解释发送请求时哪个进程必须保持运行，以及请求应从另一个终端发送。本页将区分首次下载依赖项与应用启动，展示如何停止并重启进程，并说明默认的内存事件历史会在进程结束后消失。首次成功启动后才会介绍监视模式。
