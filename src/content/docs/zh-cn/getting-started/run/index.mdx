## 页面计划

本页将从项目根目录构建并运行生成的 `Counter` 应用，指出本地 HTTP 地址，并说明在另一个终端发送请求时，哪个进程必须保持运行。页面会区分首次下载依赖项与启动应用，展示如何停止和重启进程，并说明默认的内存事件历史会在进程结束后消失。成功启动一次之后才会介绍监视模式。
