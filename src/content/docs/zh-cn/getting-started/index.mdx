<p class="docs-lead">准备好环境，并给 AI 智能体一个范围明确的小任务。</p>

如果命令、决策、事件和查询对你来说还是新概念，请先阅读[代码背后的工作](../introduction/)。本指南沿用同一个商店示例：库存充足时接受订单，商店售罄时拒绝订单。

## 准备开发环境 <a id="prepare-your-environment" />

**Neo CLI** 用于创建、构建、运行和测试应用。[前置要求和安装说明](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/README.md#prerequisites)列出了 Nix 和 Git；文档中的源码安装也会使用 Rust 的 Cargo。请先按照[项目创建和运行指南](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/project-and-cli.md#create-and-run-an-application)创建应用仓库，再安装智能体技能。

若要先检查 Counter 应用，请阅读[起始项目的要求和快速入门](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/starter/README.md#requirements)。它默认使用内存事件存储：进程结束后，已记录的事件会消失。[存储指南](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/storage.md)介绍了持久化存储选项。

这些链接对应经过检查的框架版本。请使用与你的应用固定版本相匹配的说明。智能体技能安装程序另行要求 **Node.js 22.20 或更高版本**。

继续之前，请打开应用仓库，并确保编程智能体可以在其中工作。目前的技能集合支持 **Claude Code** 和 **Codex**。

## 安装智能体技能 <a id="install-agent-skills" />

NeoHaskell 技能为编程智能体提供项目专用指南。请在应用的 Git 根目录运行此命令：

```sh title="终端" wrap
npx skills add neohaskell/skills --skill '*'
```

安装程序会询问要使用哪个智能体以及安装范围。请选择完整集合，以便相关技能和资源可以一起使用。将安装的文件和锁定文件保留在项目中。

命令和安装程序要求来自 [NeoHaskell 技能 README](https://github.com/neohaskell/skills/blob/0ff0872d554e79d955f4c92f9b905056b908e9ae/README.md)，检查日期为 2026 年 11 月 9 日。更新信息请参阅[当前安装说明](https://github.com/neohaskell/skills#readme)。

## 描述第一个任务 <a id="describe-a-first-task" />

告诉智能体你期望的行为，并说明命令无法被接受时应该发生什么。商店示例可以使用下面这项任务：

```text title="给智能体的示例任务" wrap
让顾客可以订购一只陶瓷马克杯。

仅当数量为正数且库存充足时才接受订单。

将已接受的订单记录为 OrderPlaced，并提供一个查询来获取剩余库存。

如果库存不足，就拒绝该命令，不要记录已接受订单的事件。

检查接受和拒绝这两种结果。
```

先从这一种行为开始。等你能检查第一个结果后，再分别添加付款、配送和其他条件。

## 检查结果 <a id="check-the-result" />

让智能体演示一次接受的订单和一次拒绝的订单。对于每种情况，以如下所示的库存为起点，并根据模型比较结果。

| 起始库存 | 命令 | 预期事件 | 操作后库存 |
| --- | --- | --- | --- |
| 3 只马克杯 | 订购 1 只马克杯 | `OrderPlaced` | 2 只马克杯 |
| 0 只马克杯 | 订购 1 只马克杯 | 无已接受订单事件 | 0 只马克杯 |

还要检查零或负数数量是否会被拒绝。技术检查有助于发现实现错误；行为是否符合应用预期，仍由你决定。

如果结果出乎意料，请使用相同术语向智能体说明差异：命令、决策、事件和查询。这样就能明确要修正的行为。

有关语法、测试指南、发行说明或帮助，请参阅[资源与项目状态](../resources/)。
