<p class="docs-lead">准备好开发环境，并为 AI 智能体安排一个小而明确的首要任务。</p>

如果你还不熟悉命令、决策、事件和查询，请先阅读[核心概念](/learn/)。本指南使用同一个商店示例：库存充足时接受订单，商店售罄时拒绝订单。

## 准备开发环境

**Neo CLI** 用于创建、构建、运行和测试应用。其[前置条件和安装说明](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/README.md#prerequisites)列出了 Nix 和 Git；文档中的源码安装方式还会用到 Rust 的 Cargo。请按照[项目创建和运行指南](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/project-and-cli.md#create-and-run-an-application)，在安装智能体技能之前创建应用仓库。

如果想先检查 Counter 应用，请阅读入门项目的[需求和快速入门指南](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/starter/README.md#requirements)。它默认使用内存事件存储，进程结束后，已记录的事件就会消失。[存储指南](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/storage.md)介绍了持久化存储选项。

这些链接介绍的是经过检查的框架版本。请使用与你的应用固定版本相匹配的说明。智能体技能安装程序另需 **Node.js 22.20 或更高版本**。

继续之前，请打开应用仓库，并准备好在其中工作的编程智能体。目前的技能集支持 **Claude Code** 和 **Codex**。

## 安装智能体技能

NeoHaskell 技能会为编程智能体提供针对项目的指导。请在应用的 Git 根目录中运行此命令：

```sh title="终端" wrap
npx skills add neohaskell/skills --skill '*'
```

安装程序会询问要使用的智能体和安装范围。请选择完整技能集，让相关技能和资源能够一起使用。请将安装的文件和锁文件保存在项目中。

命令和安装程序的要求来自 [NeoHaskell 技能 README](https://github.com/neohaskell/skills/blob/0ff0872d554e79d955f4c92f9b905056b908e9ae/README.md)，检查日期为 2026 年 11 月 9 日。请查看[当前安装说明](https://github.com/neohaskell/skills#readme)以获取更新。

## 描述首个任务

告诉智能体你希望实现的行为，并说明命令无法被接受时应该如何处理。商店示例可以使用以下任务：

```text title="给智能体的示例任务" wrap
允许顾客订购一只陶瓷马克杯。

仅当数量为正数且库存充足时才接受订单。

将已接受的订单记录为 OrderPlaced，并提供一个用于查询剩余库存的查询。

如果库存不足，则拒绝该命令，不记录已接受订单的事件。

检查接受和拒绝这两种结果。
```

先从这一个行为开始。确认可以检查首个结果后，再分别添加付款、配送和其他条件。

## 检查结果

请智能体演示一笔已接受的订单和一笔被拒绝的订单。每种情况都从下表所示的库存开始，并将结果与模型进行对比。

| 起始库存 | 命令 | 预期事件 | 之后的库存 |
| --- | --- | --- | --- |
| 3 只马克杯 | 订购 1 只马克杯 | `OrderPlaced` | 2 只马克杯 |
| 0 只马克杯 | 订购 1 只马克杯 | 无已接受订单的事件 | 0 只马克杯 |

还要检查数量为零或负数时是否会被拒绝。技术检查有助于发现实现错误；你仍需判断这些行为是否符合应用的预期。

如果结果出乎意料，请使用相同的术语向智能体描述差异：命令、决策、事件和查询。这样就能明确指出需要修正的行为。

如需查看语法、测试指南、发行说明或获取帮助，请访问[资源与项目状态](/resources/)。
