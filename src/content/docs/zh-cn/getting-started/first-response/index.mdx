## 页面计划

本页将通过创建一个 `Counter`、在变更命令中使用返回的实体标识符，并通过查询读取结果值，来验证正在运行的起始项目。本页将说明请求载荷、响应封装，以及投影反映变更前可能存在的延迟。被拒绝的输入将用于区分正常运行的验证响应和设置故障。维护中的 `Counter` 场景将提供一种可重复检查方式，供读者在开始商店教程前使用。
