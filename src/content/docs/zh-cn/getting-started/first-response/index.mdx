## 页面计划

本页将通过创建 `Counter`、在变更命令中使用返回的实体标识符，并通过查询读取结果值，来验证运行中的起始项目。页面会解释请求载荷、响应封装，以及投影反映变更前可能出现的延迟。遭拒绝的输入会帮助区分正常运行的验证响应与设置故障。在开始商店教程之前，维护中的 `Counter` 场景将提供可重复的检查。
