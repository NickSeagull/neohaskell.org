## 页面计划

本页将说明受支持的环境，并安装所需的 Nix 和 Git 工具以及 Neo CLI。页面会区分 CLI 安装与项目管理的编译器和库获取方式，说明可选的编辑器环境，并展示如何检查已安装的工具。说明将对应经过验证的发行版本和平台；影响首次构建的二进制缓存选项也会说明，并提供设置恢复的直接链接。
