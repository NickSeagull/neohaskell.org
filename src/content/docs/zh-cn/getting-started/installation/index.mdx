## 页面计划

本页将说明支持的环境，并使用所需的 Nix 和 Git 工具安装 Neo CLI。本页将区分 CLI 安装与项目管理的编译器和库获取方式，介绍可选的编辑器环境，并展示如何检查已安装的工具。说明将对应经过验证的版本和平台；如果二进制缓存选项会影响首次构建，也会加以说明，并提供设置故障恢复的直接链接。
