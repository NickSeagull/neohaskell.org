## 页面计划

本页将把常见的首次运行症状与失败步骤及最小修正关联起来，包括缺少工具、工作目录错误、项目名称已存在、项目配置无效、依赖项不可用或缺少智能体指南。每种情况都会展示经过验证的诊断方法和确认恢复的检查。页面会保留读者的文件，说明如何识别 CLI 和框架版本，并将更深入的编译器或运行时错误链接到参考页面。
