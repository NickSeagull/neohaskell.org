## 页面计划

本页将把常见的首次运行问题对应到失败步骤和最小修正措施：缺少工具、工作目录错误、项目名称已存在、项目配置无效、依赖项不可用，或缺少智能体指南。每种情况都会给出经过验证的诊断方法和确认恢复的检查。本页会保留读者文件，说明如何识别 CLI 和框架版本，并将更深入的编译器或运行时错误链接到参考文档。
