## 页面计划

本页将说明 `Event` Model 如何把应用行为分组成功能、章节和切片，以及为什么每个切片都有明确的职责。带注释的 `Counter` 功能树将把命令切片和查询切片关联到它们声明的事件。页面会对比组织故事与划定实体边界，并链接到介绍实现的教程和介绍 DSL 的框架参考。
