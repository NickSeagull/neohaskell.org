## 页面计划

本页将从设置后可运行的项目继续，检查生成的 `Counter` 文件，并让智能体接到范围明确的任务，为商店引入状态和事件。带注释的文件树将解释 `Entity`、`Event`、`Core` 和 `Feature`，但不会讲解所有导入。读者将明确设置期初库存，并检查已接受订单如何改变库存。发布可运行源码前，将先验证建议的商店标识符。
