## 页面计划

本页将从设置后生成的可运行项目继续，检查生成的 `Counter` 文件，并让智能体执行一项范围明确的任务：引入商店状态和事件。带注释的文件树会介绍 `Entity`、`Event`、`Core` 和 `Feature`，但不会讲解所有导入项。读者会明确设定初始库存，并检查已接受的订单会如何改变库存。发布任何可运行源码前，都会先验证拟议的商店标识。
