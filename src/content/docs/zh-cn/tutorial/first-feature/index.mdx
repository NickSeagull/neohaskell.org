## 页面规划

本页将从[设置你的智能体](/getting-started/)准备好的项目和[为第一个功能建模](/tutorial/)编写的规格说明开始。页面将展示如何把这项范围明确的任务交给智能体、检查修改过的文件，并将一种后端行为连接到可调用接口。精简的源代码片段和带注释的文件树将说明各个部分；需要了解语法时，会直接链接到[语言基础](/reference/language/)。完成后将继续阅读[测试行为](/tutorial/test-behavior/)。
