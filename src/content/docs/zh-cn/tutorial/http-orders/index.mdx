## 页面计划

本页将通过 `Feature` 注册商店命令和查询，并将该 `Feature` 组合进应用中命名的 `Event` Model。读者会发送一个已接受订单和一个遭拒绝订单，然后通过运行中的 HTTP 服务检查库存查询。精简的连接代码片段及紧邻的请求和响应示例会把源码与可观察行为联系起来。教程会使用经过验证的商店路由和载荷，并将更广泛的 HTTP 和 MCP 选项链接到任务指南。
