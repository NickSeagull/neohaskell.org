## 页面计划

本页将通过 `Feature` 注册商店命令和查询，并将该 `Feature` 组合到应用的命名 `Event` Model 中。读者将通过正在运行的 HTTP 服务发送一笔已接受订单和一笔被拒绝订单，然后检查库存查询。精简的连接源码摘录和相邻的请求与响应示例将把源码和可观察到的行为关联起来。教程将使用经过验证的商店路由和载荷；更广泛的 HTTP 与 MCP 选择将链接到对应任务指南。
