## 页面计划

本页将把商店的原始表格转化为可重复检查，涵盖已接受订单、售罄时的拒绝、商店状态缺失，以及随后的库存查询。读者将区分决策测试、事件重放检查和 HTTP 场景，然后检查一个有意制造的失败及其修复方式。预期结果和实际结果将并列展示。智能体提供的证据必须包含实际运行的检查，并考虑查询更新可能延迟，而不能假设结果会立即一致。
