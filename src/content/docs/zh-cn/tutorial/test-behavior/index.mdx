## 页面计划

本页将把原始商店表格转换为可重复的检查，涵盖已接受的订单、售罄时的拒绝、商店状态缺失，以及相应的库存查询。读者会区分决策测试、事件重放检查和 HTTP 场景，然后检查一次有意触发的失败及其修复。预期结果和实际结果会一同展示。智能体提供的证据必须列出实际运行的检查，并考虑查询更新延迟，而不是假定数据立即一致。
