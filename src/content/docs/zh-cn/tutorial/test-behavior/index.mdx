## 页面规划

本页将根据最初的规格说明，验证[实现功能](/tutorial/first-feature/)中的功能。内容将展示被接受和被拒绝的订单、无效数量、已记录事件，以及由此得到的库存查询结果。输入、预期结果和实际观察到的结果将放在同一张对比表中，并配上简短的测试片段和故障说明。读者将了解继续阅读[安全地修改功能](/tutorial/change-safely/)之前，应要求智能体提供哪些证据。
