## Page plan

This page will explain what a decision receives, what it returns, and why external effects belong outside that calculation. It will compare the same input evaluated twice, an accepted command, and a rejected command, using minimal verified source and explicit results. A boundary figure will separate pure logic from network, storage, and file operations. The explanation will connect type checks to the mistakes they can catch while keeping business intent the reader's responsibility, then link to [Connect external services](/guides/integrations/).
