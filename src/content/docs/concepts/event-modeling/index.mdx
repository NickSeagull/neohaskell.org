## Page plan

This page will explain how to choose useful commands, decisions, events, and queries when a domain story has several steps or competing interpretations. It will compare alternative boundaries and make the assumptions behind each model explicit. A small sequence of static figures will show how the model changes as the requirements become clearer. [Core concepts](/learn/) will own the definitions, and [Model your first feature](/tutorial/) will supply the concrete shop specification; this explanation will focus on the reasoning behind those choices.
