## Page plan

This page will explain why a recorded event and a current query result are different things. It will align a short event history with the state derived from it, then show how another accepted command changes the answer without rewriting earlier facts. A labeled ledger and state table will carry the explanation. An optional future comparison control may reveal successive states, with every result also available as static text. Configuration and restart procedures will remain in [Keep data across restarts](/guides/storage/).
