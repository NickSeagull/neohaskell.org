NeoHaskell is an AI-first programming language under active development. Start with a small behavior you can describe and check. The Counter starter gives you a concrete application to inspect before extending it with your agent.

## Before relying on an application <a id="before-relying-on-an-application" />

The starter uses an in-memory event store by default. Its recorded events disappear when that process ends. Persistent event history and persistent query storage are separate configuration choices; follow the storage guide above when you need data to survive a restart.

Your application also owns its access rules. Read the [authorization guidance](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/authorization.md) and test the allowed and rejected cases. An AI agent helps implement these rules; it does not decide your application's policies at runtime.

Published source and releases let you inspect what is available. They do not by themselves establish production readiness for your application.

The [framework source license](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/LICENSE) is available alongside the code. Check each tool's own license when choosing dependencies.
