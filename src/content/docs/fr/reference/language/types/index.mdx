## Plan de page <a id="page-plan" />

Cette page couvrira les paramètres de type, les enregistrements, les constructeurs, les types somme, les alias de type, les contraintes de classes, les types associés, l’application de type visible et la notation de dérivation tels qu’ils apparaissent dans le code d’application. Un enregistrement de commande annoté et une somme d’événements relieront les noms des sources aux valeurs possibles. La page distinguera les définitions écrites à la main des fonctions dérivées, avec des liens vers les contrats du framework, sans enseigner la métaprogrammation ni reproduire un manuel du langage Haskell.
