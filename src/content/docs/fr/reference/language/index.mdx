## Plan de page

Cette page présentera la syntaxe minimale nécessaire pour suivre [Implémenter la fonctionnalité](/tutorial/first-feature/), sans exiger de cours de Haskell. Elle couvrira les modules, les valeurs, les fonctions, les types, la correspondance de motifs, les pipelines et les blocs do avec de petits exemples vérifiés accompagnés de leurs résultats. Les liaisons locales utiliseront des instructions let à l’intérieur des blocs do. Les exemples de diagnostics expliqueront une erreur courante et sa correction. Des liens stables vers les sections permettront aux autres guides de renvoyer directement au concept voulu. [Bibliothèque Core](/reference/core/) présentera les opérations disponibles.
