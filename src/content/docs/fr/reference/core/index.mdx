## Plan de page <a id="page-plan" />

Cette page servira de point d’entrée vers `Core` et de référence rapide pour les types scalaires : `Text`, les types numériques, `Bool`, `Unit`, `Uuid`, ainsi que la différence entre un type réexporté et les opérations de modules qualifiés. Un tableau concis reliera les types aux modules des conteneurs, des résultats optionnels, des tâches et du JSON. Des signatures choisies illustreront la conversion de texte et les conventions arithmétiques ; les modules avancés de concurrence et d’implémentation resteront accessibles dans les sources sans encombrer la barre latérale.
