## Plan de page

Cette page organisera les types et opérations de Core que les personnes qui créent des applications rencontrent le plus souvent. Chaque entrée documentée présentera une signature, ses entrées et sorties, un exemple minimal vérifié, les cas limites pertinents et un lien vers la définition de référence. Des tableaux compacts faciliteront la comparaison entre les opérations associées. Des paires de code source et de résultats rendront le comportement explicite. La page renverra vers [Les bases du langage](/reference/language/) pour la syntaxe et restera une vue d’ensemble jusqu’à ce que le contenu justifie de créer des pages de référence distinctes. Elle évitera ainsi les pages vides consacrées à chaque fonction.
