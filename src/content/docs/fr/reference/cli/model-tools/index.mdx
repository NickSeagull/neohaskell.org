## Plan de page <a id="page-plan" />

Cette page répertoriera les paramètres d’hôte et de port de `neo ide`, les filtres d’`inspect`, `inspect sync` ainsi que les options de chemin et JSON de `validate`. Un tableau compact distinguera l’inspection en lecture seule de la synchronisation des sources vers le modèle et des modifications dans l’IDE. Il indiquera les codes de sortie de validation et la structure d’un résultat qui sera capturé ultérieurement, avec des liens vers les tâches de création du modèle. Les contrats `Command` correspondront à la révision documentée et ne seront pas supposés présents dans les anciens binaires.
