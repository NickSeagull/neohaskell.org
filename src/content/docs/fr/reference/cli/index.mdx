## Plan de page

Cette page documentera `neo new`, `build`, `run`, `test` et `lock`, avec leur invocation, le répertoire de travail, les entrées, les indicateurs et les résultats définis par les sources dans un tableau compact des commandes. Les options globales verbeuse et CI, le mode surveillance, la création de bibliothèques et le contrôle de `build` sur `lock` disposeront d’ancres. La page renverra les outils de modélisation et les commandes de configuration des agents à leurs pages dédiées, tandis que l’installation et le premier lancement complet resteront dans le guide de démarrage.
