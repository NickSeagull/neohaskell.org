## Plan de page

Cette page documentera la Neo CLI pour une révision identifiée, notamment les commandes de création, de construction, d’exécution et de test d’un projet. Chaque entrée indiquera où exécuter la commande, les arguments requis, les options, le résultat ou code de sortie attendu et une méthode concrète de résolution. Les commandes copiables seront accompagnées de résultats vérifiés et d’alternatives par plateforme uniquement lorsque celles-ci diffèrent. [Configurer votre agent](/getting-started/) présentera toutes les étapes du premier démarrage. Cette page permettra de retrouver rapidement les informations nécessaires aux travaux suivants.
