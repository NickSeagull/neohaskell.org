## Plan de page <a id="page-plan" />

Cette page séparera les échecs de configuration au démarrage, les paramètres d’écoute invalides, les ports occupés, le rejet d’une commande, le refus d’autorisation et l’échec d’exécution. Un tableau compact des symptômes reliera chaque catégorie à la configuration responsable ou au type de réponse publique, ainsi qu’à un contrôle de reprise. Il montrera pourquoi une commande rejetée est un résultat métier valide et pas automatiquement un défaut du serveur, et renverra les problèmes de magasin ou de fournisseur aux guides de tâches maintenus.
