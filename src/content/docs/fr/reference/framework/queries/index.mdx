## Plan de page <a id="page-plan" />

Cette page définira `Query`, `QueryOf`, `EntitiesOf`, `queryId`, `combine` et les résultats `Update`, `Delete` et `NoOp`. Un petit exemple reliant une entité à une requête distinguera l’identité d’une ligne de celle d’un flux d’événements. Des sections avec ancres couvriront le filtrage `NeoQL`, les entrées de pagination et les champs de réponse, les limites de résultats, le contrôle d’accès avant récupération et la visibilité de chaque ligne. La requête `Counter` servira d’exemple concret, avec des liens vers les tâches portant sur les requêtes HTTP, le stockage et l’autorisation plutôt que de reprendre toutes leurs procédures.
