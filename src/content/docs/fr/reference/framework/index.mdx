## Plan de page

Cette page reliera les entités, commandes, décisions, événements, requêtes et la composition de l’application aux définitions vérifiées du framework. Chaque entrée indiquera sa responsabilité, les types associés, les champs requis et le plus petit exemple complet de code source illustrant son rôle. Une figure compacte présentera les relations entre les composants tout en distinguant les événements enregistrés des résultats des requêtes. Les entrées renverront vers [Concepts fondamentaux](/learn/) pour les explications et vers le [tutoriel sur la première fonctionnalité](/tutorial/first-feature/) pour voir leur utilisation dans une application.
