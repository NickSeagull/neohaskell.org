## Plan de page

Cette page définira les champs de `Config`, la documentation requise, les valeurs par défaut, les valeurs obligatoires, les noms de variables d’environnement, les indicateurs de commande, les enregistrements imbriqués et la protection des secrets. Un tableau de priorité unique indiquera l’ordre suivant : ligne de commande, environnement du processus, dotenv, puis valeur par défaut, avec un petit exemple hypothétique de port. La page expliquera le chargement au démarrage, les fabriques de configuration, l’ordre d’enregistrement et les choix distincts de magasin. Les paramètres propres aux fournisseurs renverront aux guides de tâches ; la configuration de compilation `neo.json` aura sa propre page.
