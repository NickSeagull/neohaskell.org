## Plan de page

Cette page répertoriera les champs de configuration vérifiés, les valeurs par défaut, les valeurs requises et les substitutions d’environnement pour la version documentée du framework. Elle couvrira les transports, le stockage des événements et des requêtes, les connexions aux fournisseurs et les secrets, sans afficher de vrais identifiants. Un tableau uniforme et de petits exemples de configuration complets montreront comment les valeurs s’articulent. Lorsque les exemples invalides auront été vérifiés, ils incluront le diagnostic réel et sa correction. Les entrées renverront vers le guide pratique pertinent au lieu d’en répéter toute la procédure.
