## Plan de page

Cette page décrira les champs name, version, neo-version, le type de projet, les métadonnées, la licence par défaut et les dépendances de `neo.json`, en les distinguant des paramètres d’environnement à l’exécution. Un manifeste complet compact et un tableau des champs expliqueront la gestion des fichiers Cabal et Nix générés, avec des liens vers les formes de dépendances prises en charge. Une section sur la sélection des sources identifiera le remplacement local du framework comme paramètre de développement avancé ; la compatibilité des versions restera explicite et ne confondra pas main avec une version publiée.
