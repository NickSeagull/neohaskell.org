## Plan de page <a id="page-plan" />

Cette page reliera les symptômes courants d’un premier lancement à l’étape en échec et à sa correction la plus simple : outils manquants, mauvais répertoire de travail, nom de projet déjà utilisé, configuration de projet invalide, dépendances indisponibles ou conseils pour agents manquants. Chaque cas présentera un diagnostic vérifié et le contrôle confirmant la résolution. La page préservera les fichiers du lecteur, expliquera comment identifier les versions de sa CLI et de son framework et renverra les erreurs approfondies du compilateur ou de l’exécution à la référence.
