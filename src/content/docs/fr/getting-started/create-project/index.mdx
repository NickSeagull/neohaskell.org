## Plan de page

Cette page créera une application nommée avec la CLI Neo, expliquera où lancer la commande et présentera le projet de départ `Counter` créé dans le nouveau répertoire. Elle montrera le parcours interactif habituel et une commande reproductible pour un agent, expliquera le commit Git initial et la version du framework figée, puis vérifiera le projet généré avant de poursuivre. La création de bibliothèques et l’ensemble des options de la CLI resteront des sujets de référence.
