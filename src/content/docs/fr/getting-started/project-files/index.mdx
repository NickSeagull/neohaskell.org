## Plan de page

Cette page reliera le projet généré aux décisions que le lecteur et son agent doivent prendre. Elle localisera le modèle `Event` de l’application, la fonctionnalité `Counter`, les décisions des commandes, les événements, les mises à jour des entités, les requêtes et les tests. Elle distinguera ensuite ces fichiers rédigés par l’utilisateur des fichiers de compilation régénérés à partir de `neo.json`. Une carte compacte des répertoires reliera chaque emplacement à son rôle. Les lecteurs apprendront où examiner une modification proposée sans étudier chaque module du framework.
