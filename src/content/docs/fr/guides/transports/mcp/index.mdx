## Plan de page <a id="page-plan" />

Cette page enregistrera le transport MCP stdio pour une fonctionnalité existante et montrera l’initialisation, la découverte des outils, l’appel d’une commande et la lecture d’une ressource de requête. Une courte transcription du protocole distinguera les commandes, exposées comme outils, des requêtes, exposées comme ressources. L’exemple expliquera la gestion du processus et le contexte d’exécution de confiance afin que les lecteurs ne confondent pas ce protocole local avec un service HTTP distant authentifié.
