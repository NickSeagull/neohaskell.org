## Plan de page

Cette page protégera une commande à l’aide d’une règle d’accès déclarée et d’une décision qui vérifie la propriété de l’entité concernée. Un tableau comparera les appelants anonymes, les propriétaires authentifiés, les autres utilisateurs et un appel local de confiance. Les tests associés vérifieront que les commandes refusées n’atteignent pas la décision et n’ajoutent pas d’événements. Ils montreront aussi pourquoi l’authentification doit être activée pour que la vérification des règles HTTP s’applique.
