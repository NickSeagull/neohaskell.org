Les quatre pages sous [Pour commencer](../introduction/), [Configurer votre agent](../getting-started/) et [Ressources](../resources/) contiennent des conseils existants. Les autres destinations présentent des plans de page qui décrivent les explications, exemples et figures à rédiger. La page Ressources renvoie aux instructions actuellement disponibles en amont.

Le premier parcours commence par le jugement du développeur et les questions métier, explique pourquoi les événements préservent le sens d’une modification, puis présente les commandes et les requêtes avant de les relier dans un modèle d’événements. Il vérifiera ensuite le projet de départ Counter fourni avec NeoHaskell. Le tutoriel construira ensuite une boutique de tasses en céramique dans ce projet, de sa première décision à une interface HTTP testée. Chaque guide de tâche répondra à une question indépendante ; les pages de concepts expliqueront la conception et les pages de référence définiront la syntaxe et les contrats d’API.
