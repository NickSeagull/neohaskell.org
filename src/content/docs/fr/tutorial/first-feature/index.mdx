## Plan de page <a id="page-plan" />

Cette page poursuivra le projet fonctionnel créé lors de la configuration, examinera les fichiers `Counter` générés et confiera à un agent la tâche délimitée d’introduire l’état et les événements de la boutique. Une arborescence annotée expliquera `Entity`, `Event`, `Core` et `Feature` sans détailler chaque import. Les lecteurs définiront explicitement le stock initial et examineront comment une commande acceptée le modifie. Les identifiants proposés pour la boutique seront vérifiés avant la publication de code exécutable.
