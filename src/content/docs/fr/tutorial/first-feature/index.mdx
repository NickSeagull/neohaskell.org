## Plan de page

Cette page partira du projet fonctionnel obtenu en [configurant votre agent](/getting-started/) et de la spécification de [Modéliser votre première fonctionnalité](/tutorial/). Elle montrera comment confier cette tâche bien délimitée à un agent, examiner les fichiers modifiés et relier un comportement backend à une interface appelable. Des extraits ciblés de code source et une arborescence de fichiers annotée expliqueront chaque élément. Lorsque la syntaxe sera nécessaire, ils renverront directement vers [Les bases du langage](/reference/language/). Le résultat mènera à [Tester le comportement](/tutorial/test-behavior/).
