## Plan de page

Cette page ajoutera une exigence à la fonctionnalité de boutique testée et suivra ses effets sur le modèle, le code source et les vérifications. Elle montrera comment confier à un agent une modification bien délimitée, examiner un diff ciblé et relancer les tests du nouveau comportement et des comportements existants. Des exemples avant et après rendront visibles les modifications involontaires. Le chapitre se terminera par une modification du backend relue et renverra vers [Travailler avec un agent IA](/guides/ai-workflow/) pour retrouver le processus réutilisable de vérification et de résolution des problèmes.
