NeoHaskell est un langage de programmation pensé pour l'IA dès sa conception, en cours de développement. Commencez par un petit comportement que vous pouvez décrire et vérifier. Le starter Counter vous permet d'examiner une application concrète avant de la faire évoluer avec votre agent.

## Commencez à créer

Découvrez les [concepts fondamentaux](/learn/) avant de [configurer votre agent](/getting-started/). Vous pouvez lire les concepts sans rien installer.

- [Prérequis et installation de la CLI](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/README.md#prerequisites) : les outils nécessaires pour créer et exécuter une application.
- [Créer et exécuter un projet](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/project-and-cli.md) : les étapes de création, de compilation et d'exécution d'un projet.
- [Guide de démarrage rapide du starter Counter](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/starter/README.md#quickstart) : l'application présentée dans l'extrait de code de la page d'accueil, avec un parcours HTTP et des instructions de test.

## Langage et framework

Les ressources suivantes sont publiées dans le dépôt NeoHaskell à l'intention des créateurs d'applications et des agents de programmation. Elles décrivent une version précise des sources. Utilisez la version correspondante si votre projet en utilise une autre.

- [Syntaxe et Core](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/syntax-and-core.md) : un module complet, les types, les opérateurs et les conventions des applications.
- [Conseils pour les applications selon la tâche](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/index.md) : commandes, événements, requêtes, configuration, transports et intégrations.
- [Tests](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/testing.md) : tests des décisions, scénarios HTTP et vérification des modifications.
- [Stockage](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/storage.md) : historique des événements, stockage des requêtes et persistance.

## Avant de vous fier à une application

Par défaut, le starter utilise un stockage d'événements en mémoire. Les événements enregistrés disparaissent à la fin du processus. L'historique persistant des événements et le stockage persistant des requêtes sont des options de configuration distinctes. Consultez le guide sur le stockage ci-dessus si vos données doivent survivre à un redémarrage.

Votre application définit aussi ses propres règles d'accès. Lisez les [conseils sur l'autorisation](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/authorization.md) et testez les cas autorisés et rejetés. Un agent d'IA vous aide à implémenter ces règles, mais ne décide pas des politiques de votre application à l'exécution.

Les sources publiées et les versions vous permettent d'examiner ce qui est disponible. À elles seules, elles ne garantissent pas que votre application est prête pour la production.

La [licence du code source du framework](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/LICENSE) est disponible avec le code. Vérifiez la licence de chaque outil lorsque vous choisissez vos dépendances.

## Suivez les changements et obtenez de l'aide

- [Historique des versions de la CLI et du framework](https://github.com/neohaskell/NeoHaskell/releases) : changements apportés aux outils d'application et au framework. La [version 0.17.1](https://github.com/neohaskell/NeoHaskell/releases/tag/neo-v0.17.1), publiée le 6 novembre 2026, ajoute le stockage de fichiers appartenant à l'application pour les documents générés.
- [Versions des compétences pour agents](https://github.com/neohaskell/skills/releases) : changements apportés à la collection distincte d'instructions pour Claude Code et Codex.
- [Posez vos questions à la communauté sur Discord](https://discord.com/invite/wDj3UYzec8) : expliquez ce que vous essayez de créer et où vous êtes bloqué.
- [Consultez les problèmes signalés](https://github.com/neohaskell/NeoHaskell/issues) ou [lisez le guide de contribution](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/CONTRIBUTING.md) : suivez les problèmes connus et découvrez le processus de contribution au projet.
