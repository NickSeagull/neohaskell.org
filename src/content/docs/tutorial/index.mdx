## Page plan

This page will turn the ideas from [Core concepts](/learn/) into a concrete specification for ordering a ceramic mug. It will define the starting stock, command, acceptance conditions, recorded event, and query result, including a rejected order. A small behavior table and a static model will show what must be checked. The completed specification will lead into [Implement the feature](/tutorial/first-feature/); broader modeling choices belong in [Model application behavior](/concepts/event-modeling/).
