## ページ案 <a id="page-plan" />

このページでは、サポート対象の環境を示し、必要なNixおよびGitのツールとともにNeo CLIをインストールします。CLIのインストールと、プロジェクト管理下のコンパイラーおよびライブラリの取得を区別します。任意のエディター環境と、インストール済みツールの確認方法も説明します。手順は検証済みのリリースとプラットフォームに基づき、初回ビルドに影響するバイナリーキャッシュの選択肢を説明して、セットアップ復旧への直接リンクを用意します。
