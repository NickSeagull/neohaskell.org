## ページ案

このページでは、生成されたプロジェクトを、読者とエージェントが判断するために必要な情報と対応づけます。アプリケーションの`Event` Model、`Counter`フィーチャー、コマンドの判断、イベント、エンティティの更新、クエリ、テストの場所を示し、手書きのファイルと`neo.json`から再生成されるビルドファイルを区別します。簡潔なディレクトリ図で、各場所の目的を説明します。フレームワークのすべてのモジュールを調べなくても、変更案を確認できるようにします。
