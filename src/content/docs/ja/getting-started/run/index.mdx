## ページ案 <a id="page-plan" />

このページでは、プロジェクトルートから生成された`Counter`アプリケーションをビルドして実行し、ローカルのHTTPアドレスを示します。また、別のターミナルからリクエストを送る間、実行したままにする必要があるプロセスを説明します。初回の依存関係のダウンロードとアプリケーションの起動を区別し、プロセスの停止と再起動の方法を示します。プロセスの終了時に既定のメモリ内イベント履歴が消えることも説明します。ウォッチモードは、最初の起動に成功してから紹介します。
