## ページ案 <a id="page-plan" />

このページでは、実行中のスターターで`Counter`を作成し、返されたエンティティ識別子を変更コマンドに使ってから、クエリで結果の値を読み取り、動作を確認します。リクエストのペイロード、レスポンスの形式、変更がプロジェクションに反映されるまでの遅延について説明します。入力を拒否する応答も取り上げ、正常に機能する検証応答とセットアップ失敗を区別します。読者がショップのチュートリアルに進む前に、保守されている`Counter`のシナリオで繰り返し確認できるようにします。
