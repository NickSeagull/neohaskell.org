## ページ案 <a id="page-plan" />

このページでは、Neo CLIで名前付きアプリケーションを作成し、コマンドを実行する場所と、新しいディレクトリに作成される`Counter`スターターを説明します。通常の対話形式での作成方法と、エージェント向けの再現可能なコマンドを示し、初期Gitコミットとフレームワークの固定バージョンを説明してから、生成されたプロジェクトを確認します。ライブラリの作成とCLIオプションの全一覧はリファレンスで扱います。
