## ページ案 <a id="page-plan" />

このページでは、在庫の引き当てを例に、意図からドメイン上の判断、永続化までを追います。簡潔な結果表で、1件または複数のイベントを伴う受理、イベントを伴わない受理、ドメインによる拒否、実行失敗を区別します。在庫不足の拒否と、受理済みの変更を保存できない失敗との違いも説明します。最初の店の例は意図的に小さく保ち、手順についてはテストとトラブルシューティングへのリンクを用意します。
