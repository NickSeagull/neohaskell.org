## ページ案

このページでは、`Event` Model がアプリケーションの振る舞いをフィーチャー、チャプター、スライスにまとめる方法と、各スライスに明確な責任を持たせる理由を説明します。注釈付きの `Counter` フィーチャーツリーで、コマンドスライスとクエリスライスを宣言済みイベントにつなげます。ストーリーの整理とエンティティ境界の適用を区別し、実装のチュートリアルとDSLのフレームワークリファレンスに案内します。
