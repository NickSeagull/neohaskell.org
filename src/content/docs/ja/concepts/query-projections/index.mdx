## ページ案 <a id="page-plan" />

このページでは、選択したイベントソースから導出され、別個に維持される回答としてクエリ状態を説明します。カートと在庫のアクティビティクエリを例に、クエリはコマンドの境界を統合せずに複数のエンティティを組み合わせられることを示します。図ではイベント履歴、プロジェクションの更新、永続化されたチェックポイント位置を分けます。互換性のある進捗の再開と、変更されたクエリ状態の再構築を比較し、リプレイ中の準備完了状態も説明します。障害復旧手順書にはしません。
