## ページ案 <a id="page-plan" />

このページではOAuthプロバイダーを登録し、認証済みユーザーによる接続、コールバック、トークンの利用と更新、切断までを追います。シーケンス図でアプリケーションの本人識別とプロバイダーの認証情報、一時的な接続状態を分けます。利用者が用意する永続的なシークレットストアと、現在メモリ内にあるコールバックのトランザクションストアについて説明します。また、再起動後に未完了の接続がどうなるか、リクエストが別のインスタンスに届いた場合に何が起きるかも扱います。
