## ページ案 <a id="page-plan" />

このページでは、既存のフィーチャーにstdioのMCPトランスポートを登録し、初期化、ツールの検出、コマンド呼び出し、クエリリソースの読み取りを示します。簡潔なプロトコルのやりとりを通じて、コマンドはツール、クエリはリソースとして区別します。プロセスの所有者と信頼された実行コンテキストも説明し、このローカルプロトコルを認証済みリモートHTTPサービスと混同しないようにします。
