## ページ案

このページではアプリケーションCLIのトランスポートを登録し、生成されたエンティティとコマンドのグループを使ってコマンドを実行します。ターミナルへの入力と成功・拒否の結果を組み合わせ、出力モードがスクリプトに与える影響を説明します。例ではローカルの運用者が信頼される境界を示し、プロジェクトの作成と管理に使うneo開発CLIと、このアプリケーションのインターフェースを区別します。
