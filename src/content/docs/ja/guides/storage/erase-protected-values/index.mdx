## ページ案

このページでは、PostgreSQLを使った保護値の仕組みを使い、範囲を限定した消去タスクを紹介します。所有者による認可済みのリクエスト、保護された参照を1つ削除する処理、その結果として発行されるコマンド、明示的な再試行までを追います。処理前後の図で、保持されたイベント記録と取得できなくなった保護コンテンツを区別します。意図した結果を確認するとき、クエリと外部の複製を別途考慮すべきことも説明します。
