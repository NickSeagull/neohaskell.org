## ページ案

このページでは、イベント履歴とは別に永続クエリストレージを構成し、チェックポイントからの再開と、明示的に確認した再構築を追います。現在のクエリハッシュはクエリ名から導出されるため、プロジェクションコードを変更しただけでは保存済みの進捗が自動で無効にならないことを説明します。タイムラインで、リプレイ中に新しいイベントが届く様子と、準備完了になるタイミングを示します。再構築の失敗を診断の証拠と復旧につなげます。復旧には利用可能な履歴が必要で、外部への副作用を元に戻すことはできません。
