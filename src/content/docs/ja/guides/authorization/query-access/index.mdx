## ページ案

このページでは、データの取得前にクエリ単位のアクセス確認を行い、個別の結果には所有権の確認を適用します。所有者、別の認証済みユーザー、匿名の呼び出し元が同じクエリを使う場合を、ページ分割された結果も含めて比較します。簡潔な判断表で各確認の実行場所を示し、コマンドの権限がクエリエンドポイントも自動的に保護すると思い込まずに、返却データを保護する方法を説明します。
