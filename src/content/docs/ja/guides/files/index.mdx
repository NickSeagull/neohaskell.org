## ページ案 <a id="page-plan" />

このページでは、ファイルのメタデータとバイナリーストレージを設定し、ドキュメントをアップロードして、そのファイル参照をコマンドに添付し、所有者として取得します。シーケンス図で、保留中のアップロード、確定済みの添付、期限切れ、バイナリーの欠落を区別します。取得を許可するリクエストと拒否するリクエストを並べて示します。永続化の説明では、ファイルのバイト列、所有権のメタデータ、アプリケーションイベントを別々に扱います。
