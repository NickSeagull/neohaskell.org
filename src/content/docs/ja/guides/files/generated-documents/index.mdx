## ページ案

このページでは、ドキュメントのリクエストから、バイト列を生成するアウトバウンドハンドラー、所有者に紐づけて保持するファイルの保存、その参照を記録するコマンドの発行までを追います。再試行例では安定した作成キーを再利用し、内容が一致する場合と競合する場合を比較します。図では保持されたドキュメントと保留中のアップロードを分け、バイナリーディレクトリとファイルのメタデータの両方に耐久性のあるストレージが必要な理由を示します。
