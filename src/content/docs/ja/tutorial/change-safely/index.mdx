## ページ案 <a id="page-plan" />

このページでは、店頭販売用にマグカップを1個残すようショップを変更するタスクをエージェントに依頼します。先に動作表を更新し、判断の差分を確認して、新しい境界条件と既存の受理・拒否ケースをチェックします。変更前後の比較で、意図して変える結果と維持すべき結果を示します。確認済みのソースとチェック結果をまとめ、再利用できるエージェント作業ガイドを案内して締めくくります。
