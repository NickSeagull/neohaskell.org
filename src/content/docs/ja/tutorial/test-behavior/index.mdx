## ページの計画

このページでは、[機能を実装する](/tutorial/first-feature/)で作成した機能を、元の仕様に照らして検証します。承認と拒否が行われる注文、無効な数量、記録されたイベント、その後の在庫クエリを示します。入力、期待される結果、実際に観測された結果を比較表に並べ、小さなテストの抜粋と、失敗した場合の説明を掲載します。次の章の[安全に変更する](/tutorial/change-safely/)に進む前に、エージェントにどのような根拠を求めるべきかを説明します。
