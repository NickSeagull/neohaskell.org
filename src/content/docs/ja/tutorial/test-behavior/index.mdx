## ページ案 <a id="page-plan" />

このページでは、元のショップの表を、受理された注文、売り切れ時の拒否、ショップの状態の欠落、結果の在庫クエリを繰り返し確認できるチェックにします。判断のテスト、イベントリプレイの確認、HTTPシナリオの違いを説明してから、意図的な失敗と修正を1つ示します。期待した結果と観測した結果を並べます。エージェントは実際に実行したチェックを証拠として提示し、クエリの更新遅延も説明する必要があります。即時整合性を前提にしません。
