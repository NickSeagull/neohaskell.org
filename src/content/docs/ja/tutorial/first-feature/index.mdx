## ページ案 <a id="page-plan" />

このページでは、セットアップで作成した動作中のプロジェクトから始め、生成された`Counter`ファイルを確認して、ショップの状態とイベントを追加する範囲を限定したタスクをエージェントに依頼します。注釈付きのファイルツリーで、すべてのインポートを教えることなく`Entity`、`Event`、`Core`、`Feature`を説明します。開始時の在庫を明示して、受理された注文による変化を確認します。実行可能なソースを公開する前に、ショップで使う識別子を検証します。
