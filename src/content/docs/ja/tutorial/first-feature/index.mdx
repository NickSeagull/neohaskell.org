## ページの計画

[エージェントをセットアップする](/getting-started/)で用意したプロジェクトと、[最初の機能をモデル化する](/tutorial/)で作成した仕様から始めます。範囲を限定したタスクをエージェントに依頼する方法、変更されたファイルを確認する方法、バックエンドの振る舞いを呼び出し可能なインターフェースに接続する方法を示します。要点を絞ったソースコードの抜粋と注釈付きのファイルツリーで各部分を説明し、構文が必要な箇所では[言語の基本](/reference/language/)に直接案内します。ここで作成したものを使って、[振る舞いをテストする](/tutorial/test-behavior/)に進みます。
