## ページ案

このページでは、ショップの現在の状態から在庫クエリを作り、その回答とイベント履歴が別のものである理由を説明します。受理された注文1件でマグカップが3個から2個になる流れを追い、拒否された注文では履歴も在庫も変わらないことを確認します。簡潔な履歴と回答の図を、プロジェクションのコードおよび宣言されたイベント入力と一緒に示します。HTTPのクエリには、受理されたコマンドの反映まで時間がかかる場合があることも説明します。
