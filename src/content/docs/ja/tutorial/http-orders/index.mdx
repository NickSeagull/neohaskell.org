## ページ案

このページでは、ショップのコマンドとクエリを`Feature`経由で登録し、その`Feature`を名前付きのアプリケーション`Event` Modelに組み込みます。読者は、受理される注文と拒否される注文を1つずつ送り、実行中のHTTPサービスから在庫クエリを確認します。接続設定に絞ったコードと、隣り合わせたリクエストおよびレスポンスの例で、ソースを観測可能な動作につなげます。検証済みのショップのルートとペイロードを使い、HTTPとMCPのより広い選択肢はタスクガイドに案内します。
