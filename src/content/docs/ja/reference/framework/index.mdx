## ページ案

このページでは、`EventModel`、`FeatureAction`、`chapter`、`slice`、`entity`、`command`、`produces`、`query`、`readsFrom`を、ソース内にある`Counter`フィーチャーに対応づけます。簡潔な関係図で、イベント履歴と`query`行を混同せずに、宣言、検証、ランタイムでの組み立てを示します。ビルダーのシグネチャと順序の制約もモデルと並べて説明します。`Service.Application`を直接組み立てる方法は、高度な節へのリンクとして扱い、公開APIであることを保ちつつ、現在のスターターの構成を中心に説明します。
