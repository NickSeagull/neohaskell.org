## ページの計画

このページでは、エンティティ、コマンド、判定、イベント、クエリ、アプリケーションの構成を、検証済みのフレームワーク定義に対応付けます。各項目に役割、関連する型、必須フィールド、役割を示す最小限の完全なソースコード例を記載します。イベント記録とクエリ結果を分けたまま、要素同士の関係を簡潔な図で示します。概念の説明には[コア概念](/learn/)、1つのアプリケーションでの使い方には[最初の機能のチュートリアル](/tutorial/first-feature/)に案内します。
