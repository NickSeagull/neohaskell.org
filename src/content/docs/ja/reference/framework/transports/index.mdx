## ページ案 <a id="page-plan" />

このページではWeb、アプリケーションCLI、MCPの登録方法を比較します。コマンドでそのトランスポートを許可し、モデルに登録する必要があることを示します。ルートの命名、コマンドのレスポンス、クエリハンドラーの入力、スキーマ登録を、1つのリクエストとレスポンスの形式で記録します。高度な節には、公開されているTransportインターフェースを説明するアンカーを設けます。アプリケーションCLIとneo開発コマンドのリファレンスを明確に区別します。
