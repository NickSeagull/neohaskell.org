## ページ案

このページでは`Query`、`QueryOf`、`EntitiesOf`、`queryId`、`combine`、`Update`、`Delete`、`NoOp`の各結果を定義します。エンティティからクエリへの小さな例で、行の識別とイベントストリームの識別を分けて示します。アンカー付きの節で`NeoQL`のフィルタリング、ページ分割の入力とレスポンスフィールド、結果の上限、取得前のアクセス確認、行ごとの可視性を扱います。`Counter`クエリを具体的な利用例として使い、HTTPリクエスト、ストレージ、認可のタスクへは手順を重ねずにリンクします。
