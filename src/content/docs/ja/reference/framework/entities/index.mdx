## ページ案

このページでは`EntityOf`、`EventOf`、`EntityIdType`、`initialState`、`update`、イベントの振り分け、関連するderiveヘルパーを規定します。短いイベント列と順に変化するエンティティの状態で、純粋な畳み込みを示します。シグネチャでは引数の順番とストリームの識別を明示します。単一イベントのペイロードとエンティティのイベント合計型の違いも説明し、永続化の設定や互換性の変更はタスクガイドに案内します。
