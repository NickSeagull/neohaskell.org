## ページ案

このページでは`Core`の入口とスカラー型、すなわち`Text`、数値型、`Bool`、`Unit`、`Uuid`を一覧にし、再エクスポートされる型と修飾が必要なモジュール操作の違いを示します。短い型とモジュールの対応表から、コンテナー、任意値と結果、タスク、JSONのページに案内します。選んだシグネチャでテキスト変換と算術規約を示し、高度な並行処理や実装モジュールはサイドバーに追加せず、ソースへのリンクに留めます。
