## ページの計画

このページでは、アプリケーションの作成者がよく使うCoreの型と操作をまとめます。各項目には、シグネチャ、入力と出力、検証済みの最小限の例、関連する境界条件、正式な定義へのリンクを掲載します。関連する操作は簡潔な表で比較し、ソースと出力の組み合わせで振る舞いを明示します。[言語の基本](/reference/language/)で構文を確認できるよう案内します。実際の内容が個別のリファレンスページを必要とするまでは、全体像を示すページとし、内容のない関数ごとのページは作りません。
