## ページ案 <a id="page-plan" />

このページでは`Nothing`および`Just`と、`Err`および`Ok`を比較します。説明を必要としない不在と、型付きエラーが必要な場合を示します。簡潔なシグネチャと対応するケースで、`map`、`andThen`、`withDefault`、`mapError`、2つのコンテナー間の変換を扱います。解析や検索の例では、呼び出し元が意図して処理するまでエラーを保持し、副作用のある失敗処理は`Task`に案内します。
