## ページ案

このページでは`Task error value`、成功値の構築、型付きの失敗、連結、`do`記法、復旧、`Result`への変換を説明します。短い処理の例で、どの手順が実行され、失敗後に何が起きるかを示します。シグネチャ表ではタスクの構築とプログラム境界での実行を区別します。クリーンアップとキャンセルは高度な項目に案内し、`Decision`は業務上の受理と拒否を扱う別の契約として明確に相互参照します。
