## ページ案

このページでは、ワークスペースの欠落、不正な`neo.json`、前提条件の不足、無効な依存関係、利用できないフレームワークガイダンス、子プロセスの失敗など、観測可能な障害を一覧にします。各項目で診断コードと場所を、最小限の修正および復旧確認と組み合わせます。注釈付きの診断例では、ソース範囲と保持された子プロセスの出力を説明します。ソースで定義されたメッセージと実際に取得した実行記録は区別し、修正に追加の証拠が必要な場合はCLIオプションとコミュニティへの報告方法に案内します。
