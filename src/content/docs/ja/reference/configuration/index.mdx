## ページの計画

このページでは、ドキュメントで扱うフレームワークのバージョンについて、検証済みの設定項目、既定値、必須の値、環境変数による上書きを一覧にします。トランスポート、イベントとクエリのストレージ、プロバイダーとの接続、シークレットの値を扱いますが、実際の認証情報は表示しません。一貫した表と小さく完結した設定例で、値の組み合わせ方を示します。無効な例には、検証済みの実際の診断内容と修正方法を記載します。各項目から、手順を繰り返すのではなく、関連するタスクガイドに案内します。
