## ページ案

このページでは、`Config`のフィールド、必須の説明、既定値、必須値、環境変数名、コマンドフラグ、ネストしたレコード、シークレットのマスキングを定義します。優先順位をコマンドライン、プロセス環境、dotenv、既定値の順に示す表と、ポート番号の簡単な仮例を用意します。起動時の読み込み、構成ファクトリー、登録順序、個別のストア選択を説明します。プロバイダー固有の設定はタスクガイドに案内し、`neo.json`のビルド構成は専用ページで扱います。
