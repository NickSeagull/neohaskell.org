## ページ案

このページでは、モジュールとインポート、関数適用、シグネチャ、パイプライン、レコードへのアクセス、条件分岐、`case`式、`do`ブロックを通じて、日常的なソースコードの読み方を説明します。各構文は、簡潔なソースコードと結果の組み合わせで示し、チュートリアルから参照できる安定したアンカーを用意します。修飾付き操作と生成される言語拡張について説明し、ローカル変数には`let`文を使い、`do`ブロック内で定義します。型定義は次のページに案内します。
