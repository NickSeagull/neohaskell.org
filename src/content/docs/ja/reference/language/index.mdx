## ページの計画

このページでは、Haskellの講座を必要とせずに[機能を実装する](/tutorial/first-feature/)を読み進められるよう、最低限必要な構文を説明します。モジュール、値、関数、型、パターンマッチング、パイプライン、doブロックを、小さく検証済みの例とその結果で扱います。doブロック内のローカル束縛にはlet文を使います。診断例では、よくある間違いと修正方法を説明します。他のガイドから必要な構文に直接移動できるよう、安定したセクションリンクを設けます。利用できる操作については[コアライブラリ](/reference/core/)で説明します。
