## ページ案

このページでは、型パラメーター、レコード、コンストラクター、直和型、型エイリアス、型クラス制約、関連型、可視型適用、deriving記法を、アプリケーションコードに現れる形で扱います。注釈付きのコマンドレコードとイベントの直和型を使って、ソース上の表記と取り得る値をつなぎます。手書きの定義とderiveヘルパーを区別し、メタプログラミングやHaskell言語マニュアルの再現には踏み込まず、フレームワークの契約にリンクします。
