## ページの計画

このページでは、プロジェクトの作成、ビルド、実行、テストのコマンドを含め、特定のリビジョンに基づいてNeo CLIの使い方を説明します。それぞれの項目に、実行場所、必須引数、オプション、期待される出力や終了結果、具体的な復旧手順を記載します。そのまま実行できるコマンドと検証済みの結果を対応させ、プラットフォームによって異なる場合に限り、別の手順も紹介します。最初の実行手順全体は[エージェントをセットアップする](/getting-started/)で扱います。このページは、その後の作業で素早く調べるためのものです。
