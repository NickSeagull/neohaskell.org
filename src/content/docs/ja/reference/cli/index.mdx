## ページ案 <a id="page-plan" />

このページでは`neo new`、`build`、`run`、`test`、`lock`を取り上げ、実行方法、作業ディレクトリ、入力、フラグ、ソースで定義された結果を、簡潔なコマンド表にまとめます。共通のverboseとCIオプション、ウォッチ動作、ライブラリの作成、`build`の`lock`チェックには個別のアンカーを設けます。モデルツールとエージェント設定コマンドは、それぞれ専用の範囲を限定したページに案内します。インストールと初回起動の全手順は「はじめに」に残します。
