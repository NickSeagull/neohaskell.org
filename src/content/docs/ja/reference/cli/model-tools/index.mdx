## ページ案

このページでは、`neo ide`のホストとポートの設定、`inspect`のフィルター、`inspect sync`、`validate`のパスとJSONオプションを列挙します。簡潔な表で、読み取り専用の確認、ソースからモデルへの同期、IDEでの編集を区別します。検証時の終了コードと、将来の取得結果の構造も記録し、モデル作成タスクは別のページに案内します。`Command`の契約は、古いバイナリーにも存在すると仮定せず、文書化するリビジョンに結びつけます。
