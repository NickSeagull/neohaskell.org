## ページ案

このページでは、`neo skills setup`のツール選択、スキルのフィルタリング、`all-tools`、`force`、`dry-run`、`refresh`の各オプションと、`neo guidance retry`を説明します。共通のワークフロースキルと、`build`、`run`、`test`で同期する、ソースに対応したフレームワークガイダンスを区別します。簡潔な保存先とオプションの表で、書き込まれるものと保持されるものを説明します。エージェント導入の詳しい内容はガイドに委ね、汎用フィーチャー生成コマンドがあるかのような説明はしません。
