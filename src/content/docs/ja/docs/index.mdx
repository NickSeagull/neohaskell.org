[はじめに](/introduction/)、[エージェントを設定する](/getting-started/)、[リソース](/resources/)の4ページには、既存のガイダンスがあります。それ以外のページには、これから執筆する解説、例、図の計画を記載しています。リソースでは、現在上流で利用できる手順を案内します。

最初の学習の流れでは、開発者の判断と業務上の問いから始め、イベントが変更の意味を保持する理由を説明してから、コマンドとクエリを紹介し、それらをイベントモデルでつなぎます。続いてNeoHaskellに付属するCounterのスターターを確認します。その後、チュートリアルでは、このプロジェクトで陶器のマグカップ店を作り、最初の判断からテスト済みのHTTPインターフェースまで進めます。各タスクガイドは個別の問いに答え、概念解説は設計を説明し、リファレンスは構文とAPIの契約を定義します。
