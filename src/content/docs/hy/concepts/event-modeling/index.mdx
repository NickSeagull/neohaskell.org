## Էջի ծրագիր <a id="page-plan" />

Այս էջը կբացատրի, թե ինչպես է `Event` Model-ը հավելվածի վարքը խմբավորում առանձնահատկությունների, գլուխների և սլայսների մեջ, և ինչու յուրաքանչյուր սլայս ունի հստակ պատասխանատվություն։ Նշումներով `Counter` առանձնահատկության ծառը հրամանի սլայսը և հարցման սլայսը կկապի դրանց հայտարարված իրադարձությունների հետ։ Այն կտարբերակի պատմության կազմակերպումը էության սահմանը կիրառելուց, ապա հղում կտա իրականացման ձեռնարկին և DSL-ի ֆրեյմվորքի տեղեկատուին։
