## Էջի ծրագիր <a id="page-plan" />

Այս էջը կտարբերակի իրադարձությունների հոսքում գրանցված փաստերը էության վիճակից, որը ստացվում է դրանք հերթով կիրառելով։ Համահունչ `Counter` մատյանն ու վիճակի աղյուսակը ցույց կտան, թե ինչպես է նույն պատմությունը վերակառուցում նույն էությունը՝ դրա թարմացման ֆունկցիայի միջոցով։ Այն կբացատրի, որ վերարտադրումը վիճակը ստանում է գրանցված փաստերից, այլ ոչ թե կրկին գործարկում սկզբնական հրամանները, իսկ հարցումների վերակառուցման բացատրությունը կթողնի առանձին էջին, պահպանման կարգավորումը՝ պահեստավորման ուղեցույցին։
