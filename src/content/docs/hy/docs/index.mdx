[Սկսեք այստեղ](/introduction/), [Կարգավորեք ձեր գործակալը](/getting-started/) և [Ռեսուրսներ](/resources/) բաժինների չորս էջերը պարունակում են առկա ուղեցույցները։ Մնացած էջերը նկարագրում են պլանավորված բացատրությունները, օրինակներն ու պատկերները։ Ռեսուրսների բաժինը հղում է անում այժմ վերին նախագծում հասանելի հրահանգներին։

Առաջին ճանապարհը սկսվում է մշակողի դատողությունից և բիզնեսի հարցերից, բացատրում է, թե ինչու են իրադարձությունները պահպանում փոփոխության իմաստը, ապա ներկայացնում հրամաններն ու հարցումները՝ նախքան դրանք Իրադարձությունների մոդելի մեջ կապելը։ Հետո կստուգվի NeoHaskell-ի հետ տրամադրվող Counter մեկնարկային օրինակը։ Ձեռնարկը այդ նախագծում կկառուցի կերամիկական գավաթների խանութ՝ առաջին որոշումից մինչև թեստավորված HTTP միջերեսը։ Յուրաքանչյուր առաջադրանքի ուղեցույց կպատասխանի առանձին հարցի, հասկացությունները կբացատրեն նախագծումը, իսկ տեղեկատու էջերը կսահմանեն շարահյուսությունն ու API-ի պայմանագրերը։
