## Էջի ծրագիր <a id="page-plan" />

Այս էջը կգրանցի հավելվածի CLI փոխադրումը և գեներացված էության ու հրամանների խմբավորման միջոցով հրաման կկանչի։ Այն տերմինալի մուտքերը կհամադրի հաջող ու մերժված արդյունքների հետ և կբացատրի, թե ինչպես է ելքի ռեժիմն ազդում սցենարավորման վրա։ Օրինակը կնշի տեղային օպերատորի վստահության սահմանը և այս հավելվածի միջերեսը կտարբերակի նախագիծ ստեղծելու ու կառավարելու համար օգտագործվող neo մշակման CLI-ից։
