## Էջի ծրագիր

Այս էջը կգրանցի առկա առանձնահատկության համար stdio MCP փոխադրումը և ցույց կտա սկզբնավորումը, գործիքների հայտնաբերումը, հրամանի կանչն ու հարցման ռեսուրսի ընթերցումը։ Համառոտ արձանագրության պատճենը հրամանները կտարբերակի որպես գործիքներ, իսկ հարցումները՝ որպես ռեսուրսներ։ Օրինակը կբացատրի գործընթացի սեփականությունն ու վստահելի կատարման համատեքստը, որպեսզի ընթերցողները տեղային այս արձանագրությունը չշփոթեն նույնականացվող հեռավոր HTTP ծառայության հետ։
