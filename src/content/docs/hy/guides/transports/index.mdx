## Էջի ծրագիր

Այս էջը Web փոխադրմամբ հասանելի կդարձնի առկա առանձնահատկությունը և կուսումնասիրի գեներացված երթուղիներն ու OpenAPI պայմանագիրը։ Հրամանի հարցումը, մերժված մուտքն ու հարցման պատասխանը կապակցված կլինեն հավելվածի սահմանմանը և դիտարկելի HTTP վարքին։ Զտումն ու էջավորումը կշարունակեն [հարցման պայմանագիրը](/reference/framework/queries/)։ Օրինակները կներառեն փոխադրման գրանցումն ու դիտարկիչի ծագման կարգավորումը, ապա հղում կտան նույնականացման ուղեցույցին՝ նախքան միջերեսն անվստահելի կանչողների համար բացելը։
