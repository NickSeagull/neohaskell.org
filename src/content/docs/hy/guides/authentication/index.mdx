## Էջի ծրագիր <a id="page-plan" />

Այս էջը հավելվածը կմիացնի OIDC թողարկչին, անհրաժեշտության դեպքում կկարգավորի սպասվող թոքենի լսարանը և կզննի հրամանին հասանելի օգտատիրոջ պնդումները։ Հարցումների համեմատությունը կներառի վավեր թոքեն, անվավեր թոքեն և անանուն կանչող։ Սահմանների փոքր դիագրամը կառանձնացնի ինքնության ստուգումը հրաման գործարկելու թույլտվությունից և կանչողին արտաքին OAuth մատակարարին կապելուց։
