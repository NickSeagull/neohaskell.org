## Էջի ծրագիր <a id="page-plan" />

Այս էջը կկարգավորի ֆայլերի մետատվյալներն ու բլոբերի պահեստը, կվերբեռնի փաստաթուղթ, դրա հղումը կկցի հրամանին և կստանա այն որպես սեփականատեր։ Հաջորդականությունը կտարբերակի սպասող վերբեռնումները, հաստատված կցումները, ժամկետի ավարտը և բացակայող բլոբերը։ Զույգ հարցումները ցույց կտան թույլատրված ու մերժված ստացումը, իսկ պահպանման բացատրությունը ֆայլի բայթերը, սեփականության մետատվյալներն ու հավելվածի իրադարձությունները կպահի առանձին։
