## Էջի ծրագիր <a id="page-plan" />

Այս էջը կգրանցի OAuth մատակարար և նույնականացված օգտատիրոջ համար կհետևի միացմանը, հետադարձ կանչին, թոքենի օգտագործմանը, թարմացմանն ու անջատմանը։ Հաջորդականության դիագրամը կառանձնացնի հավելվածի ինքնությունը մատակարարի հավաստագրերից և կապի ժամանակավոր վիճակից։ Այն կբացատրի սպառողի տրամադրած մշտական գաղտնիքների պահոցը և ներկայիս՝ հիշողության մեջ պահվող հետադարձ կանչի գործարքների պահոցը, ներառյալ այն, թե ինչ է պատահում կիսատ կապին վերագործարկումից հետո կամ երբ հարցումը հասնում է մեկ այլ օրինակի։
