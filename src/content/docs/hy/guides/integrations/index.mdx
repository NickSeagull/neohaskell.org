## Էջի ծրագիր <a id="page-plan" />

Այս էջը կընդունված իրադարձությունը կկապի տիպավորված ելքային մշակիչի հետ, կկատարի HTTP հարցում և մատակարարի պատասխանը կվերածի հետագա հրամանի։ Հաջողության ու ձախողման հետքերը ցույց կտան մաքուր որոշման և արտաքին գործողության սահմանը։ Օրինակը կօգտագործի իդեմպոտենտության բանալի և կբացատրի HTTP-ի ու դիսպետչերի կրկնափորձի առանձին կարգավորումները՝ առանց կայուն առաքում կամ մեկանգամյա կատարում խոստանալու։
