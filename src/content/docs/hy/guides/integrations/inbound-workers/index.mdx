## Էջի ծրագիր <a id="page-plan" />

Այս էջը կգրանցի տիպավորված մուտքային աշխատող, որը հրամաններ է ուղարկում հայտարարված էությունների թիրախներին։ Ժամաչափով կառավարվող փոքր օրինակը ցույց կտա աշխատողի կարգավորումը, աջակցվող հրամանների բազմությունն ու հավելվածի կապակցումը, որին կհաջորդի կոմպիլյացիայի ժամանակ մերժված թիրախը։ Կյանքի ցիկլի դիագրամը կնշի մեկնարկի ու կանգնեցման պատասխանատվությունները, իսկ տեքստը կտարբերակի երկարաժամկետ մուտքային աղբյուրը ընդունված իրադարձությանը հաջորդող ելքային արձագանքից։
