## Էջի ծրագիր <a id="page-plan" />

Այս էջը մեկ հրաման կպաշտպանի հայտարարված հասանելիության քաղաքականությամբ և համապատասխան էության սեփականությունը ստուգող որոշմամբ։ Աղյուսակը կհամեմատի անանուն կանչողներին, նույնականացված սեփականատերերին, այլ օգտատերերին և վստահելի տեղային կանչը։ Ուղեկցող թեստերը կհաստատեն, որ մերժված հրամանները չեն հասնում որոշմանը և իրադարձություններ չեն ավելացնում, ինչպես նաև ցույց կտան, թե ինչու նույնականացումը միացնելը պարտադիր է, որպեսզի HTTP քաղաքականության դարպասը կիրառվի։
