## Էջի ծրագիր

Այս էջը տվյալները ստանալուց առաջ կկիրառի հարցման մակարդակի հասանելիության ստուգում, իսկ առանձին արդյունքների համար՝ սեփականության ստուգում։ Այն կհամեմատի նույն հարցումը սեփականատիրոջ, մեկ այլ նույնականացված օգտատիրոջ և անանուն կանչողի համար՝ ներառյալ էջավորված արդյունքը։ Որոշումների կարճ աղյուսակը ցույց կտա, թե որտեղ է կատարվում յուրաքանչյուր ստուգումը, որպեսզի ընթերցողը կարողանա պաշտպանել վերադարձվող տվյալները՝ առանց ենթադրելու, որ հրամանների թույլտվություններն ինքնաբերաբար պաշտպանում են հարցումների վերջնակետերը։
