## Էջի ծրագիր <a id="page-plan" />

Այս էջը հարցումների մշտական պահեստավորումը կկարգավորի իրադարձությունների պատմությունից առանձին և կհետևի հենակետից վերսկսելուն ու բացահայտորեն ստուգված վերակառուցմանը։ Այն կբացատրի, որ հարցման ընթացիկ հեշը ստացվում է հարցման անունից, ուստի միայն պրոյեկցիայի կոդի փոփոխությունն ինքնաբերաբար անվավեր չի դարձնում պահպանված առաջընթացը։ Ժամանակագիծը ցույց կտա վերարտադրման ընթացքում մուտք գործող իրադարձությունները և պատրաստվածության հասանելի դառնալու պահը։ Վերակառուցման ձախողումը կկապվի ախտորոշիչ ապացույցների ու վերականգնման հետ, որը պահանջում է օգտագործելի պատմություն և չի չեղարկում արտաքին ազդեցությունները։
