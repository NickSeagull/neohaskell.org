## Էջի ծրագիր

Այս էջը կներկայացնի ջնջման սահմանափակ առաջադրանք՝ PostgreSQL-ի վրա հիմնված պաշտպանված արժեքների մեխանիզմով։ Այն կհետևի սեփականատիրոջ թույլատրված հարցմանը, մեկ պաշտպանված հղման ջնջմանը, արդյունքում առաջացած հրամանին և բացահայտ կրկնափորձին։ Նախքան և հետո դիագրամը կտարբերակի պահպանված իրադարձության գրառումը անհասանելի պաշտպանված բովանդակությունից և կբացատրի, թե ինչպես առանձին հաշվի առնել հարցումներն ու արտաքին պատճենները՝ նախատեսված արդյունքը ստուգելիս։
