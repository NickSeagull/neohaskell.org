## Էջի ծրագիր <a id="page-plan" />

Այս էջը վարքի պահանջը կվերածի գործակալի սահմանափակ առաջադրանքի՝ նախագծի տարբերակով, համապատասխան սկզբնաղբյուրով, ընդունման դեպքերով և թույլատրված փոփոխություններով։ Այն ցույց կտա վերօգտագործելի հուշում և կենտրոնացված diff, ապա պահանջվող արդյունքը կհամեմատի որոշման թեստերի ու միջերեսի ապացույցների հետ։ Ուղղման օրինակը կտարբերակի կոմպիլյատորի հաջող ավարտը ճիշտ վարքից և գործակալին կուղղորդի ամրագրված ֆրեյմվորքի պահպանվող ուղեցույցին։
