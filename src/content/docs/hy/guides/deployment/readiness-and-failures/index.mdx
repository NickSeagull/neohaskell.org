## Էջի ծրագիր <a id="page-plan" />

Այս էջը կհամեմատի առողջության վերջնակետը հարցման պատրաստվածության հետ և կհետևի ձախողված գործողությանը՝ օգտագործելով հարցման նույնացուցիչն ու կառուցվածքային մատյանները։ Վիճակի փոքր դիագրամը HTTP արդյունքների հետ միասին ցույց կտա հարցման վերակառուցումը, պատրաստ լինելը և ձախողումը։ Ախտորոշման օրինակները կտարբերակեն պահեստավորման ձախողումը անհասանելի ինտեգրումից և վերականգնման քայլերը կկապեն ապացույցների հետ՝ գործող գործընթացը չհամարելով բոլոր հարցումների հասանելիության ապացույց։
