## Էջի ծրագիր

Այս էջը կստուգի գործող մեկնարկային օրինակը՝ ստեղծելով `Counter`, վերադարձված էության նույնացուցիչն օգտագործելով փոփոխության հրամանում և հարցման միջոցով կարդալով ստացված արժեքը։ Այն կբացատրի հարցման մարմինը, պատասխանի փաթեթը և հնարավոր ուշացումը, մինչև պրոյեկցիան արտացոլի փոփոխությունը։ Մերժված մուտքը ցույց կտա գործող վավերացման պատասխանի և կարգավորման ձախողման տարբերությունը։ Պահպանվող `Counter` սցենարը կրկնելի ստուգում կտա նախքան ընթերցողները կսկսեն խանութի ձեռնարկը։
