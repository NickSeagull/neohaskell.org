## Էջի ծրագիր <a id="page-plan" />

Այս էջը գեներացված նախագիծը կկապի այն որոշումների հետ, որոնք պետք է կայացնեն ընթերցողն ու նրա գործակալը։ Այն կգտնի հավելվածի `Event` Model-ը, `Counter` առանձնահատկությունը, հրամանների որոշումները, իրադարձությունները, էության թարմացումները, հարցումներն ու թեստերը, ապա դրանք կտարբերակի `neo.json`-ից վերագեներացվող հավաքման ֆայլերից։ Համառոտ գրացուցակային քարտեզը յուրաքանչյուր տեղը կկապի իր նպատակին։ Ընթերցողները կսովորեն, թե որտեղ ստուգել առաջարկված փոփոխությունը՝ առանց ամբողջ ֆրեյմվորքի մոդուլներն ուսումնասիրելու։
