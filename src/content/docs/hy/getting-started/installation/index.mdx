## Էջի ծրագիր

Այս էջը կնշի աջակցվող միջավայրն ու կտեղադրի Neo CLI-ն՝ դրա պահանջվող Nix և Git գործիքներով։ Այն կտարբերակի CLI-ի տեղադրումը նախագծով կառավարվող կոմպիլյատորն ու գրադարանները ստանալուց, կբացատրի ընտրովի խմբագրիչի միջավայրը և ցույց կտա տեղադրված գործիքները ստուգելու եղանակները։ Հրահանգները կկապվեն ստուգված թողարկմանն ու հարթակին, իսկ երկուական քեշի ընտրությունները կբացատրվեն, երբ դրանք ազդում են առաջին հավաքման վրա՝ տեղադրման վերականգնման էջերի ուղիղ հղումներով։
