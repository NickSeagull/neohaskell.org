## Էջի ծրագիր

Այս էջը Neo CLI-ով կստեղծի անվանված հավելված, կբացատրի՝ որտեղ գործարկել հրամանը, և կներկայացնի նոր գրացուցակում հայտնվող `Counter` մեկնարկային օրինակը։ Այն ցույց կտա սովորական ինտերակտիվ տարբերակը և գործակալի համար վերարտադրելի հրամանը, կբացատրի սկզբնական Git commit-ն ու ֆրեյմվորքի ամրագրումը, ապա կհաստատի գեներացված նախագիծը՝ շարունակելուց առաջ։ Գրադարանի ստեղծումն ու CLI-ի բոլոր ընտրանքները կմնան տեղեկատուի թեմաներ։
