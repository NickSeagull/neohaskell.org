## Էջի ծրագիր <a id="page-plan" />

Այս էջը նախագծի արմատից կհավաքի ու կգործարկի գեներացված `Counter` հավելվածը, կնշի տեղային HTTP հասցեն և կբացատրի, թե որ գործընթացը պետք է շարունակի աշխատել, մինչ հարցումներն ուղարկվում են մեկ այլ տերմինալից։ Այն կտարբերակի կախվածությունների սկզբնական ներբեռնումը հավելվածի գործարկումից, ցույց կտա գործընթացը կանգնեցնելու ու վերագործարկելու եղանակը և կբացատրի, որ հիշողության մեջ պահվող լռելյայն իրադարձությունների պատմությունն անհետանում է, երբ գործընթացն ավարտվում է։ Դիտարկման ռեժիմը կներկայացվի միայն առաջին հաջող մեկնարկից հետո։
