## Էջի ծրագիր

Այս էջը խանութի հրամանն ու հարցումը կգրանցի դրա `Feature`-ով և այդ `Feature`-ը կմիացնի հավելվածի անվանված `Event` Model-ին։ Ընթերցողները գործող HTTP ծառայության միջոցով կուղարկեն մեկ ընդունված ու մեկ մերժված պատվեր, ապա կուսումնասիրեն պաշարի հարցումը։ Կենտրոնացված կապակցման հատվածն ու կողք կողքի հարցման ու պատասխանի օրինակները սկզբնաղբյուրը կկապեն դիտարկելի վարքին։ Ձեռնարկը կօգտագործի ստուգված խանութի երթուղիներն ու մարմինները, իսկ HTTP-ի և MCP-ի ավելի լայն ընտրանքները կհղի համապատասխան առաջադրանքի ուղեցույցին։
