## Էջի ծրագիր <a id="page-plan" />

Այս էջը խանութի ընթացիկ վիճակը կվերածի պաշարի հարցման և ցույց կտա, թե ինչու է դրա պատասխանը առանձին իրադարձությունների պատմությունից։ Ընթերցողները կհետևեն մեկ ընդունված պատվերի ընթացքին՝ երեք գավաթից երկուսի, ապա կստուգեն, որ մերժված պատվերը չի փոխում ո՛չ պատմությունը, ո՛չ պաշարը։ Պատմության ու պատասխանի համառոտ պատկերը կուղեկցի պրոյեկցիայի կոդին և դրա հայտարարված իրադարձությունների մուտքերին։ Դասը կբացատրի, որ ընդունված հրամանն արտացոլելու համար HTTP հարցմանը կարող է ժամանակ պետք լինել։
