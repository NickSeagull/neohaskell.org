## Էջի պլան

Այս էջը [Իրականացրեք հնարավորությունը](/tutorial/first-feature/) նյութի հնարավորությունը կստուգի դրա սկզբնական բնութագրման համեմատ։ Այն ցույց կտա ընդունված ու մերժված պատվերները, անվավեր քանակները, գրանցված իրադարձությունները և դրանցից ստացված պաշարի հարցումը։ Մուտքը, ակնկալվող արդյունքն ու դիտարկված արդյունքը միասին կլինեն համեմատության աղյուսակում՝ փոքր թեստային հատվածների և բացատրված խափանման հետ։ Ընթերցողները կսովորեն, թե ինչ ապացույց խնդրել գործակալից նախքան [Անվտանգ փոփոխություն կատարեք](/tutorial/change-safely/) էջին անցնելը։
