## Էջի ծրագիր <a id="page-plan" />

Այս էջը խանութի սկզբնական աղյուսակը կվերածի կրկնելի ստուգումների՝ ընդունված պատվերի, սպառված պաշարի մերժման, բացակայող խանութի վիճակի և ստացված պաշարի հարցման համար։ Ընթերցողները կտարբերակեն որոշման թեստը իրադարձությունների վերարտադրման ստուգումից ու HTTP սցենարից, ապա կուսումնասիրեն մեկ միտումնավոր ձախողում և դրա ուղղումը։ Սպասվող ու դիտարկված արդյունքները կցուցադրվեն միասին։ Գործակալի ապացույցը պետք է ներառի իրականում կատարված ստուգումները և հաշվի առնի հարցման թարմացման ուշացումը՝ ակնթարթային հետևողականություն ենթադրելու փոխարեն։
