## Էջի պլան

Այս էջը կսկսի [Կարգավորեք ձեր գործակալը](/getting-started/) ուղեցույցի գործող նախագծից և [Մոդելավորեք ձեր առաջին հնարավորությունը](/tutorial/) էջի բնութագրումից։ Այն ցույց կտա, թե ինչպես այդ սահմանափակված առաջադրանքը տալ գործակալին, ուսումնասիրել փոփոխված ֆայլերը և հետնամասի մեկ վարքագիծը միացնել կանչելի միջերեսին։ Սկզբնական կոդի համապատասխան հատվածներն ու ծանոթագրություններով ֆայլերի ծառը կբացատրեն յուրաքանչյուր մասը՝ շարահյուսության անհրաժեշտության դեպքում ուղիղ հղում տալով [Լեզվի հիմնական տարրերը](/reference/language/) էջին։ Արդյունքը կշարունակվի [Թեստավորեք վարքագիծը](/tutorial/test-behavior/) էջում։
