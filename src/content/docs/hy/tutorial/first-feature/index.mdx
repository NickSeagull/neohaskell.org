## Էջի ծրագիր

Այս էջը կշարունակվի կարգավորումից ստացված գործող նախագծով, կուսումնասիրի գեներացված `Counter` ֆայլերը և գործակալին կտա խանութի վիճակն ու իրադարձությունները ներմուծելու սահմանափակ առաջադրանք։ Նշումներով ֆայլերի ծառը կբացատրի `Entity`, `Event`, `Core` և `Feature` հասկացությունները՝ առանց յուրաքանչյուր ներմուծում սովորեցնելու։ Ընթերցողները բացահայտ կսահմանեն մեկնարկային պաշարը և կուսումնասիրեն, թե ընդունված պատվերն ինչպես է փոխում այն։ Առաջարկված խանութի նույնացուցիչները կստուգվեն մինչև գործարկվող սկզբնաղբյուր հրապարակելը։
