## Էջի ծրագիր <a id="page-plan" />

Այս էջը կցանկագրի դիտարկելի ձախողումները՝ բացակայող աշխատանքային տարածք, անվավեր `neo.json`, բացակայող նախապայմաններ, անվավեր կախվածություններ, անհասանելի ֆրեյմվորքի ուղեցույց և զավակ գործընթացների ձախողում։ Գրառումները ախտորոշիչ կոդն ու տեղը կհամադրեն ամենափոքր ուղղման և վերականգնումը հաստատող ստուգման հետ։ Մեկ նշումներով ախտորոշումը կբացատրի սկզբնաղբյուրի հատվածներն ու պահպանված զավակ գործընթացի ելքը։ Սկզբնաղբյուրով սահմանված հաղորդագրությունները կմնան տարբեր գործարկված արձանագրություններից՝ CLI-ի ընտրանքների և համայնքին դիմելու հղումներով, երբ ուղղման համար ավելի շատ ապացույց է պետք։
