## Էջի ծրագիր <a id="page-plan" />

Այս էջը կտարանջատի գործարկման կարգավորման ձախողումները, կապի անվավեր կարգավորումները, զբաղված լսողներին, հրամանի մերժումը, թույլտվության մերժումն ու կատարման ձախողումը։ Ախտանիշների համառոտ աղյուսակը յուրաքանչյուր կատեգորիա կկապի պատասխանատու կարգավորման կամ հանրային պատասխանի տիպի և վերականգնման մեկ ստուգման հետ։ Այն ցույց կտա, թե ինչու մերժված հրամանը վավեր բիզնես արդյունք է, ոչ թե ինքնաբերաբար սերվերի խափանում, իսկ պահեստի կամ մատակարարի ձախողումները կուղղորդի համապատասխան առաջադրանքների ուղեցույցներին։
