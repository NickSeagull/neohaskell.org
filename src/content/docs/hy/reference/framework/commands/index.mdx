## Էջի ծրագիր <a id="page-plan" />

Այս էջը կհստակեցնի հրամանի գրառումը, `EntityOf`, `getEntityId`, `decide`, `RequestContext`, փոխադրումների թույլտվություններն ու ածանցման օգնականները՝ հեղինակած ֆունկցիաները համապատասխանեցնելով հանրային `Command` մեթոդներին։ Այն համառոտ արդյունքների աղյուսակով կհամեմատի `acceptNew`, `acceptExisting`, `acceptAny`, `acceptAfter` և `reject`-ը։ `Counter`-ի որոշման դեպքերը հիմք կտան ընդունված և մերժված վարքի համար։ Բազմավարձակալների ստորագրություններն ու թույլտվության hook-երը կունենան հղումներ, իսկ իրականացման ու հասանելիության քաղաքականության երկար բացատրությունները կմնան առաջադրանքների ուղեցույցներում։
