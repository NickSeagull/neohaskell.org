## Էջի ծրագիր <a id="page-plan" />

Այս էջը կհամեմատի Web, հավելվածի CLI և MCP գրանցումները՝ ցույց տալով, որ հրամանը պետք է թույլատրի իր փոխադրումը, իսկ մոդելը՝ տեղադրի այն։ Այն մեկ հարցման ու պատասխանի կառուցվածքով կգրանցի երթուղիների անվանումը, հրամանների պատասխանները, հարցման մշակիչի մուտքերն ու սխեմայի գրանցումը։ Առաջադեմ հղվող բաժինը կնկարագրի հանրային Transport միջերեսը։ Հավելվածի CLI-ն հստակ կտարբերվի neo մշակման հրամանների տեղեկատուից։
