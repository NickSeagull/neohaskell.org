## Էջի պլան

Այս էջը էությունները, հրամանները, որոշումները, իրադարձությունները, հարցումներն ու հավելվածի համադրումը կկապի շրջանակի ստուգված սահմանումների հետ։ Յուրաքանչյուր գրառում կնշի իր պարտականությունը, համապատասխան տիպերը, պարտադիր դաշտերն ու դերի ցուցադրման համար անհրաժեշտ ամենափոքր ամբողջական սկզբնական կոդի օրինակը։ Կոմպակտ կապերի պատկերը ցույց կտա, թե ինչպես են մասերը միանում՝ իրադարձությունների գրառումները հարցումների արդյունքներից առանձին պահելով։ Գրառումները կհղվեն դեպի [Հիմնական հասկացություններ](/learn/)՝ բացատրության, և [առաջին հնարավորության ուսուցողական նյութ](/tutorial/first-feature/)՝ մեկ հավելվածում դրանց կիրառության համար։
