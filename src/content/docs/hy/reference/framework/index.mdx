## Էջի ծրագիր

Այս էջը `EventModel`, `FeatureAction`, `chapter`, `slice`, `entity`, `command`, `produces`, `query` և `readsFrom` հայտարարությունները կկապի տեղային `Counter` առանձնահատկության հետ։ Հարաբերությունների համառոտ դիագրամը ցույց կտա հայտարարումը, վավերացումն ու գործարկման ժամանակ կապակցումը՝ իրադարձությունների պատմությունը `query` տողերի հետ չխառնելով։ Կառուցողի ստորագրություններն ու հերթականության սահմանափակումները կլինեն մոդելի կողքին։ `Service.Application`-ի ուղղակի կապակցումը կլինի հղվող առաջադեմ բաժին՝ պահպանելով դրա հանրային կարգավիճակը, բայց առաջին տեղում դնելով մեկնարկային օրինակի ներկայիս ճարտարապետությունը։
