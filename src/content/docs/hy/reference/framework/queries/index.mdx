## Էջի ծրագիր

Այս էջը կսահմանի `Query`, `QueryOf`, `EntitiesOf`, `queryId`, `combine` և `Update`, `Delete`, `NoOp` արդյունքները։ Էություն-հարցում փոքր օրինակը տողի նույնացուցիչը ցույց կտա իրադարձությունների հոսքի նույնացուցիչից առանձին։ Հղումներով բաժինները կներկայացնեն `NeoQL` զտումը, էջավորման մուտքերն ու պատասխանի դաշտերը, արդյունքների սահմանները, տվյալներ ստանալուց առաջ հասանելիության ստուգումը և յուրաքանչյուր տողի տեսանելիությունը։ `Counter` հարցումը կլինի կոնկրետ սպառողի օրինակ՝ HTTP հարցումների, պահեստավորման ու թույլտվության առաջադրանքների հղումներով՝ դրանց ամբողջ ընթացակարգերը չկրկնելու փոխարեն։
