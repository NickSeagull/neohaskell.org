## Էջի ծրագիր <a id="page-plan" />

Այս էջը կհստակեցնի `EntityOf`, `EventOf`, `EntityIdType`, `initialState`, `update`, իրադարձությունների ուղղորդումն ու համապատասխան derive օգնականները։ Իրադարձությունների կարճ հաջորդականությունն ու էության հաջորդական վիճակները ցույց կտան մաքուր fold-ը, իսկ ստորագրությունները կհստակեցնեն արգումենտների հերթականությունն ու հոսքի նույնացուցիչը։ Այն կբացատրի մեկ իրադարձության պարունակության և էության իրադարձությունների sum տիպի տարբերությունը, իսկ պահպանման կարգավորումն ու համատեղելիության փոփոխությունները կհղի առաջադրանքների ուղեցույցներին։
