## Էջի ծրագիր

Այս էջը փաստաթղթավորելու է `neo new`, `build`, `run`, `test` և `lock` հրամանները՝ համառոտ հրամանների աղյուսակում ներառելով գործարկումը, աշխատանքային գրացուցակը, մուտքերն ու սկզբնաղբյուրում սահմանված արդյունքները։ Ընդհանուր verbose և CI ընտրանքները, դիտարկման վարքը, գրադարանի ստեղծումն ու `build`-ի `lock` ստուգումը հղումներ կունենան։ Մոդելի գործիքներն ու գործակալի կարգավորման հրամանները կուղղվեն իրենց սահմանափակ էջերին, իսկ տեղադրումն ու ամբողջական առաջին գործարկումը կմնան սկսելու բաժնում։
