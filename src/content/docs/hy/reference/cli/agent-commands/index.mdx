## Էջի ծրագիր

Այս էջը կփաստաթղթավորի `neo skills setup` գործիքների ընտրությունը, հմտությունների զտումը, `all-tools`, `force`, `dry-run` և `refresh` ընտրանքները, ինչպես նաև `neo guidance retry`-ը։ Այն կտարբերակի ընդհանուր աշխատանքային հոսքի հմտությունները սկզբնաղբյուրին համապատասխան ֆրեյմվորքի ուղեցույցից, որը համաժամացվում է `build`, `run` և `test` հրամաններով։ Նպատակների ու ընտրանքների համառոտ աղյուսակը կբացատրի, թե ինչ է գրվում և պահպանվում։ Գործակալի ավելի երկար ներածությունը կմնա իր ուղեցույցում, և գործառույթներ գեներացնելու ընդհանուր հրաման չի ենթադրվի։
