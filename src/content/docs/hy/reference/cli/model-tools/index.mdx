## Էջի ծրագիր

Այս էջը կներկայացնի `neo ide`-ի հոսթի ու պորտի կարգավորումները, `inspect` զտիչները, `inspect sync`-ը և `validate`-ի ուղու ու JSON-ի ընտրանքները։ Համառոտ աղյուսակը կտարբերակի միայն ընթերցմամբ զննումը սկզբնաղբյուրից մոդել համաժամեցնելու և IDE-ի խմբագրումներից։ Այն կգրանցի վավերացման ելքի կոդերը և ցույց կտա ապագայում պահպանվող արդյունքի կառուցվածքը՝ հղում անելով մոդել ստեղծելու առաջադրանքներին։ `Command` պայմանագրերը կկապվեն փաստաթղթավորված տարբերակին, այլ ոչ թե կհամարվեն առկա հին երկուական ֆայլերում։
