## Էջի ծրագիր <a id="page-plan" />

Այս էջը կներկայացնի `Json`-ի կոդավորումն ու վերծանումը, `FromJSON` և `ToJSON` օրինակները, անվավեր մուտքը որպես `Result`, ինչպես նաև API-ի տվյալները նկարագրող առանձին `Schema` պայմանագիրը։ Փոքր գրառումը կհամադրվի դրա JSON կառուցվածքի և մեկ անվավեր մուտքի հետ։ Այն կտարբերակի սերիալացումը վավերացումից ու գեներացված API նկարագրություններից։ Քերականական վերլուծիչի օգնականները կլինեն հղումներով աղյուսակներում, իսկ հրամանի մարմնի մանրամասները կուղղորդվեն փոխադրումների տեղեկատուին։
