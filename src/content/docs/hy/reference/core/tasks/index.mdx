## Էջի ծրագիր

Այս էջը կփաստաթղթավորի `Task error value`-ը, հաջող կառուցումը, տիպավորված ձախողումը, շղթայումը, `do` գրառումը, վերականգնումն ու `Result`-ի վերածումը։ Մեկ կարճ հաջորդականությունը ցույց կտա, թե որ քայլն է գործարկվում և ինչ է պատահում ձախողումից հետո։ Ստորագրությունների աղյուսակը կտարբերակի առաջադրանք կազմելը ծրագրի սահմանին այն գործարկելուց։ Մաքրումն ու չեղարկումը կլինեն հղվող առաջադեմ բաժիններ, իսկ `Decision`-ի հղումը հստակ ցույց կտա, որ դա բիզնես ընդունման ու մերժման առանձին պայմանագիր է։
