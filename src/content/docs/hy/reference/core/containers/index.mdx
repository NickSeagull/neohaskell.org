## Էջի ծրագիր

Այս էջը կխմբավորի `Array` և `Map` գործողությունները՝ ըստ տվյալների կառուցման, որոնման, փոխակերպման, համադրման և կրճատման։ Ստորագրությունների աղյուսակները կհստակեցնեն pipeline-ի արգումենտների հերթականությունը, իսկ փոքր օրինակները ցույց կտան բացակայող ինդեքս կամ բանալի, դատարկ հավաքածուներ և հասարակ գումար։ Կապակցված գործողությունները մեկ էջում հղումներ կունենան՝ կանոնական սահմանումներով ու եզրային դեպքերով, այլ ոչ թե յուրաքանչյուր արտահանվող ֆունկցիայի համար առանձին երթուղի։
