## Էջի ծրագիր <a id="page-plan" />

Այս էջը կհամեմատի `Nothing`-ն ու `Just`-ը `Err`-ի և `Ok`-ի հետ՝ ցույց տալով, թե երբ բացակայությունը բացատրություն չի պարունակում, իսկ երբ անհրաժեշտ է տիպավորված սխալ։ Համառոտ ստորագրություններն ու զույգ դեպքերը կներկայացնեն `map`, `andThen`, `withDefault`, `mapError` և երկու կոնտեյներների միջև փոխակերպումները։ Վերլուծման կամ որոնման օրինակը սխալը կպահպանի, մինչև կանչողը միտումնավոր մշակի այն, իսկ կողմնակի ազդեցություններ առաջացնող սխալների մշակումը կհղվի `Task`-ին։
