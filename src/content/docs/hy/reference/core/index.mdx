## Էջի ծրագիր

Այս էջը կծառայի որպես `Core`-ի մուտքի կետ ու սկալյար արժեքների տեղեկատու՝ `Text`, թվային տիպերի, `Bool`, `Unit`, `Uuid`-ի և վերաարտահանվող տիպի ու որակավորված մոդուլի գործողությունների տարբերության համար։ Տիպերի ու մոդուլների համառոտ աղյուսակը ընթերցողներին կուղղորդի դեպի կոնտեյներներ, ընտրովի արդյունքներ, առաջադրանքներ ու JSON։ Ընտրված ստորագրությունները ցույց կտան տեքստի փոխակերպումն ու թվաբանության պայմանականությունները։ Առաջադեմ համաժամանակությունն ու իրականացման մոդուլները կմնան հղված սկզբնաղբյուր, ոչ թե կողային ցանկի նյութ։
