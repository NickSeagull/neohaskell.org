## Էջի պլան

Այս էջը կկազմակերպի Core-ի այն տիպերն ու գործողությունները, որոնց հավելվածներ կառուցողները հաճախ են հանդիպում։ Փաստաթղթավորված յուրաքանչյուր գրառում կունենա ստորագրություն, մուտքն ու ելքը, նվազագույն ստուգված օրինակ, համապատասխան եզրային դեպքեր և հղում սկզբնական սահմանմանը։ Կոմպակտ աղյուսակները կօգնեն համեմատել նմանատիպ գործողությունները, իսկ սկզբնական կոդի և ելքի զույգերը հստակ կցուցադրեն վարքագիծը։ Էջը կհղվի դեպի [Լեզվի հիմնական տարրերը](/reference/language/)՝ շարահյուսության համար և կմնա ընդհանուր ակնարկ, մինչև իրական բովանդակությունն առանձին տեղեկատու էջերի անհրաժեշտություն առաջացնի։ Այդպես կխուսափենք դատարկ՝ յուրաքանչյուր ֆունկցիայի համար առանձին էջերից։
