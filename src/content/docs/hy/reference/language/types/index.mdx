## Էջի ծրագիր

Այս էջը կներկայացնի տիպի պարամետրերը, գրառումները, կառուցիչները, sum տիպերը, տիպերի այլանունները, դասերի սահմանափակումները, ասոցիացված տիպերը, տեսանելի տիպի կիրառումը և deriving գրառումը՝ հավելվածի կոդում հանդիպող ձևերով։ Նշումներով համառոտ հրամանի գրառումն ու իրադարձությունների sum տիպը կկապեն սկզբնաղբյուրի գրառումն ու հնարավոր արժեքները։ Այն կտարբերակի ձեռքով գրված սահմանումները derive օգնականներից և հղում կտա ֆրեյմվորքի պայմանագրերին՝ մետածրագրավորման դասավանդման կամ Haskell լեզվի ձեռնարկ կրկնելու փոխարեն։
