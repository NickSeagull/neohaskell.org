## Էջի ծրագիր

Այս էջը հասկանալի կդարձնի առօրյա սկզբնաղբյուրը՝ ներկայացնելով մոդուլներն ու ներմուծումները, ֆունկցիաների կիրառումը, ստորագրությունները, խողովակաշարերը, գրառումների դաշտերի հասանելիությունը, պայմանականները, `case` արտահայտություններն ու `do` բլոկները։ Յուրաքանչյուր կառուցվածք կունենա սկզբնաղբյուրի մեկ համառոտ օրինակ և արդյունք՝ ձեռնարկների հղումների համար կայուն խարիսխներով։ Այն կբացատրի որակավորված գործողություններն ու գեներացված լեզվական ընդլայնումները՝ օգտագործելով `let` հրահանգներ՝ `do` բլոկների ներսում տեղային կապումների համար, իսկ տիպերի սահմանումները կհղի հաջորդ էջին։
