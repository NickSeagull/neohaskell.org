## Էջի ծրագիր <a id="page-plan" />

Այս էջը կսահմանի `Config`-ի դաշտերը, պահանջվող փաստաթղթավորումը, լռելյայն արժեքները, պարտադիր արժեքները, միջավայրի անունները, հրամանի դրոշները, ներդրված գրառումները և գաղտնիքի թաքցումը։ Առաջնահերթության մեկ աղյուսակում ցույց կտրվեն հրամանի տողը, գործընթացի միջավայրը, dotenv-ը և ապա լռելյայն արժեքը՝ փոքր պայմանական պորտի օրինակով։ Այն կբացատրի գործարկման ժամանակ բեռնումը, կարգավորման ֆաբրիկաները, գրանցման հերթականությունն ու առանձին պահեստների ընտրությունը, իսկ մատակարարին հատուկ կարգավորումները կուղղորդի առաջադրանքների ուղեցույցներին։ `neo.json`-ի հավաքման կարգավորումն առանձին էջում կմնա։
