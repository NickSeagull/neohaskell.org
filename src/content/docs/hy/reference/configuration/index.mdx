## Էջի պլան

Այս էջում կթվարկվեն փաստաթղթավորվող շրջանակի տարբերակի համար ստուգված կարգավորման դաշտերը, կանխադրվածներն ու միջավայրի վերագրումները։ Այն կընդգրկի փոխանցման եղանակները, իրադարձությունների և հարցումների պահոցները, մատակարարների միացումներն ու գաղտնի արժեքները՝ առանց իրական հավատարմագրերը ցուցադրելու։ Հետևողական աղյուսակն ու ամբողջական փոքր կարգավորումները ցույց կտան, թե ինչպես են արժեքներն իրար հետ համադրվում։ Անվավեր օրինակների համար, երբ ստուգված լինի, կնշվեն իրական ախտորոշումն ու ուղղումը։ Գրառումները կհղվեն համապատասխան առաջադրանքի ուղեցույցին՝ դրա ամբողջ ընթացքը չկրկնելու համար։
