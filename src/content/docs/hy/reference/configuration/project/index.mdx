## Էջի ծրագիր

Այս էջը կնկարագրի `neo.json`-ի name, version, neo-version, project type, metadata, license-ի լռելյայն արժեքն ու կախվածությունների գրառումները՝ դրանք տարանջատելով գործարկման միջավայրի կարգավորումներից։ Փոքր ամբողջական manifest-ը և դաշտերի աղյուսակը կբացատրեն գեներացված Cabal ու Nix ֆայլերի կառավարումը և կհղվեն կախվածությունների աջակցվող ձևերին։ Սկզբնաղբյուրի ընտրության բաժինը տեղային ֆրեյմվորքի փոխարինումը կներկայացնի որպես մշակման առաջադեմ կարգավորում, իսկ թողարկումների համատեղելիությունը բացահայտ կսահմանի՝ main-ը հրապարակված տարբերակին չնույնացնելով։
