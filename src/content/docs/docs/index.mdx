The four pages under [Start here](../introduction/), [Set up your agent](../getting-started/), and [Resources](../resources/) contain existing guidance. The other destinations contain page plans describing the explanations, examples, and figures to be written. Resources links to instructions available upstream now.

The first journey begins with developer judgment and business questions, explains why events retain the meaning of a change, then introduces commands and queries before connecting them in an Event Model. It will then check the Counter starter supplied with NeoHaskell. The tutorial will then build a ceramic-mug shop in that project, from its first decision to a tested HTTP interface. Each task guide will answer an independent question; concepts will explain the design and reference pages will define syntax and API contracts.
