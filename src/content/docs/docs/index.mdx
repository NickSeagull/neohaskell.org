<p class="docs-lead">Understand the behavior. Build one feature. Check the result.</p>

[Core concepts](/learn/), [Set up your agent](/getting-started/), and [Resources](/resources/) contain existing guidance. The other destinations below contain page plans describing the explanations, examples, and figures to be written. For instructions available now, Resources links to upstream syntax, CLI, storage, testing, and authorization guidance.

This page will orient readers around a short first journey, independent task guides, deeper explanations, and a predictable reference. It will use a linked reading map to show where each question belongs. The tutorial will follow one shop feature from its specification to a tested backend behavior and callable interface; it will not require a Haskell course. Examples and figures will support the article where they explain a specific idea.
