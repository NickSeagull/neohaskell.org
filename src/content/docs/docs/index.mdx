<p class="docs-lead">Understand an application with Event Modeling. Build a first project. Find the task or API you need.</p>

[Design your application](/introduction/), [Core concepts](/learn/), [Set up your agent](/getting-started/), and [Resources](/resources/) contain existing guidance. The other destinations contain page plans describing the explanations, examples, and figures to be written. Resources links to instructions available upstream now.

The first journey begins with a shared picture of what an application should do, before introducing NeoHaskell concepts or installation. It will then check the Counter starter supplied with NeoHaskell. The tutorial will then build a ceramic-mug shop in that project, from its first decision to a tested HTTP interface. Each task guide will answer an independent question; concepts will explain the design and reference pages will define syntax and API contracts.
