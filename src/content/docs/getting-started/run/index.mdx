## Page plan <a id="page-plan" />

This page will build and run the generated `Counter` application from its project root, identify the local HTTP address, and explain which process must remain running while requests are sent from another terminal. It will distinguish an initial dependency download from application startup, show how to stop and restart the process, and explain that the default in-memory event history disappears when the process ends. Watch mode will be introduced only after the first successful launch.
