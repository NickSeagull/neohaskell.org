## Page plan <a id="page-plan" />

This page will identify the supported environment and install the Neo CLI with its required Nix and Git tools. It will distinguish installing the CLI from obtaining the project-managed compiler and libraries, explain the optional editor environment, and show checks for the installed tools. Instructions will be tied to a verified release and platform, with binary-cache choices explained where they affect the first build and direct links to setup recovery.
