## Page plan

This page will map the generated project to the decisions a reader and their agent need to make. It will locate the application `Event` Model, the `Counter` feature, command decisions, events, entity updates, queries, and tests, then distinguish those authored files from build files regenerated from `neo.json`. A compact directory map will connect each location to its purpose. Readers will learn where to inspect a proposed change without studying every framework module.
