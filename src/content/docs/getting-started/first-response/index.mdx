## Page plan <a id="page-plan" />

This page will verify the running starter by creating a `Counter`, using the returned entity identifier in a change command, and reading the resulting value through its query. It will explain the request payload, response envelope, and possible delay before the projection reflects the change. A rejected input will distinguish a working validation response from a setup failure. The maintained `Counter` scenario will provide a repeatable check before readers begin the shop tutorial.
