## Page plan

This page will connect common first-run symptoms to the failed step and its smallest corrective action: missing tools, the wrong working directory, an existing project name, invalid project configuration, unavailable dependencies, or missing agent guidance. Each case will show a verified diagnostic and the check that confirms recovery. It will preserve the reader's files, explain how to identify their CLI and framework versions, and link deeper compiler or runtime errors to the reference.
