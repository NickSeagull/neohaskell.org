## Seitenplan <a id="page-plan" />

Diese Seite verfolgt eine Bestandsreservierung von der Absicht über die fachliche Entscheidung bis zur Speicherung. Eine kompakte Ergebnistabelle unterscheidet zwischen Annahme mit einem oder mehreren Ereignissen, Annahme ohne Ereignisse, fachlicher Ablehnung und Ausführungsfehler. Sie erklärt, warum die Ablehnung wegen unzureichenden Bestands etwas anderes ist als ein Fehler beim Speichern einer angenommenen Änderung. Die erste Ladenillustration bleibt bewusst klein; Links zu Tests und Fehlerbehebung behandeln die Abläufe.
