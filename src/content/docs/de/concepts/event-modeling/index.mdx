## Seitenplan <a id="page-plan" />

Diese Seite erklärt, wie ein `Event`-Modell das Anwendungsverhalten in Features, Kapitel und Slices gliedert und warum jedes Slice eine klar umrissene Aufgabe hat. Ein kommentierter `Counter`-Featurebaum verbindet ein Kommando-Slice und ein Abfrage-Slice mit den deklarierten Ereignissen. Die Seite grenzt die Gliederung einer Geschichte von der Durchsetzung einer Entitätsgrenze ab und verweist anschließend für die Implementierung auf das Tutorial und für die DSL auf die Framework-Referenz.
