## Seitenplan <a id="page-plan" />

Diese Seite registriert das Kommando und die Abfrage des Ladens über sein `Feature` und bindet dieses `Feature` in das benannte `Event`-Modell der Anwendung ein. Die Leserinnen und Leser senden eine angenommene und eine abgelehnte Bestellung und untersuchen anschließend die Bestandsabfrage über den laufenden HTTP-Dienst. Ein fokussierter Ausschnitt zur Verknüpfung und direkt danebenstehende Anfrage-Antwort-Paare verbinden Quellcode mit beobachtbarem Verhalten. Das Tutorial verwendet überprüfte Routen und Nutzdaten für den Laden; allgemeine Optionen für HTTP und MCP stehen im Aufgabenleitfaden.
