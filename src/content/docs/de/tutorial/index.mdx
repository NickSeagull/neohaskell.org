## Seitenplan

Diese Seite überträgt die Ideen aus den [Kernkonzepten](/learn/) in eine konkrete Spezifikation für die Bestellung eines Keramikbechers. Sie definiert den Anfangsbestand, das Kommando, die Annahmebedingungen, das aufgezeichnete Ereignis und das Abfrageergebnis. Auch eine abgelehnte Bestellung ist enthalten. Eine kleine Verhaltenstabelle und ein statisches Modell zeigen, was geprüft werden muss. Die fertige Spezifikation führt zu [Die Funktion implementieren](/tutorial/first-feature/). Weiterführende Überlegungen zur Modellierung stehen unter [Anwendungsverhalten modellieren](/concepts/event-modeling/).
