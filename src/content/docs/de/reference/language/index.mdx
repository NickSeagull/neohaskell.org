## Seitenplan

Diese Seite vermittelt die nötigen Syntaxgrundlagen für [Die Funktion implementieren](/tutorial/first-feature/), ohne einen Haskell-Kurs vorauszusetzen. Sie behandelt Module, Werte, Funktionen, Typen, Pattern Matching, Pipelines und do-Blöcke anhand kurzer geprüfter Beispiele mit den zugehörigen Ergebnissen. Lokale Bindungen verwenden let-Anweisungen innerhalb von do-Blöcken. Diagnosebeispiele erklären einen häufigen Fehler und seine Korrektur. Stabile Abschnittslinks ermöglichen es anderen Leitfäden, direkt auf das benötigte Sprachelement zu verweisen. Die [Core-Bibliothek](/reference/core/) behandelt verfügbare Operationen.
