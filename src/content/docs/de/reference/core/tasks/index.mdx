## Seitenplan <a id="page-plan" />

Diese Seite dokumentiert `Task error value`, erfolgreiche Erzeugung, typisierte Fehler, Verkettung, `do`-Notation, Fehlerbehandlung und die Konvertierung zu `Result`. Eine kurze Sequenz zeigt, welcher Schritt ausgeführt wird und was nach einem Fehler passiert. Eine Signaturtabelle unterscheidet das Erstellen eines Tasks von seiner Ausführung an der Programmgrenze. Aufräumen und Abbruch werden als erweiterte Themen verlinkt; `Decision` wird ausdrücklich als eigener Vertrag für fachliche Annahme und Ablehnung eingeordnet.
