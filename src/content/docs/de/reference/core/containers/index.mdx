## Seitenplan

Diese Seite gruppiert Operationen für `Array` und `Map` nach Erstellen, Finden, Transformieren, Kombinieren und Reduzieren von Daten. Signaturtabellen machen die Argumentreihenfolge in Pipelines deutlich. Kleine Beispiele zeigen einen nicht vorhandenen Index oder Schlüssel, leere Sammlungen und eine einfache Summe. Verwandte Operationen erhalten Anker auf einer gemeinsamen Seite mit den kanonischen Definitionen und Randfällen, statt für jede exportierte Funktion eine eigene Route zu erhalten.
