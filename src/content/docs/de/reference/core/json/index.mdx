## Seitenplan <a id="page-plan" />

Diese Seite behandelt die JSON-Kodierung und -Dekodierung mit `Json`, die Instanzen `FromJSON` und `ToJSON`, fehlerhafte Eingaben als `Result` sowie den getrennten Vertrag `Schema` zur Beschreibung von API-Daten. Ein kleiner Record wird zusammen mit seiner JSON-Struktur und einer ungültigen Eingabe gezeigt. Die Seite unterscheidet Serialisierung von Validierung und generierten API-Beschreibungen. Parser-Hilfsfunktionen stehen in Tabellen mit Ankern; Details zu Kommando-Nutzdaten werden auf die Transportreferenz verlinkt.
