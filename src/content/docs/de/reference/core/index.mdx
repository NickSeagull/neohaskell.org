## Seitenplan

Diese Seite ordnet die Core-Typen und -Operationen, denen Anwendungsentwickler am häufigsten begegnen. Jeder dokumentierte Eintrag enthält eine Signatur, Eingabe und Ausgabe, ein minimales geprüftes Beispiel, relevante Grenzfälle und einen Link zur maßgeblichen Definition. Kompakte Tabellen erleichtern den Vergleich verwandter Operationen. Quelltext und Ausgabe nebeneinander machen das Verhalten deutlich. Die Seite verweist für Syntax auf [Sprachgrundlagen](/reference/language/) und bleibt eine Übersicht, bis tatsächliche Inhalte eigene Referenzseiten rechtfertigen. Leere Platzhalter für einzelne Funktionen werden vermieden.
