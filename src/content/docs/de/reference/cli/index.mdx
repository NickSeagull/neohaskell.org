## Seitenplan

Diese Seite dokumentiert `neo new`, `build`, `run`, `test` und `lock` anhand einer kompakten Kommandotabelle mit Aufruf, Arbeitsverzeichnis, Eingaben, Flags und quellcodedefinierten Ergebnissen. Globale Optionen für verbose und CI, Watch-Verhalten, das Erstellen von Bibliotheken und die von `build` vorgenommene `lock`-Prüfung erhalten eigene Anker. Modellwerkzeuge und Kommandos zur Agenteneinrichtung werden auf ihre jeweiligen abgegrenzten Seiten verlinkt. Installation und der vollständige erste Start bleiben im Einstiegskapitel.
