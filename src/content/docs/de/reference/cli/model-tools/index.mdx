## Seitenplan <a id="page-plan" />

Diese Seite listet Einstellungen für Host und Port von `neo ide`, Filter für `inspect`, `inspect sync` sowie Pfad- und JSON-Optionen für `validate` auf. Eine kompakte Tabelle unterscheidet schreibgeschützte Untersuchung von Synchronisierung zwischen Quellcode und Modell sowie Änderungen in der IDE. Sie hält Exit-Codes der Validierung fest und zeigt die Struktur eines künftig erfassten Ergebnisses. Aufgaben zur Modellierung werden an anderer Stelle verlinkt. `Command`-Verträge beziehen sich auf die dokumentierte Revision und werden nicht für ältere Binärdateien vorausgesetzt.
