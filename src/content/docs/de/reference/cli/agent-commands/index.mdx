## Seitenplan <a id="page-plan" />

Diese Seite dokumentiert für `neo skills setup` die Werkzeugauswahl, Skill-Filter und Optionen `all-tools`, `force`, `dry-run` und `refresh`, dazu `neo guidance retry`. Sie unterscheidet gemeinsame Workflow-Skills von quellcodegestützten Framework-Anleitungen, die mit `build`, `run` und `test` synchronisiert werden. Eine kompakte Tabelle zu Zielen und Optionen erklärt, was geschrieben und bewahrt wird. Das ausführliche Onboarding für Agenten bleibt im Leitfaden; ein allgemeines Kommando zur Feature-Erzeugung wird nicht suggeriert.
