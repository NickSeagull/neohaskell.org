## Seitenplan

Diese Seite unterscheidet Fehler in der Startkonfiguration, ungültige Bind-Einstellungen, belegte Listener, Kommandoablehnungen, verweigerte Autorisierung und Ausführungsfehler. Eine kompakte Symptomtabelle ordnet jede Kategorie der zuständigen Konfiguration oder dem öffentlichen Antworttyp sowie einer Prüfung zur Behebung zu. Sie zeigt, warum ein abgelehntes Kommando ein gültiges fachliches Ergebnis und nicht automatisch ein Serverfehler ist. Bei Speicher- oder Anbieterfehlern verweist sie auf die gepflegten Aufgabenanleitungen.
