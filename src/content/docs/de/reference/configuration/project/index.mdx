## Seitenplan <a id="page-plan" />

Diese Seite beschreibt die Felder name, version, neo-version, Projekttyp, Metadaten, Standardlizenz und Abhängigkeiten in `neo.json` und unterscheidet sie von Laufzeit-Umgebungseinstellungen. Ein kleines vollständiges Manifest und eine Feldtabelle erklären, welche Cabal- und Nix-Dateien erzeugt werden und wer sie verwaltet. Ein Abschnitt zur Quellenauswahl erläutert die lokale Framework-Überschreibung als erweiterte Entwicklungseinstellung. Die Release-Kompatibilität wird ausdrücklich benannt, statt main mit einer veröffentlichten Version gleichzusetzen.
