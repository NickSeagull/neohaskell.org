## Seitenplan <a id="page-plan" />

Diese Seite definiert `Config`-Felder, erforderliche Dokumentation, Standardwerte, Pflichtwerte, Umgebungsvariablen, Kommandozeilen-Flags, verschachtelte Records und das Ausblenden von Geheimnissen. Eine einzige Rangfolgetabelle zeigt Kommandozeile, Prozessumgebung, dotenv und anschließend Standardwert anhand eines kleinen hypothetischen Portbeispiels. Sie erklärt das Laden beim Start, Konfigurationsfabriken, Registrierungsreihenfolge und getrennte Speicherauswahl. Anbieterspezifische Einstellungen werden auf Aufgabenleitfäden verwiesen; die Build-Konfiguration `neo.json` erhält eine eigene Seite.
