## Seitenplan

Diese Seite vergleicht die Registrierung von Web-, Anwendungs-CLI- und MCP-Transporten. Sie zeigt, dass ein Kommando seinen Transport erlauben muss und dass das Modell ihn einbinden muss. Außerdem dokumentiert sie Routennamen, Kommandoantworten, Eingaben der Abfrage-Handler und die Schema-Registrierung anhand einer Anfrage- und Antwortstruktur. Ein erweiterter Abschnitt mit Anker beschreibt die öffentliche Transport-Schnittstelle. Die Anwendungs-CLI wird klar von der Referenz zu den Neo-Entwicklungskommandos unterschieden.
