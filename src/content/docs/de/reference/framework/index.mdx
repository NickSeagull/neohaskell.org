## Seitenplan <a id="page-plan" />

Diese Seite ordnet `EventModel`, `FeatureAction`, `chapter`, `slice`, `entity`, `command`, `produces`, `query` und `readsFrom` dem quellnahen `Counter`-Feature zu. Eine kompakte Beziehungsabbildung zeigt Deklaration, Validierung und Laufzeitaufbau, ohne Ereignisverlauf und `query`-Zeilen zu vermischen. Builder-Signaturen und Reihenfolgebedingungen stehen beim Modell. Der direkte Aufbau mit `Service.Application` wird als erweiterter Abschnitt verlinkt. Der aktuelle Aufbau des Starters bleibt der Einstieg, während der öffentliche Status dieser API erhalten bleibt.
