## Seitenplan

Diese Seite erstellt mit der Neo-CLI eine benannte Anwendung, erklärt, wo das Kommando ausgeführt wird, und benennt den `Counter`-Starter, der im neuen Verzeichnis erscheint. Sie zeigt den üblichen interaktiven Ablauf und ein reproduzierbares Kommando für einen Agenten, erklärt den ersten Git-Commit und die festgelegte Framework-Version und bestätigt das erzeugte Projekt, bevor es weitergeht. Das Erstellen von Bibliotheken und die vollständige Liste der CLI-Optionen bleiben Referenzthemen.
