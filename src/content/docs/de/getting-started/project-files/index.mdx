## Seitenplan <a id="page-plan" />

Diese Seite ordnet das erzeugte Projekt den Entscheidungen zu, die Leserinnen, Leser und ihr Agent treffen müssen. Sie zeigt das `Event`-Modell der Anwendung, das `Counter`-Feature, Kommandoentscheidungen, Ereignisse, Entitätsaktualisierungen, Abfragen und Tests. Außerdem grenzt sie diese bearbeiteten Dateien von Build-Dateien ab, die aus `neo.json` neu erzeugt werden. Eine kompakte Verzeichnisübersicht ordnet jedem Speicherort seine Aufgabe zu. So erfahren die Leserinnen und Leser, wo sie eine vorgeschlagene Änderung prüfen können, ohne jedes Framework-Modul studieren zu müssen.
