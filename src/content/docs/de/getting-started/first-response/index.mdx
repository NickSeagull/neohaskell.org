## Seitenplan

Diese Seite prüft den laufenden Starter: Sie erstellt einen `Counter`, verwendet die zurückgegebene Entitäts-ID in einem Änderungs-Kommando und liest den resultierenden Wert über dessen Abfrage aus. Sie erklärt die Anfrage-Nutzdaten, den Antwortumschlag und die mögliche Verzögerung, bis die Projektion die Änderung widerspiegelt. Eine abgelehnte Eingabe zeigt, wie eine funktionierende Validierungsantwort von einem Einrichtungsfehler zu unterscheiden ist. Das gepflegte `Counter`-Szenario bietet eine wiederholbare Prüfung, bevor die Leserinnen und Leser mit dem Tassenladen-Tutorial beginnen.
