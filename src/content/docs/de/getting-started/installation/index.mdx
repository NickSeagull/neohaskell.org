## Seitenplan

Diese Seite nennt die unterstützte Umgebung und installiert die Neo-CLI mit den erforderlichen Werkzeugen Nix und Git. Sie unterscheidet die CLI-Installation vom projektverwalteten Compiler und den Bibliotheken, erklärt die optionale Editor-Umgebung und zeigt, wie die installierten Werkzeuge geprüft werden. Die Anweisungen beziehen sich auf eine überprüfte Version und Plattform. Optionen für den Binär-Cache werden erläutert, wenn sie den ersten Build beeinflussen, und direkte Links führen zur Behebung von Einrichtungsproblemen.
