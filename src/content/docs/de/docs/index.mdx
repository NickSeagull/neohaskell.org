Die [Kernkonzepte](/learn/), [Deinen Agenten einrichten](/getting-started/) und [Ressourcen](/resources/) enthalten bereits vorhandene Anleitungen. Die übrigen Ziele unten enthalten Seitenpläne für Erklärungen, Beispiele und Abbildungen, die noch erstellt werden. Für Anleitungen, die schon jetzt verfügbar sind, verweisen die Ressourcen auf maßgebliche Anleitungen zu Syntax, CLI, Speicherung, Tests und Autorisierung.

Diese Seite bietet einen Überblick über einen kurzen Einstieg, eigenständige Aufgabenleitfäden, ausführlichere Erklärungen und eine übersichtliche Referenz. Eine verlinkte Lesekarte zeigt, wo die jeweilige Frage behandelt wird. Das Tutorial begleitet eine Funktion des Shops von der Spezifikation über ein getestetes Backend-Verhalten bis zu einer aufrufbaren Schnittstelle. Ein Haskell-Kurs ist dafür nicht erforderlich. Beispiele und Abbildungen unterstützen den Text, wenn sie einen konkreten Gedanken erklären.
