## Seitenplan

Diese Seite erklärt, wie sich Anwendungsverhalten über HTTP und MCP bereitstellen lässt. Dazu gehören Konfiguration und Verträge, die für die dokumentierte Framework-Version geprüft wurden. Sie zeigt ein Kommando und eine Abfrage anhand von Anfrage-und-Antwort-Paaren sowie gleichwertigen Tool-Aufrufen und enthält ein Beispiel zur Prüfung des generierten OpenAPI. Ein kleines Grenzdiagramm trennt Transportschnittstellen von Entscheidungen. Statische Beispiele zeigen sowohl Erfolg als auch Ablehnung. Ein Live-Widget für Anfragen kommt erst infrage, wenn eine unterstützte isolierte Laufzeitumgebung verfügbar ist.
