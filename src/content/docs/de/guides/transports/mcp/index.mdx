## Seitenplan

Diese Seite registriert den stdio-MCP-Transport für ein vorhandenes Feature und zeigt Initialisierung, Tool-Erkennung, einen Kommandoaufruf und das Lesen einer Abfrage-Ressource. Ein kurzes Protokolltranskript unterscheidet Kommandos als Tools von Abfragen als Ressourcen. Das Beispiel erklärt die Prozesszuständigkeit und den vertrauenswürdigen Ausführungskontext, damit dieser lokale Dienst nicht mit einem authentifizierten entfernten HTTP-Dienst verwechselt wird.
