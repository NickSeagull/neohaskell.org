## Seitenplan

Diese Seite macht aus einer Verhaltensanforderung eine klar begrenzte Agentenaufgabe. Sie nennt die Projekt-Revision, relevante Quelldateien, Abnahmefälle und erlaubte Änderungen. Ein wiederverwendbarer Prompt und ein fokussierter Diff zeigen, wie sich das angeforderte Ergebnis mit Entscheidungstests und Schnittstellennachweisen vergleichen lässt. Ein Korrekturbeispiel unterscheidet einen erfolgreichen Compilerlauf von korrektem Verhalten und verweist den Agenten auf die gepflegten Anleitungen für das festgelegte Framework.
