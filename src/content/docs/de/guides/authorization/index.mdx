## Seitenplan <a id="page-plan" />

Diese Seite schützt ein Kommando mit einer deklarierten Zugriffsrichtlinie und einer Entscheidung, die den relevanten Besitz der Entität prüft. Eine Tabelle vergleicht anonyme Aufrufer, authentifizierte Eigentümer, andere Benutzer und einen vertrauenswürdigen lokalen Aufruf. Die zugehörigen Tests prüfen, dass abgelehnte Kommandos die Entscheidung nicht erreichen und keine Ereignisse anhängen. Außerdem zeigen sie, warum Authentifizierung aktiviert sein muss, damit die HTTP-Richtlinienprüfung greift.
