## Seitenplan <a id="page-plan" />

Diese Seite verfolgt eine Dokumentanfrage durch einen ausgehenden Handler, der Bytes erzeugt, eine dauerhafte Datei mit Eigentümer speichert und ein Kommando ausgibt, das ihre Referenz aufzeichnet. Ein Wiederholungsbeispiel verwendet einen stabilen Erstellungs-Schlüssel und vergleicht passende Inhalte mit einem widersprüchlichen Versuch. Die Abbildung unterscheidet dauerhaft gespeicherte Dokumente von ausstehenden Uploads und zeigt, warum sowohl das Blob-Verzeichnis als auch die Dateimetadaten dauerhaft gespeichert werden müssen.
