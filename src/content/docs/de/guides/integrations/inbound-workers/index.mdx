## Seitenplan

Diese Seite registriert einen typisierten eingehenden Worker, der Kommandos an deklarierte Entitätsziele ausgibt. Ein kleines zeitgesteuertes Beispiel zeigt die Worker-Konfiguration, die unterstützten Kommandos und die Einbindung in die Anwendung. Anschließend wird ein bei der Kompilierung abgelehntes Ziel gezeigt. Eine Lebenszyklusabbildung benennt die Zuständigkeiten beim Start und Beenden. Der Text unterscheidet eine dauerhaft laufende eingehende Quelle von einer ausgehenden Reaktion auf ein angenommenes Ereignis.
