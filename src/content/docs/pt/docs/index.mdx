<p class="docs-lead">Compreenda o comportamento. Crie uma funcionalidade. Verifique o resultado.</p>

[Conceitos fundamentais](/learn/), [Configurar o agente](/getting-started/) e [Recursos](/resources/) contêm orientações existentes. Os restantes destinos abaixo contêm planos de páginas que descrevem as explicações, os exemplos e as figuras a criar. Para consultar as instruções disponíveis, Recursos inclui ligações para orientações sobre sintaxe, CLI, armazenamento, testes e autorização.

Esta página orientará os leitores por um primeiro percurso curto, guias de tarefas independentes, explicações mais aprofundadas e uma referência previsível. Usará um mapa de leitura com ligações para indicar onde se enquadra cada pergunta. O tutorial acompanhará uma funcionalidade de loja, desde a especificação até ao comportamento testado do backend e a uma interface que pode ser chamada; não exigirá um curso de Haskell. Os exemplos e as figuras apoiarão o artigo quando explicarem uma ideia específica.
