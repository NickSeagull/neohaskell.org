As quatro páginas em [Comece aqui](../introduction/), [Configure o seu agente](../getting-started/) e [Recursos](../resources/) contêm orientações existentes. Os restantes destinos contêm planos de páginas que descrevem as explicações, os exemplos e as figuras a criar. A página de recursos liga a instruções atualmente disponíveis a montante.

A primeira jornada começa pela avaliação do programador e pelas questões de negócio. Explica por que razão os eventos preservam o significado de uma alteração e, em seguida, introduz comandos e consultas antes de os ligar num modelo de eventos. Depois, verificará o projeto inicial Counter fornecido com NeoHaskell. O tutorial criará uma loja de canecas de cerâmica nesse projeto, desde a primeira decisão até a uma interface HTTP testada. Cada guia de tarefas responderá a uma questão independente; os conceitos explicarão o design e as páginas de referência definirão a sintaxe e os contratos da API.
