## Plano da página

Esta página abordará parâmetros de tipos, registos, construtores, tipos soma, sinónimos de tipos, restrições de classes, tipos associados, aplicação visível de tipos e notação de derivação, tal como aparecem no código das aplicações. Um registo de comando e uma soma de eventos, compactos e anotados, ligarão a grafia do código-fonte aos valores possíveis. Distinguirá definições escritas à mão de auxiliares de derivação, com ligações para os contratos do framework em vez de ensinar metaprogramação ou reproduzir um manual da linguagem Haskell.
