## Plano da página

Esta página apresentará a sintaxe mínima necessária para acompanhar [Implementar a funcionalidade](/tutorial/first-feature/), sem exigir um curso de Haskell. Abrangerá módulos, valores, funções, tipos, correspondência de padrões, pipelines e blocos do, com exemplos pequenos verificados e resultados adjacentes. As associações locais usarão instruções let dentro de blocos do. Os exemplos de diagnóstico explicarão um erro comum e a sua correção. Ligações estáveis para secções permitirão que outros guias apontem diretamente para a construção necessária, enquanto a [Biblioteca Core](/reference/core/) descreverá as operações disponíveis.
