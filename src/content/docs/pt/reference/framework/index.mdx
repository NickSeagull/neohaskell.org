## Plano da página

Esta página relacionará entidades, comandos, decisões, eventos, consultas e composição da aplicação com as definições verificadas do framework. Cada entrada indicará a sua responsabilidade, os tipos relevantes, os campos obrigatórios e o exemplo completo mais pequeno que demonstre o seu papel. Uma figura compacta das relações mostrará como as peças se ligam, mantendo separados os registos de eventos e os resultados das consultas. As entradas incluirão ligações para [Conceitos fundamentais](/learn/) para explicações e para o [tutorial da primeira funcionalidade](/tutorial/first-feature/) para ver a utilização numa aplicação.
