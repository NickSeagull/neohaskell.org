## Plano da página <a id="page-plan" />

Esta página será a entrada para `Core` e uma referência rápida a tipos escalares: `Text`, tipos numéricos, `Bool`, `Unit` e `Uuid`. Distinguirá um tipo reexportado das operações de módulos qualificados. Uma pequena tabela de tipos e módulos encaminhará os leitores para contentores, resultados opcionais, tarefas e JSON. Assinaturas selecionadas mostrarão as convenções de conversão de texto e aritmética; os módulos avançados de concorrência e implementação ficarão como ligações para o código-fonte, em vez de ocuparem a barra lateral.
