## Plano da página

Esta página organizará os tipos e as operações Core mais comuns para quem cria aplicações. Cada entrada documentada terá uma assinatura, as entradas e saídas, um exemplo mínimo verificado, os casos-limite relevantes e uma ligação à definição canónica. Tabelas compactas ajudarão a comparar operações relacionadas; pares de código-fonte e resultados tornarão o comportamento explícito. A página incluirá uma ligação para [Fundamentos da linguagem](/reference/language/) sobre sintaxe e continuará a ser uma visão geral até que o conteúdo real justifique páginas de referência separadas, evitando páginas vazias para cada função.
