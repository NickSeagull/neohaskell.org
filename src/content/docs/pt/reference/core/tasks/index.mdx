## Plano da página

Esta página documentará `Task error value`, a construção de resultados bem-sucedidos, as falhas tipadas, o encadeamento, a notação `do`, a recuperação e a conversão para `Result`. Uma sequência curta mostrará que passo é executado e o que acontece depois de uma falha; uma tabela de assinaturas separará a construção de uma tarefa da sua execução no limite do programa. A limpeza e o cancelamento serão tópicos avançados ligados, com `Decision` explicitamente associado como contrato distinto para a aceitação ou rejeição de negócio.
