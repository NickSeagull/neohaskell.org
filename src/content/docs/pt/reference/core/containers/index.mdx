## Plano da página <a id="page-plan" />

Esta página agrupará as operações de `Array` e `Map` por construção, pesquisa, transformação, combinação e redução de dados. Tabelas de assinaturas explicitarão a ordem dos argumentos das pipelines, enquanto pequenos exemplos mostrarão um índice ou uma chave inexistentes, coleções vazias e um total simples. As operações relacionadas terão ligações internas na mesma página, com definições canónicas e casos limite ligados, em vez de uma rota separada para cada função exportada.
