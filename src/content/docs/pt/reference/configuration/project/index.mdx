## Plano da página

Esta página descreverá o nome, a versão, a versão de neo, o tipo de projeto, os metadados, a licença predefinida e as entradas de dependências de `neo.json`, distinguindo-os das definições de ambiente de execução. Um manifesto completo compacto e uma tabela de campos explicarão a gestão dos ficheiros Cabal e Nix gerados e ligarão aos formatos de dependência suportados. Uma secção sobre seleção de código-fonte identificará a substituição local do framework como definição avançada de desenvolvimento, mantendo explícita a compatibilidade das versões sem equiparar main a uma versão publicada.
