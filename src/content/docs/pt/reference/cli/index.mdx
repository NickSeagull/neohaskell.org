## Plano da página

Esta página documentará a Neo CLI com base numa revisão identificada, incluindo comandos para criar projetos, compilar, executar e testar. Cada entrada indicará onde executar o comando, os argumentos obrigatórios, as opções, o resultado esperado ou o código de saída e uma etapa concreta de recuperação. As invocações copiáveis serão acompanhadas de resultados verificados e de alternativas para outras plataformas apenas quando forem diferentes. [Configurar o agente](/getting-started/) apresentará o percurso completo da primeira execução; esta página servirá para consultas rápidas durante o trabalho posterior.
