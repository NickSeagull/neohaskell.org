## Plano da página

Esta página começará com o projeto funcional de [Configurar o agente](/getting-started/) e a especificação de [Modelar a primeira funcionalidade](/tutorial/). Mostrará como atribuir essa tarefa delimitada a um agente, inspecionar os ficheiros alterados e ligar um comportamento de backend a uma interface que pode ser chamada. Excertos de código-fonte focados e uma árvore de ficheiros anotada explicarão cada parte, com ligações diretas para [Fundamentos da linguagem](/reference/language/) quando for necessária sintaxe. O resultado conduzirá a [Testar o comportamento](/tutorial/test-behavior/).
