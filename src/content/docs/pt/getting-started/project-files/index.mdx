## Plano da página <a id="page-plan" />

Esta página associará o projeto gerado às decisões que o leitor e o agente têm de tomar. Localizará o modelo de `Event` da aplicação, a funcionalidade `Counter`, as decisões dos comandos, os eventos, as atualizações das entidades, as consultas e os testes. Depois, distinguirá esses ficheiros escritos pela equipa dos ficheiros de compilação regenerados a partir de `neo.json`. Um mapa compacto de diretórios relacionará cada localização com a sua finalidade. Os leitores aprenderão onde inspecionar uma alteração proposta sem estudar todos os módulos do framework.
