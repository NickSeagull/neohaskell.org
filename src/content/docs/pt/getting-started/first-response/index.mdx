## Plano da página

Esta página verificará o projeto inicial em execução, criando um `Counter`, usando o identificador da entidade devolvido num comando de alteração e lendo o valor resultante através da respetiva consulta. Explicará o payload do pedido, o envelope da resposta e o possível atraso até a projeção refletir a alteração. Uma entrada rejeitada permitirá distinguir uma resposta de validação funcional de uma falha de configuração. O cenário `Counter` mantido no projeto dará uma verificação repetível antes de os leitores começarem o tutorial da loja.
