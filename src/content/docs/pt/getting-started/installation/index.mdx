## Plano da página

Esta página identificará o ambiente suportado e instalará a CLI Neo com as ferramentas Nix e Git necessárias. Distinguirá a instalação da CLI da obtenção do compilador e das bibliotecas geridos pelo projeto, explicará o ambiente de editor opcional e mostrará como verificar as ferramentas instaladas. As instruções corresponderão a uma versão e plataforma verificadas, com explicações sobre as opções de cache binária que afetam a primeira compilação e ligações diretas para resolver problemas de configuração.
