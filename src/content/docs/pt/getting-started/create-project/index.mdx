## Plano da página

Esta página criará uma aplicação com nome através da CLI Neo, explicará onde executar o comando e identificará o projeto inicial `Counter` que aparece no novo diretório. Mostrará o percurso interativo habitual e um comando reproduzível para um agente, explicará o commit Git inicial e a versão fixa do framework e confirmará o projeto gerado antes de prosseguir. A criação de bibliotecas e o conjunto completo de opções da CLI ficarão na referência.
