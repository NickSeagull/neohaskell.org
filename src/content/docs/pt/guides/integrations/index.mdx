## Plano da página <a id="page-plan" />

Esta página ligará um evento aceite a um processador de saída tipado, fará uma chamada HTTP e transformará a resposta do fornecedor num comando de seguimento. Os percursos de sucesso e de falha mostrarão a fronteira entre uma decisão pura e um efeito externo. O exemplo usará uma chave de idempotência e explicará as definições de repetição separadas para HTTP e para o distribuidor, sem prometer entrega duradoura ou execução exatamente uma vez.
