## Plano da página <a id="page-plan" />

Esta página reunirá um exemplo de implementação reproduzível para uma aplicação e uma revisão fixadas do framework, indicando o executável, a configuração de execução, a base de dados e os caminhos dos ficheiros. Uma figura de implementação distinguirá os serviços persistentes do processo da aplicação e mostrará a fronteira HTTP pública. A verificação abrangerá o arranque, um comando aceite, uma consulta e um reinício, identificando ainda o alojamento e a supervisão de processos específicos do ambiente que o repositório não fornece.
