## Plano da página

Esta página aplicará uma verificação de acesso ao nível da consulta antes de obter dados e uma verificação de titularidade para resultados individuais. Comparará a mesma consulta para um proprietário, outro utilizador autenticado e alguém anónimo, incluindo um resultado paginado. Uma pequena tabela de decisões mostrará onde é executada cada verificação para que o leitor possa proteger os dados devolvidos sem presumir que as permissões dos comandos protegem automaticamente os pontos de acesso das consultas.
