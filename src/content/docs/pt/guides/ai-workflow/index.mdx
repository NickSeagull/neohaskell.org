## Plano da página

Esta página transformará um pedido de comportamento numa tarefa delimitada para o agente, indicando a revisão do projeto, o código-fonte relevante, os casos de aceitação e as alterações permitidas. Apresentará um pedido reutilizável e uma diferença de código focada, depois comparará o resultado pedido com os testes das decisões e as evidências da interface. Um exemplo de correção distinguirá uma compilação bem-sucedida de um comportamento correto e encaminhará o agente para as orientações mantidas para a revisão fixada do framework.
