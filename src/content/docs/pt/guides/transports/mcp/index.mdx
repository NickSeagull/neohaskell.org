## Plano da página <a id="page-plan" />

Esta página registará o transporte MCP stdio para uma funcionalidade existente e mostrará a inicialização, a descoberta de ferramentas, uma chamada de comando e a leitura de um recurso de consulta. Uma transcrição compacta do protocolo distinguirá os comandos como ferramentas das consultas como recursos. O exemplo explicará a propriedade do processo e o contexto de execução de confiança para que os leitores não confundam este protocolo local com um serviço HTTP remoto autenticado.
