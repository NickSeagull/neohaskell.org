<p class="docs-lead">Comprende el comportamiento. Crea una funcionalidad. Comprueba el resultado.</p>

[Conceptos básicos](/learn/), [Configura tu agente](/getting-started/) y [Recursos](/resources/) contienen orientación disponible. El resto de destinos de abajo contiene planes de páginas con las explicaciones, los ejemplos y las figuras que se redactarán. Para consultar las instrucciones disponibles ahora, Recursos enlaza a la sintaxis, la CLI, el almacenamiento, las pruebas y la autorización de los proyectos originales.

Esta página orientará a los lectores mediante un primer recorrido breve, guías prácticas independientes, explicaciones más detalladas y una referencia predecible. Un mapa de lectura con enlaces mostrará dónde encontrar cada respuesta. El tutorial seguirá una funcionalidad de tienda, desde su especificación hasta un comportamiento de backend probado y una interfaz invocable; no requerirá un curso de Haskell. Los ejemplos y las figuras acompañarán al artículo cuando ayuden a explicar una idea concreta.
