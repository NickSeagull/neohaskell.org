<p class="docs-lead">Ejecuta un primer proyecto. Crea una tienda de tazas. Encuentra la tarea o API que necesitas.</p>

[Conceptos básicos](/learn/), [Configura tu agente](/getting-started/) y [Recursos](/resources/) contienen guías disponibles. Las demás páginas describen las explicaciones, los ejemplos y las figuras que se escribirán. Recursos enlaza a las instrucciones disponibles actualmente en el repositorio original.

El primer recorrido comprobará el proyecto inicial Counter incluido con NeoHaskell. Después, el tutorial creará una tienda de tazas de cerámica en ese proyecto, desde su primera decisión hasta una interfaz HTTP probada. Cada guía de tareas responderá a una pregunta independiente; los conceptos explicarán el diseño y las páginas de referencia definirán la sintaxis y los contratos de la API.
