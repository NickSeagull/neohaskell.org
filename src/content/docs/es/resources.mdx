NeoHaskell es un lenguaje de programación concebido desde el principio para la IA y en desarrollo activo. Empieza con un comportamiento sencillo que puedas describir y comprobar. El proyecto inicial Counter te ofrece una aplicación concreta para inspeccionar antes de ampliarla con tu agente.

## Empieza a crear

Aprende los [conceptos básicos](/learn/) antes de seguir la guía [Configura tu agente](/getting-started/). Puedes leer los conceptos sin instalar nada.

- [Requisitos previos e instalación de la CLI](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/README.md#prerequisites): las herramientas necesarias para crear y ejecutar una aplicación.
- [Crea y ejecuta un proyecto](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/project-and-cli.md): los pasos para crear, compilar y ejecutar un proyecto.
- [Guía rápida del proyecto inicial Counter](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/starter/README.md#quickstart): la aplicación que aparece en el fragmento de código de la página de inicio, con un flujo HTTP e instrucciones de pruebas.

## Lenguaje y framework

La documentación siguiente se publica en el repositorio de NeoHaskell para quienes crean aplicaciones y agentes de programación. Describe una versión inspeccionada del código fuente; si tu proyecto fija otra versión, usa la documentación correspondiente a esa versión.

- [Sintaxis y Core](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/syntax-and-core.md): un módulo completo, tipos, operadores y convenciones de aplicaciones.
- [Instrucciones para aplicaciones por tarea](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/index.md): comandos, eventos, consultas, configuración, transportes e integraciones.
- [Pruebas](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/testing.md): pruebas de decisiones, escenarios HTTP y comprobación de cambios.
- [Almacenamiento](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/storage.md): historial de eventos, almacenamiento de consultas y persistencia.

## Antes de confiar en una aplicación

El proyecto inicial usa un almacén de eventos en memoria de forma predeterminada. Los eventos registrados desaparecen cuando termina ese proceso. El historial persistente de eventos y el almacenamiento persistente de consultas son opciones de configuración independientes. Si necesitas conservar los datos tras un reinicio, sigue la guía de almacenamiento anterior.

Tu aplicación también debe definir sus propias reglas de acceso. Lee las [instrucciones de autorización](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/authorization.md) y prueba los casos permitidos y rechazados. Un agente de IA ayuda a implementar estas reglas, pero no decide las políticas de la aplicación en tiempo de ejecución.

El código fuente publicado y las versiones te permiten inspeccionar lo que está disponible. Por sí solos, no garantizan que tu aplicación esté lista para producción.

La [licencia del código fuente del framework](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/LICENSE) está disponible junto al código. Consulta la licencia de cada herramienta al elegir dependencias.

## Sigue los cambios y pide ayuda

- [Historial de versiones de la CLI y del framework](https://github.com/neohaskell/NeoHaskell/releases): cambios en las herramientas de aplicación y el framework. La [versión 0.17.1](https://github.com/neohaskell/NeoHaskell/releases/tag/neo-v0.17.1), publicada el 6 de noviembre de 2026, añade almacenamiento de archivos generados asignados a sus propietarios.
- [Versiones de las skills del agente](https://github.com/neohaskell/skills/releases): cambios en la colección independiente de instrucciones para Claude Code y Codex.
- [Pregunta a la comunidad en Discord](https://discord.com/invite/wDj3UYzec8): comparte lo que intentas crear y dónde te has atascado.
- [Consulta los problemas notificados](https://github.com/neohaskell/NeoHaskell/issues) o [lee la guía para contribuir](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/CONTRIBUTING.md): sigue los problemas conocidos y consulta el proceso de colaboración del proyecto.
