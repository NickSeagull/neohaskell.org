NeoHaskell es un lenguaje de programación diseñado para la IA y en desarrollo activo. Empieza por un comportamiento pequeño que puedas describir y comprobar. El proyecto inicial Counter te ofrece una aplicación concreta que inspeccionar antes de ampliarla con tu agente.

## Empieza a construir

Empieza por [El trabajo que hay detrás del código](/introduction/) para recorrer el proceso de diseño antes de [Configurar tu agente](/getting-started/). La secuencia de diseño no requiere instalación.

- [Requisitos previos e instalación de la CLI](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/README.md#prerequisites): las herramientas necesarias para crear y ejecutar una aplicación.
- [Crea y ejecuta un proyecto](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/project-and-cli.md): los pasos para crear, compilar y ejecutar un proyecto.
- [Guía de inicio rápido del proyecto inicial Counter](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/starter/README.md#quickstart): la aplicación que aparece en el fragmento de código de la página de inicio, con un flujo de trabajo HTTP e instrucciones para las pruebas.

## Lenguaje y framework

Las siguientes guías están publicadas en el repositorio de NeoHaskell para quienes crean aplicaciones y sus agentes de programación. Describen una revisión del código fuente inspeccionada; usa la revisión correspondiente si tu proyecto fija otra versión.

- [Sintaxis y Core](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/syntax-and-core.md): un módulo completo, tipos, operadores y convenciones de aplicaciones.
- [Guía de aplicaciones por tarea](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/index.md): comandos, eventos, consultas, configuración, transportes e integraciones.
- [Pruebas](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/testing.md): pruebas de decisiones, escenarios HTTP y comprobación de cambios.
- [Almacenamiento](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/storage.md): historial de eventos, almacenamiento de consultas y persistencia.

## Antes de confiar en una aplicación

El almacén de eventos del proyecto inicial está en memoria de forma predeterminada. Sus eventos registrados desaparecen cuando termina el proceso. El historial persistente de eventos y el almacenamiento persistente de consultas son opciones de configuración separadas; cuando necesites que los datos sobrevivan a un reinicio, sigue la guía de almacenamiento anterior.

Tu aplicación también define sus propias reglas de acceso. Lee la [guía de autorización](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/authorization.md) y prueba los casos permitidos y rechazados. Un agente de IA ayuda a implementar estas reglas, pero no decide las políticas de tu aplicación durante la ejecución.

El código fuente publicado y las versiones permiten inspeccionar lo que está disponible. Por sí solos, no demuestran que tu aplicación esté lista para producción.

La [licencia del código fuente del framework](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/LICENSE) está disponible junto al código. Comprueba la licencia de cada herramienta cuando elijas dependencias.

La [versión 0.17.1](https://github.com/neohaskell/NeoHaskell/releases/tag/neo-v0.17.1), publicada el 6 de noviembre de 2026, añade almacenamiento de archivos generados propiedad de un usuario.
- [Versiones de las skills de agente](https://github.com/neohaskell/skills/releases): cambios en la colección independiente de instrucciones para Claude Code y Codex.
- [Pregunta a la comunidad en Discord](https://discord.com/invite/wDj3UYzec8): comparte lo que intentas construir y dónde te has quedado atascado.
- [Consulta los problemas notificados](https://github.com/neohaskell/NeoHaskell/issues) o [lee la guía de contribución](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/CONTRIBUTING.md): consulta los problemas conocidos y el flujo de trabajo para contribuir al proyecto.

## Plan de la página

Esta página conservará las guías sustanciales existentes sobre configuración, código fuente, almacenamiento, autorización, licencias, versiones y comunidad, y enlazará destinos de referencia más precisos. Sus enlaces al repositorio original seguirán vinculados a la revisión que describen; la investigación sobre la rama principal actual se mantendrá separada de las versiones publicadas y las versiones de las skills de agente. Se podrá añadir una tabla compacta de compatibilidad cuando se verifiquen las versiones; no se inventará ningún compromiso de asistencia ni afirmación de verificación en tiempo de ejecución.
