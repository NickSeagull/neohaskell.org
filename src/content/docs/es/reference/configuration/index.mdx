## Plan de la página <a id="page-plan" />

Esta página definirá los campos de `Config`, la documentación obligatoria, los valores predeterminados, los valores requeridos, los nombres de variables de entorno, las opciones de comandos, los registros anidados y la ocultación de secretos. Una tabla de precedencia mostrará, en este orden, la línea de comandos, el entorno del proceso, dotenv y el valor predeterminado, con un ejemplo hipotético de puerto. Explicará la carga durante el inicio, las fábricas de configuración, el orden de registro y las opciones separadas de almacén; enlazará la configuración específica de proveedores con las guías de tareas y reservará una página propia para la configuración de compilación de `neo.json`.
