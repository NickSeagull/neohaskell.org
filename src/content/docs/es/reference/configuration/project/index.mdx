## Plan de la página

Esta página describirá el nombre, la versión, neo-version, el tipo de proyecto, los metadatos, la licencia predeterminada y las dependencias de `neo.json`, y los distinguirá de la configuración del entorno en tiempo de ejecución. Un manifiesto completo breve y una tabla de campos explicarán qué archivos Cabal y Nix se generan y enlazarán a los formatos de dependencia admitidos. Una sección sobre la selección del código fuente identificará la sustitución local del framework como un ajuste avanzado de desarrollo. La compatibilidad de versiones seguirá siendo explícita y no se equiparará main con una versión publicada.
