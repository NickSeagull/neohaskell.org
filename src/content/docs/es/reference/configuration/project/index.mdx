## Plan de la página <a id="page-plan" />

Esta página describirá los campos name, version, neo-version, project type, metadata y license default de `neo.json`, así como las dependencias, y los distinguirá de la configuración del entorno en tiempo de ejecución. Un manifiesto completo pequeño y una tabla de campos explicarán qué herramientas administran los archivos Cabal y Nix generados y enlazarán a los formatos de dependencia compatibles. Una sección sobre la selección del código fuente identificará la modificación local del framework como una opción avanzada de desarrollo. La compatibilidad de versiones publicadas quedará explícita, sin equiparar la rama main a una versión publicada.
