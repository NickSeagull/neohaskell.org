## Plan de la página <a id="page-plan" />

Esta página relacionará `EventModel`, `FeatureAction`, `chapter`, `slice`, `entity`, `command`, `produces`, `query` y `readsFrom` con la feature `Counter` definida en el mismo archivo. Un diagrama compacto de relaciones mostrará la declaración, la validación y el ensamblaje en tiempo de ejecución, sin mezclar el historial de eventos con las filas de `query`. Las firmas de los constructores y las restricciones de orden aparecerán junto al modelo. El ensamblaje directo de `Service.Application` se enlazará en una sección avanzada, conservando su condición de API pública y dando prioridad a la arquitectura actual del proyecto inicial.
