## Plan de la página

Esta página relacionará `EventModel`, `FeatureAction`, `chapter`, `slice`, `entity`, `command`, `produces`, `query` y `readsFrom` con la función `Counter` definida en el código fuente. Un diagrama breve de relaciones mostrará la declaración, la validación y el montaje en tiempo de ejecución sin mezclar el historial de eventos con las filas de `query`. Las firmas y las restricciones de orden de los creadores aparecerán junto al modelo. El montaje directo de `Service.Application` tendrá un enlace a una sección avanzada, conservando su condición de API pública y dando prioridad a la arquitectura actual del proyecto inicial.
