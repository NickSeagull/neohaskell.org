## Plan de la página <a id="page-plan" />

Esta página recopilará fallos observables como un espacio de trabajo ausente, un `neo.json` no válido, requisitos previos ausentes, dependencias no válidas, guía del framework no disponible y procesos secundarios fallidos. Las entradas relacionarán el código y la ubicación del diagnóstico con la corrección más pequeña y una comprobación de recuperación. Un diagnóstico anotado explicará los intervalos del código fuente y la salida conservada del proceso secundario. Los mensajes definidos por el código fuente se distinguirán de las transcripciones de ejecuciones reales, con enlaces a las opciones de CLI y a los canales para informar de problemas cuando haga falta más información para corregirlos.
