## Plan de la página

Esta página recogerá fallos observables, como un espacio de trabajo que falta, un `neo.json` no válido, requisitos previos ausentes, dependencias no válidas, instrucciones del framework no disponibles y procesos secundarios fallidos. Cada entrada relacionará el código y la ubicación del diagnóstico con la corrección más sencilla y una comprobación de recuperación. Un diagnóstico anotado explicará los fragmentos de código fuente y la salida conservada del proceso secundario. Los mensajes definidos en el código fuente se distinguirán de las transcripciones de ejecución y se incluirán enlaces a las opciones de la CLI y a los canales de la comunidad cuando haga falta más información para corregir el problema.
