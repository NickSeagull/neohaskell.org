## Plan de la página

Esta página facilitará la lectura del código fuente habitual mediante módulos e importaciones, aplicación de funciones, firmas, cadenas de operaciones, acceso a registros, condicionales, expresiones `case` y bloques `do`. Cada construcción tendrá un ejemplo breve de código y resultado, con anclas estables para los enlaces de los tutoriales. Explicará las operaciones cualificadas y las extensiones de lenguaje generadas, usará instrucciones `let` dentro de bloques `do` para las vinculaciones locales y enlazará las definiciones de tipos con la página siguiente.
