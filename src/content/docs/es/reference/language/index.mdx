## Plan de la página <a id="page-plan" />

Esta página facilitará la lectura del código habitual: módulos e imports, aplicación de funciones, firmas, pipelines, acceso a registros, condicionales, expresiones `case` y bloques `do`. Cada construcción tendrá un ejemplo compacto de código fuente y resultado, con anclas estables para los enlaces de tutoriales. Explicará las operaciones cualificadas y las extensiones del lenguaje generadas, usará instrucciones `let` dentro de bloques `do` para las vinculaciones locales y enlazará las definiciones de tipos con la página siguiente.
