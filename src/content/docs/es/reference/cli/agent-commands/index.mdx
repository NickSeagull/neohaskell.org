## Plan de la página <a id="page-plan" />

Esta página documentará la selección de herramientas de `neo skills setup`, el filtrado de skills y las opciones `all-tools`, `force`, `dry-run` y `refresh`, además de `neo guidance retry`. Distinguirá las skills de flujo de trabajo compartidas de la guía del framework correspondiente al código fuente, sincronizada por `build`, `run` y `test`. Una tabla concisa de destinos y opciones explicará qué se escribe y qué se conserva. La guía de incorporación de agentes más extensa se quedará en su propia página y no se dará a entender que existe un comando genérico para generar features.
