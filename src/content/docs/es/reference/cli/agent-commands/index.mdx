## Plan de la página

Esta página documentará la selección de herramientas con `neo skills setup` y las opciones de filtrado de skills, `all-tools`, `force`, `dry-run` y `refresh`, además de `neo guidance retry`. Distinguirá las skills de flujo de trabajo compartido de las instrucciones del framework sincronizadas por `build`, `run` y `test`, que se adaptan al código fuente. Una tabla breve de destinos y opciones explicará qué se escribe y qué se conserva. La guía tendrá la introducción completa para agentes y no dará a entender que existe un comando genérico para generar funciones.
