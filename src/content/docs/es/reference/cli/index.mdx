## Plan de la página

Esta página documentará `neo new`, `build`, `run`, `test` y `lock`, con la invocación, el directorio de trabajo, las entradas, las opciones y los resultados definidos por el código fuente en una tabla breve. Incluirá anclas para las opciones globales verbose y CI, el modo de vigilancia, la creación de bibliotecas y la comprobación de `build` sobre archivos protegidos por `lock`. Enlazará las herramientas de modelado y los comandos de configuración del agente a sus propias páginas y dejará la instalación y el primer inicio completo para la guía de inicio.
