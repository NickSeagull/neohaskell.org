## Plan de la página

Esta página documentará la Neo CLI para una revisión concreta, incluidos los comandos para crear proyectos, compilar, ejecutar y probar. Cada entrada indicará dónde ejecutar el comando, los argumentos obligatorios, las opciones, el resultado esperado o el código de salida y un paso concreto para recuperarse de un error. Las invocaciones copiables irán acompañadas de resultados verificados y de alternativas por plataforma solo cuando haya diferencias. [Configura tu agente](/getting-started/) cubrirá todo el proceso del primer inicio; esta página servirá como referencia rápida para el trabajo posterior.
