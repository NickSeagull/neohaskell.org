## Plan de la página

Esta página tratará la codificación y decodificación de `Json`, las instancias de `FromJSON` y `ToJSON`, las entradas no válidas representadas como `Result` y el contrato independiente `Schema` para describir datos de API. Un registro breve irá acompañado de su estructura JSON y una entrada no válida. Se distinguirán la serialización, la validación y las descripciones de API generadas. Las funciones auxiliares del analizador se agruparán en tablas con anclas y los detalles de los cuerpos de comando enlazarán a la referencia de transporte.
