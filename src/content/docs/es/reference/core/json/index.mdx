## Plan de la página

Esta página tratará la codificación y decodificación de `Json`, las instancias `FromJSON` y `ToJSON`, las entradas mal formadas como `Result` y el contrato `Schema`, que se usa por separado para describir los datos de una API. Un registro pequeño aparecerá junto a su estructura JSON y una entrada no válida. La página distinguirá la serialización de la validación y de las descripciones de API generadas, reunirá las funciones auxiliares del analizador en tablas con anclas y enlazará los detalles de los cuerpos de comandos con la referencia de transportes.
