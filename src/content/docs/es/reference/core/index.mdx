## Plan de la página

Esta página organizará los tipos y las operaciones de Core que encuentran con más frecuencia quienes crean aplicaciones. Cada entrada documentada tendrá una firma, sus valores de entrada y salida, un ejemplo mínimo verificado, los casos límite pertinentes y un enlace a la definición canónica. Las tablas compactas ayudarán a comparar operaciones relacionadas; los pares de código fuente y resultado harán explícito el comportamiento. La página enlazará a [Conceptos esenciales del lenguaje](/reference/language/) para consultar la sintaxis y seguirá siendo una guía general hasta que el contenido real justifique páginas de referencia separadas, sin crear páginas vacías para cada función.
