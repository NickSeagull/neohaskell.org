## Plan de la página

Esta página será el punto de entrada a `Core` y una referencia rápida de tipos escalares: `Text`, tipos numéricos, `Bool`, `Unit` y `Uuid`. También explicará la diferencia entre un tipo reexportado y las operaciones de un módulo cualificado. Una tabla breve de tipos y módulos remitirá a contenedores, resultados opcionales, tareas y JSON. Algunas firmas seleccionadas mostrarán la conversión de texto y las convenciones aritméticas; los módulos avanzados de concurrencia e implementación se enlazarán como código fuente, sin ocupar la barra lateral.
