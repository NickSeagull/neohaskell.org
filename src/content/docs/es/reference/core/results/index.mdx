## Plan de la página

Esta página comparará `Nothing` y `Just` con `Err` y `Ok` y mostrará cuándo una ausencia no necesita explicación y cuándo se requiere un error tipado. Firmas breves y casos paralelos cubrirán `map`, `andThen`, `withDefault`, `mapError` y las conversiones entre ambos contenedores. Un ejemplo de análisis sintáctico o búsqueda conservará el error hasta que quien llama lo gestione expresamente y enlazará el tratamiento de errores con efectos a `Task`.
