## Plan de la página

Esta página documentará `Task error value`, la creación de tareas correctas, los fallos tipados, el encadenamiento, la notación `do`, la recuperación y la conversión a `Result`. Una secuencia breve mostrará qué paso se ejecuta y qué ocurre tras un fallo; una tabla de firmas distinguirá la creación de una tarea de su ejecución en el límite del programa. Las operaciones de limpieza y cancelación se enlazarán como temas avanzados, y `Decision` tendrá un enlace cruzado explícito como contrato separado para la aceptación y el rechazo de negocio.
