## Plan de la página

Esta página relacionará los problemas habituales del primer inicio con el paso que ha fallado y la corrección más sencilla: faltan herramientas, el directorio de trabajo no es el correcto, el nombre del proyecto ya existe, la configuración del proyecto no es válida, las dependencias no están disponibles o faltan las instrucciones del agente. Cada caso mostrará un diagnóstico verificado y la comprobación que confirma la recuperación. Se conservarán los archivos del lector, se explicará cómo identificar las versiones de la CLI y del framework y se enlazarán los errores más profundos del compilador o del entorno de ejecución con la referencia.
