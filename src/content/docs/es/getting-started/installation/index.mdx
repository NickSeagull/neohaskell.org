## Plan de la página

Esta página indicará el entorno compatible e instalará la CLI de Neo junto con Nix y Git, sus herramientas necesarias. Distinguirá la instalación de la CLI de la obtención del compilador y las bibliotecas administrados por el proyecto, explicará el entorno opcional para editores y mostrará cómo comprobar las herramientas instaladas. Las instrucciones corresponderán a una versión y plataforma verificadas, y explicarán las opciones de caché de binarios cuando afecten a la primera compilación, con enlaces directos para resolver problemas de configuración.
