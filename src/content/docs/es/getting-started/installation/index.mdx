## Plan de la página

Esta página indicará los entornos compatibles e instalará la CLI de Neo con las herramientas necesarias, Nix y Git. Distinguirá la instalación de la CLI de la obtención del compilador y las bibliotecas gestionados por el proyecto, explicará el entorno opcional para el editor y mostrará cómo comprobar las herramientas instaladas. Las instrucciones corresponderán a una versión y plataforma verificadas. Se explicarán las opciones de caché binaria cuando afecten a la primera compilación y se incluirán enlaces para resolver problemas de configuración.
