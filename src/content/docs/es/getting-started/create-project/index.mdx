## Plan de la página

Esta página creará una aplicación con nombre mediante la CLI de Neo, explicará dónde ejecutar el comando e identificará el proyecto inicial `Counter` que aparecerá en el nuevo directorio. Mostrará el proceso interactivo habitual y un comando reproducible para un agente, explicará el commit inicial de Git y la versión fijada del framework, y confirmará el proyecto generado antes de continuar. La creación de bibliotecas y todas las opciones de la CLI se tratarán en la referencia.
