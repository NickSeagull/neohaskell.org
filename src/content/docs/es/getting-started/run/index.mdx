## Plan de la página <a id="page-plan" />

Esta página compilará y ejecutará la aplicación `Counter` generada desde la raíz del proyecto, indicará la dirección HTTP local y explicará qué proceso debe seguir en ejecución mientras se envían solicitudes desde otro terminal. Distinguirá la descarga inicial de dependencias del inicio de la aplicación, mostrará cómo detener y reiniciar el proceso y explicará que el historial de eventos predeterminado en memoria desaparece cuando termina el proceso. El modo de observación se presentará después del primer inicio correcto.
