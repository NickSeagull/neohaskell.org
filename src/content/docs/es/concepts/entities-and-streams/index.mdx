## Plan de la página <a id="page-plan" />

Esta página explicará una entidad como el estado reconstruido a partir de un flujo de eventos identificado y como el límite dentro del cual un comando comprueba sus condiciones. Dos reservas de existencias en competencia ilustrarán una decisión obsoleta, un conflicto al añadir eventos y la evaluación con el estado actualizado. Un diagrama de secuencia con dos carriles mantendrá separados los historiales del carrito y de las existencias. Explicará este límite sin prometer una transacción atómica entre ambas entidades.
