## Plan de la página

Esta página explicará cómo un modelo `Event` agrupa el comportamiento de una aplicación en features, capítulos y slices, y por qué cada slice tiene una responsabilidad concreta. Un árbol anotado de la feature `Counter` conectará un slice de comando y uno de consulta con los eventos declarados. Contrapondrá la organización de una historia a la aplicación de los límites de una entidad y enlazará al tutorial para la implementación y a la referencia del framework para consultar el DSL.
