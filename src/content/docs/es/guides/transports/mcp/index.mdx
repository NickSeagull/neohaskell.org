## Plan de la página <a id="page-plan" />

Esta página registrará el transporte MCP por stdio para una feature existente y mostrará la inicialización, el descubrimiento de herramientas, una llamada de comando y la lectura de un recurso de consulta. Una transcripción breve del protocolo distinguirá los comandos, que son herramientas, de las consultas, que son recursos. El ejemplo explicará quién controla el proceso y el contexto de ejecución de confianza para que los lectores no confundan este protocolo local con un servicio HTTP remoto autenticado.
