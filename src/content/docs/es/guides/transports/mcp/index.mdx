## Plan de la página

Esta página registrará el transporte MCP por stdio para una función existente y mostrará la inicialización, el descubrimiento de herramientas, una llamada a un comando y la lectura de un recurso de consulta. Una transcripción breve del protocolo distinguirá los comandos como herramientas de las consultas como recursos. El ejemplo explicará quién controla el proceso y cuál es el contexto de ejecución de confianza para que los lectores no confundan este protocolo local con un servicio HTTP remoto autenticado.
