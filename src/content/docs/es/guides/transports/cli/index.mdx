## Plan de la página

Esta página registrará el transporte CLI de la aplicación e invocará un comando usando la entidad generada y el grupo de comandos. Relacionará las entradas del terminal con resultados correctos y rechazados y explicará cómo afecta el modo de salida a los scripts. El ejemplo indicará el límite de confianza del operador local y distinguirá esta interfaz de la aplicación de la CLI de desarrollo neo, que se usa para crear y gestionar un proyecto.
