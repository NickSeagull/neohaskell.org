## Plan de la página <a id="page-plan" />

Esta página registrará el transporte de CLI de la aplicación e invocará un comando usando la entidad generada y la agrupación de comandos. Relacionará las entradas del terminal con los resultados correctos y rechazados, y explicará cómo afecta el modo de salida a los scripts. El ejemplo indicará el límite de confianza del operador local y distinguirá esta interfaz de la aplicación de la CLI de desarrollo neo, que se usa para crear y administrar un proyecto.
