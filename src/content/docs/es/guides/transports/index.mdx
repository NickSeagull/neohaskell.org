## Plan de la página

Esta página explicará cómo se expone el comportamiento de la aplicación mediante HTTP y MCP, incluida la configuración y los contratos verificados para la versión documentada del framework. Mostrará un comando y una consulta mediante pares de solicitud/respuesta y llamadas equivalentes a herramientas, con un ejemplo de inspección de OpenAPI generado. Un diagrama pequeño de límites separará los transportes de las decisiones. Los ejemplos estáticos incluirán tanto el éxito como el rechazo; solo se planteará un componente de solicitud en directo cuando haya disponible un entorno de ejecución aislado compatible.
