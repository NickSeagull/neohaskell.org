## Plan de la página

Esta página distinguirá el historial de eventos del almacenamiento de consultas y mostrará cómo configurar las opciones de persistencia compatibles. Comparará un ejemplo en memoria con una configuración persistente y, después, comprobará qué datos sobreviven a un reinicio mediante comandos explícitos y resultados esperados. Un diagrama pequeño mantendrá separados el almacén de eventos y el estado de las consultas. Los ejemplos de fallos cubrirán la configuración ausente y el almacenamiento no disponible, con enlaces a [Historial y estado actual](/concepts/history-and-state/) para consultar el modelo subyacente y a [Recursos](/resources/#language-and-framework) para acceder a la orientación original existente.
