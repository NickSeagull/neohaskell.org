## Plan de la página

Esta página sustituirá la configuración en memoria del proyecto inicial por un almacén de eventos persistente y comprobará el mismo comportamiento registrado antes y después de un reinicio. Una comparación distinguirá la persistencia en disco de `SimpleEventStore` de la configuración de PostgreSQL, mientras que un diagrama separará el historial de eventos del estado derivado de las consultas. El ejemplo usará una configuración completa para la revisión seleccionada del framework y explicará qué rutas de almacenamiento o volúmenes de bases de datos deben conservarse.
