## Plan de la página

Esta página presentará una tarea de borrado de alcance limitado mediante el mecanismo de valores protegidos respaldado por PostgreSQL. Seguirá una solicitud autorizada del propietario, la eliminación de una referencia protegida, el comando resultante y un reintento explícito. Un diagrama del antes y el después distinguirá el registro de eventos conservado del contenido protegido que ya no está disponible. También explicará que las consultas y las copias externas deben considerarse por separado al comprobar el resultado esperado.
