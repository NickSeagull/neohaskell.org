## Plan de la página

Esta página explicará el flujo de almacenamiento de archivos documentado, incluida la propiedad, la configuración, la carga o generación y la recuperación. Seguirá un archivo mediante una pequeña figura de secuencia y mostrará ejemplos concretos de código fuente y solicitudes/respuestas. Incluirá juntos los casos de recuperación permitida, acceso denegado y archivo ausente para que el lector pueda comprobar el comportamiento esperado. La guía enlazará a [Controla el acceso](/guides/authorization/) para los permisos y a [Conserva los datos tras los reinicios](/guides/storage/) para la persistencia, sin tratar un archivo como un registro de evento.
