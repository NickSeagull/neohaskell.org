## Plan de la página <a id="page-plan" />

Esta página convertirá una petición de comportamiento en una tarea acotada para el agente, con la revisión del proyecto, el código fuente pertinente, los casos de aceptación y los cambios permitidos. Mostrará una petición reutilizable y una diferencia de código concreta; después comparará el resultado solicitado con las pruebas de decisiones y las evidencias de la interfaz. Un ejemplo de corrección distinguirá una compilación correcta de un comportamiento correcto y remitirá al agente a la guía mantenida para la versión fijada del framework.
