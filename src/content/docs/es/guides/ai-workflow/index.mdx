## Plan de la página

Esta página convertirá una solicitud de comportamiento en una tarea acotada para el agente, con la versión del proyecto, el código fuente pertinente, los casos de aceptación y los cambios permitidos. Mostrará una instrucción reutilizable y una diferencia de código concreta y, después, comparará el resultado solicitado con las pruebas de decisiones y las evidencias de la interfaz. Un ejemplo de corrección distinguirá que el compilador termine correctamente de que el comportamiento sea correcto y dirigirá al agente a las instrucciones actualizadas del framework fijado.
