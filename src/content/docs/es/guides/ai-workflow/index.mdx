## Plan de la página

Esta página describirá un proceso de colaboración repetible tras la [configuración](/getting-started/): aportar el contexto del modelo y el proyecto, solicitar un cambio, inspeccionar el resultado y corregir las discrepancias. Incluirá instrucciones copiables para tareas y correcciones, una diferencia de código acotada y ejemplos de pruebas de verificación útiles. Una breve comparación distinguirá una comprobación técnica superada de un comportamiento correcto de la aplicación. El [tutorial de la primera funcionalidad](/tutorial/first-feature/) aportará el ejemplo práctico; esta guía se centrará en reutilizar el proceso y recuperarse de errores, sin repetir la instalación.
