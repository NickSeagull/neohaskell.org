## Plan de la página

Esta página aplicará una comprobación de acceso a la consulta antes de obtener los datos y una comprobación de propiedad para cada resultado. Comparará la misma consulta para un propietario, otro usuario autenticado y alguien anónimo, e incluirá un resultado paginado. Una breve tabla de decisiones mostrará dónde se ejecuta cada comprobación para que el lector pueda proteger los datos devueltos sin suponer que los permisos de los comandos protegen automáticamente los endpoints de consulta.
