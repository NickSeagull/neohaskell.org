## Plan de la página

Esta página aplicará una comprobación de acceso a nivel de consulta antes de recuperar datos y una comprobación de propiedad para los resultados individuales. Comparará la misma consulta para un propietario, otro usuario autenticado y una persona anónima, incluido un resultado paginado. Una breve tabla de decisiones mostrará dónde se ejecuta cada comprobación para que el lector pueda proteger los datos devueltos sin dar por hecho que los permisos de los comandos protegen automáticamente los endpoints de consulta.
