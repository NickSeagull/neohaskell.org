## Plan de la página

Esta página conectará una aplicación a un emisor OIDC, configurará la audiencia esperada del token cuando sea necesario e inspeccionará las declaraciones del usuario disponibles para un comando. Una comparación de solicitudes abarcará un token válido, uno no válido y una llamada anónima. Un pequeño diagrama de límites separará la verificación de identidad del permiso para ejecutar comandos y de la conexión del usuario con un proveedor OAuth externo.
