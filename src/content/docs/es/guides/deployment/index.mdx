## Plan de la página

Esta página reunirá un ejemplo de despliegue reproducible para una aplicación y una revisión del framework fijadas, e indicará el ejecutable, la configuración en tiempo de ejecución, la base de datos y las rutas de archivos. Un diagrama de despliegue distinguirá los servicios persistentes del proceso de la aplicación y mostrará el límite HTTP público. Las comprobaciones cubrirán el inicio, un comando aceptado, una consulta y un reinicio, y señalarán qué tareas de alojamiento y supervisión de procesos dependen del entorno y no las proporciona el repositorio.
