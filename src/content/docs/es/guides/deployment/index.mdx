## Plan de la página

Esta página reunirá un ejemplo de despliegue reproducible para una aplicación y una versión fijada del framework, e indicará el ejecutable, la configuración en tiempo de ejecución, la base de datos y las rutas de archivos. Un diagrama de despliegue distinguirá los servicios persistentes del proceso de la aplicación y mostrará el límite HTTP público. Las comprobaciones abarcarán el inicio, un comando aceptado, una consulta y un reinicio. También se identificarán los servicios de alojamiento y la supervisión de procesos específicos del entorno que el repositorio no proporciona.
