NeoHaskell - язык программирования с ориентацией на ИИ, который активно разрабатывается. Начните с небольшого поведения, которое можно описать и проверить. Стартовый проект Counter даёт конкретное приложение для изучения перед его расширением с помощью агента.

## Начните создавать приложение <a id="start-building" />

Сначала прочитайте [Работа за кодом](../introduction/), чтобы разобраться в процессе проектирования, а затем перейдите к разделу [Настройте своего агента](../getting-started/). Для знакомства с проектированием установка не требуется.

- [Требования и установка CLI](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/README.md#prerequisites): инструменты для создания и запуска приложения.
- [Создание и запуск проекта](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/project-and-cli.md): последовательность создания, сборки и запуска проекта.
- [Краткое руководство по стартовому проекту Counter](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/starter/README.md#quickstart): приложение, показанное во фрагменте кода на главной странице, с инструкциями по работе через HTTP и тестированию.

## Язык и фреймворк <a id="language-and-framework" />

Следующие материалы в репозитории NeoHaskell предназначены разработчикам приложений и кодовым агентам. Они описывают изученную версию исходного кода; если проект закрепляет другую версию, используйте соответствующие ей материалы.

- [Синтаксис и Core](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/syntax-and-core.md): полный модуль, типы, операторы и соглашения для приложений.
- [Инструкции для приложений по задачам](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/index.md): команды, события, запросы, конфигурация, транспорты и интеграции.
- [Тестирование](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/testing.md): тесты решений, сценарии HTTP и проверка изменений.
- [Хранение данных](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/storage.md): история событий, хранение запросов и постоянное хранение.

## Прежде чем полагаться на приложение <a id="before-relying-on-an-application" />

По умолчанию в стартовом проекте используется хранилище событий в памяти. При завершении процесса записанные события исчезают. Постоянное хранение истории событий и запросов настраивается отдельно. Если данные должны переживать перезапуск, следуйте приведённому выше руководству по хранению данных.

В вашем приложении также должны быть правила доступа. Прочитайте [инструкции по авторизации](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/authorization.md) и проверьте разрешённые и отклонённые случаи. ИИ-агент помогает реализовать эти правила, но не принимает решения о политике приложения во время выполнения.

Опубликованные исходный код и выпуски позволяют изучить доступные возможности. Но сами по себе они не подтверждают готовность вашего приложения к производственной эксплуатации.

Рядом с кодом доступна [лицензия исходного кода фреймворка](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/LICENSE). При выборе зависимостей проверьте лицензию каждого инструмента.

## Следите за изменениями и получайте помощь <a id="follow-changes-and-get-help" />

- [История выпусков CLI и фреймворка](https://github.com/neohaskell/NeoHaskell/releases): изменения инструментов приложения и фреймворка. В [версии 0.17.1](https://github.com/neohaskell/NeoHaskell/releases/tag/neo-v0.17.1), опубликованной 6 ноября 2026 года, добавлено хранение файлов, созданных для конкретного владельца.
- [Выпуски навыков для агентов](https://github.com/neohaskell/skills/releases): изменения отдельного набора инструкций для Claude Code и Codex.
- [Спросите сообщество в Discord](https://discord.com/invite/wDj3UYzec8): расскажите, что пытаетесь создать и где столкнулись с трудностями.
- [Просмотрите зарегистрированные проблемы](https://github.com/neohaskell/NeoHaskell/issues) или [прочитайте руководство по участию в проекте](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/CONTRIBUTING.md): изучите известные проблемы и порядок участия в проекте.
