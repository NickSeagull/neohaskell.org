NeoHaskell - язык программирования с ориентацией на ИИ, который активно развивается. Начните с небольшого поведения, которое можно описать и проверить. Стартовый проект Counter поможет изучить готовое приложение, прежде чем расширять его с помощью ИИ-агента.

## Начните разработку

Изучите [основные понятия](/learn/), прежде чем переходить к разделу [Настройте ИИ-агента](/getting-started/). Для изучения понятий ничего устанавливать не нужно.

- [Системные требования и установка CLI](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/README.md#prerequisites): инструменты, необходимые для создания и запуска приложения.
- [Создание и запуск проекта](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/project-and-cli.md): последовательность создания, сборки и запуска проекта.
- [Краткое руководство по запуску стартового проекта Counter](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/neo/starter/README.md#quickstart): приложение, код которого показан на главной странице, с примером работы по HTTP и инструкциями по тестированию.

## Язык и фреймворк

Следующие материалы опубликованы в репозитории NeoHaskell для разработчиков приложений и ИИ-агентов. Они описывают проверенную версию исходного кода. Если в проекте зафиксирована другая версия, используйте соответствующие ей материалы.

- [Синтаксис и Core](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/syntax-and-core.md): полный модуль, типы, операторы и соглашения по приложениям.
- [Руководства по задачам приложения](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/index.md): команды, события, запросы, конфигурация, транспорты и интеграции.
- [Тестирование](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/testing.md): тесты решений, сценарии HTTP и проверка изменений.
- [Хранение данных](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/storage.md): история событий, хранение данных запросов и постоянное хранение.

## Прежде чем полагаться на приложение

По умолчанию в стартовом проекте используется хранилище событий в памяти. Записанные события исчезают после завершения процесса. Постоянное хранение истории событий и данных запросов настраивается отдельно. Если данные должны сохраняться после перезапуска, следуйте приведенному выше руководству по хранению данных.

Правила доступа также определяет ваше приложение. Изучите [руководство по авторизации](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/docs/agent/authorization.md) и протестируйте разрешенные и отклоненные случаи. ИИ-агент помогает реализовать эти правила, но не определяет политику приложения во время его работы.

Опубликованные исходный код и выпуски позволяют изучить доступные возможности. Сами по себе они не подтверждают готовность вашего приложения к промышленной эксплуатации.

Рядом с кодом доступна [лицензия исходного кода фреймворка](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/LICENSE). При выборе зависимостей проверяйте лицензию каждого инструмента.

## Следите за изменениями и получайте помощь

- [История выпусков CLI и фреймворка](https://github.com/neohaskell/NeoHaskell/releases): изменения инструментов для приложений и фреймворка. В [версии 0.17.1](https://github.com/neohaskell/NeoHaskell/releases/tag/neo-v0.17.1), опубликованной 6 ноября 2026 года, добавлена возможность хранить создаваемые документы с указанием владельца.
- [Выпуски навыков для ИИ-агента](https://github.com/neohaskell/skills/releases): изменения отдельной коллекции инструкций для Claude Code и Codex.
- [Задайте вопрос сообществу в Discord](https://discord.com/invite/wDj3UYzec8): расскажите, что вы хотите создать и с какой трудностью столкнулись.
- [Просмотрите известные проблемы](https://github.com/neohaskell/NeoHaskell/issues) или [прочитайте руководство для участников проекта](https://github.com/neohaskell/NeoHaskell/blob/cacc8069070721539ae0aac53286ce9492e906a5/CONTRIBUTING.md): узнайте об известных проблемах и порядке участия в проекте.

## План страницы

Пока разрабатываются новые руководства, на этой странице останутся ссылки на существующие инструкции проекта, основной исходный код, сведения о выпусках и помощь сообщества. При этом выпуски фреймворка, CLI и набора навыков агента будут перечислены отдельно. Компактное сравнение версий может помочь читателям выбрать подходящие инструкции. Ссылки на исходный код останутся рядом с фактами, которые они подтверждают. Для этого справочника не нужен интерактивный виджет.
