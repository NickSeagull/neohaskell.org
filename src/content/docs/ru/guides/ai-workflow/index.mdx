## План страницы

На этой странице запрос на изменение поведения будет преобразован в ограниченную задачу для агента с указанием версии проекта, относящихся к задаче исходников, критериев приёмки и разрешённых изменений. Будут показаны переиспользуемый запрос и точечное различие в коде, а затем результат будет сопоставлен с тестами решений и данными интерфейса. Пример исправления проведёт различие между успешной компиляцией и правильным поведением и направит агента к актуальным инструкциям для закреплённой версии фреймворка.
