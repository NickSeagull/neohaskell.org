## План страницы <a id="page-plan" />

На этой странице конечная точка проверки работоспособности будет сопоставлена с готовностью запросов, а сбойная операция будет прослежена по идентификатору запроса и структурированным журналам. Небольшая диаграмма состояний покажет состояния перестроения, готовности и сбоя запроса вместе с соответствующими HTTP-ответами. Примеры диагностики отличат сбой хранилища от недоступности интеграции, а шаги восстановления будут связаны с подтверждающими данными, поскольку работающий процесс сам по себе не доказывает, что все запросы доступны.
