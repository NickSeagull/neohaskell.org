## План страницы <a id="page-plan" />

На этой странице принятое событие будет связано с типизированным исходящим обработчиком, который выполняет HTTP-вызов и преобразует ответ провайдера в последующую команду. Трассы успеха и сбоя покажут границу между чистым решением и внешним эффектом. В примере будет использован ключ идемпотентности и объяснены отдельные параметры повторных попыток HTTP и диспетчера, без обещаний долговечной доставки или выполнения ровно один раз.
