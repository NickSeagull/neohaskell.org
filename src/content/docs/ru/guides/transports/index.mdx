## План страницы

На этой странице будет объяснено, как предоставить доступ к поведению приложения через HTTP и MCP, включая конфигурацию и контракты, проверенные для документированной версии фреймворка. Команда и запрос будут показаны на примерах пар запросов и ответов, а также эквивалентных вызовов инструментов. Кроме того, будет приведён пример изучения сгенерированного OpenAPI. Небольшая схема границ отделит способы взаимодействия от решений. Статичные примеры охватят успешный результат и отклонение. Интерактивный элемент для отправки запросов будет рассматриваться, только когда появится поддерживаемая изолированная среда выполнения.
