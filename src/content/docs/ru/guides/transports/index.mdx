## План страницы <a id="page-plan" />

На этой странице существующая фича будет опубликована через транспорт Web, после чего будут рассмотрены созданные маршруты и контракт OpenAPI. Запрос команды, отклонённый ввод и ответ запроса свяжут определение приложения с наблюдаемым поведением HTTP. Фильтрация и разбиение на страницы будут описаны в [контракте запроса](../../reference/framework/queries/). Примеры включат регистрацию транспорта и настройку источника запросов из браузера, а перед открытием интерфейса для недоверенных вызывающих будет ссылка на аутентификацию.
