## План страницы

На этой странице будет зарегистрирован транспорт CLI приложения и показан вызов команды с использованием созданной сущности и группы команд. Ввод в терминале будет сопоставлен с успешными и отклонёнными исходами, а также будет объяснено, как режим вывода влияет на написание сценариев. В примере будет обозначена граница доверия локального оператора и проведено различие между этим интерфейсом приложения и CLI neo для разработки, создания и управления проектом.
