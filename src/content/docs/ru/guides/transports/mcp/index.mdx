## План страницы

На этой странице будет зарегистрирован транспорт MCP через stdio для существующей фичи и показаны инициализация, поиск инструментов, вызов команды и чтение ресурса запроса. Краткий протоколный журнал различит команды как инструменты и запросы как ресурсы. В примере будут объяснены владение процессом и доверенный контекст выполнения, чтобы читатели не принимали этот локальный протокол за удалённый HTTP-сервис с аутентификацией.
