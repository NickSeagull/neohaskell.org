## План страницы

На этой странице запрос на документ пройдёт через исходящий обработчик, который создаёт байты, сохраняет принадлежащий пользователю постоянный файл и отправляет команду для записи ссылки на него. Пример повторной попытки будет использовать стабильный ключ создания и сопоставит совпадающее содержимое с конфликтующим запросом. Схема отделит сохранённые документы от ожидающих загрузки файлов и покажет, зачем для долговечного хранения нужны и каталог двоичных данных, и метаданные файла.
