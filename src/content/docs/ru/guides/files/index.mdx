## План страницы <a id="page-plan" />

На этой странице будут настроены метаданные файла и хранилище двоичных данных, загружен документ, его ссылка на файл прикреплена к команде, а затем файл получен от имени владельца. Диаграмма последовательности различит ожидающие загрузки, подтверждённые вложения, истечение срока действия и отсутствующие двоичные данные. Парные запросы покажут разрешённое и запрещённое получение файла, а в обсуждении хранения отдельно останутся содержимое файла, метаданные владельца и события приложения.
