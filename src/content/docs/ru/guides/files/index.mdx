## План страницы

На этой странице будет описан документированный рабочий процесс хранения файлов, включая владение, настройку, загрузку или создание и получение файлов. Один файл будет прослежен на небольшой схеме последовательности, дополненной примерами исходного кода и запросов с ответами. Случаи разрешённого получения, запрета доступа и отсутствия файла будут собраны вместе, чтобы читатель мог проверить ожидаемое поведение. В руководстве будут приведены ссылки на раздел [Контроль доступа](/guides/authorization/) с описанием разрешений и раздел [Сохранение данных после перезапуска](/guides/storage/) с описанием постоянного хранения. Файл не будет считаться записью о событии.
