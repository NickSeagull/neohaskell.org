## План страницы

На этой странице перед получением данных будет применена проверка доступа на уровне запроса, а для отдельных результатов - проверка владения. Один и тот же запрос будет рассмотрен для владельца, другого пользователя с подтверждённой личностью и анонимного вызывающего, включая результат с разбиением на страницы. Краткая таблица решений покажет, где выполняется каждая проверка, чтобы читатель мог защитить возвращаемые данные, не предполагая, что разрешения команд автоматически защищают конечные точки запросов.
