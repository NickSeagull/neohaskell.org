## План страницы

На этой странице будет представлена узкая задача удаления с использованием механизма защищённых значений на основе PostgreSQL. Будут прослежены запрос владельца с необходимым разрешением, удаление одной защищённой ссылки, следующая команда и явная повторная попытка. Схема до и после покажет отличие сохранённой записи события от недоступного защищённого содержимого и объяснит, почему при проверке нужного результата отдельно нужно учитывать запросы и внешние копии.
