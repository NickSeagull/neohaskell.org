## План страницы

На этой странице будут разделены история событий и хранилище данных запросов, а также описаны поддерживаемые варианты постоянного хранения и их настройка. Пример с данными в памяти будет сопоставлен с постоянной конфигурацией. Затем с помощью конкретных команд и ожидаемых результатов будет проверено, какие данные сохраняются после перезапуска. На небольшой схеме хранилище событий будет отделено от состояния для запросов. Примеры сбоев охватят отсутствующую конфигурацию и недоступное хранилище. Также будут приведены ссылки на раздел [История и текущее состояние](/concepts/history-and-state/) с описанием базовой модели и раздел [Материалы](/resources/#language-and-framework) с существующими инструкциями проекта.
