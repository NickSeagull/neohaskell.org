## План страницы

На этой странице постоянное хранилище запросов будет настроено отдельно от истории событий, а затем будут показаны продолжение по контрольной точке и явно проверенное перестроение. Будет объяснено, что текущий хеш запроса формируется из его имени, поэтому одно лишь изменение кода проекции автоматически не делает сохранённый прогресс недействительным. Временная шкала покажет поступление новых событий во время повторного проигрывания и момент, когда запрос становится готовым. Сбой перестроения свяжет диагностические данные с восстановлением, которое требует доступной истории и не отменяет внешние эффекты.
