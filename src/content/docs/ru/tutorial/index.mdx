## План страницы <a id="page-plan" />

На этой странице будет определён магазин, начинающий работу с тремя керамическими кружками и принимающий заказ на одну кружку, только пока она есть в запасе. Читатели предположат, какими будут команда, решение, записанное событие и запрос о запасах для случаев с принятым заказом и пустым складом. Небольшая таблица поведения станет критериями приёмки для агента. Кроме того, будет проведено различие между начальным запасом в примере и инициализацией, которую должно выполнять реализованное приложение.
