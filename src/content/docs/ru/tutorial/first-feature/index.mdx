## План страницы

На этой странице будет продолжена работа с проектом, созданным при настройке: читатели изучат файлы сгенерированной фичи `Counter` и дадут агенту ограниченную задачу добавить состояние магазина и события. В аннотированном дереве файлов будут объяснены `Entity`, `Event`, `Core` и `Feature` без разбора каждого импорта. Читатели явно зададут начальный запас и изучат, как принятый заказ его меняет. Имена фичи магазина будут проверены до публикации исполняемого исходного кода.
