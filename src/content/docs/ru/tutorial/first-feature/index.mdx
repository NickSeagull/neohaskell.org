## План страницы

Эта страница начнётся с рабочего проекта из раздела [Настройка агента](/getting-started/) и спецификации из раздела [Моделирование первой функции](/tutorial/). Здесь будет показано, как поручить агенту эту ограниченную задачу, изучить изменённые файлы и связать одно поведение серверной части с вызываемым интерфейсом. Небольшие фрагменты исходного кода и аннотированное дерево файлов объяснят каждую часть, а при необходимости будет приведена прямая ссылка на раздел [Основы языка](/reference/language/). Затем читатель перейдёт к разделу [Тестирование поведения](/tutorial/test-behavior/).
