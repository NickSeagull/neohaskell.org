## План страницы <a id="page-plan" />

На этой странице команда и запрос магазина будут зарегистрированы через его `Feature`, а затем эта `Feature` будет включена в именованную модель `Event` приложения. Читатели отправят принятый и отклонённый заказы, после чего проверят запрос о запасах через работающий HTTP-сервис. Целевой фрагмент подключения и расположенные рядом пары запросов и ответов свяжут исходный код с наблюдаемым поведением. В учебнике будут использованы проверенные маршруты и данные запросов магазина, а более общий выбор между HTTP и MCP будет описан в руководстве по задачам.
