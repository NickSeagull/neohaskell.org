## План страницы

На этой странице будет реализовано решение для заказа одной кружки с учётом текущей структуры команды, поиска сущности и явного результата принятия или отклонения. Читатели пройдут случай с доступным товаром и случай с пустым складом через одну функцию, а затем свяжут записанные события только с принятыми заказами. Короткие фрагменты кода рядом с двумя исходами объяснят нужный на этом этапе синтаксис. Отсутствующее состояние магазина будет обработано отдельным отказом без добавления транспорта или платёжного поведения.
