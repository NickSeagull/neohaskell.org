## План страницы <a id="page-plan" />

На этой странице распространённые проблемы первого запуска будут сопоставлены с этапом сбоя и минимальным исправлением: отсутствующие инструменты, неверная рабочая папка, занятое имя проекта, неверная конфигурация проекта, недоступные зависимости или отсутствующие инструкции для агента. Для каждого случая будут показаны проверенный способ диагностики и проверка восстановления. Файлы читателя останутся нетронутыми; будет объяснено, как определить версии CLI и фреймворка, а ссылки на более подробные ошибки компилятора и среды выполнения приведут в справочник.
