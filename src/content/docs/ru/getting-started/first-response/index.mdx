## План страницы

На этой странице работающий стартовый проект будет проверен созданием `Counter`, передачей возвращённого идентификатора сущности команде изменения и чтением полученного значения через её запрос. Будут объяснены тело запроса, оболочка ответа и возможная задержка перед тем, как проекция отразит изменение. Отклонённый ввод покажет, как отличить работающую проверку данных от сбоя настройки. Поддерживаемый сценарий с `Counter` даст воспроизводимую проверку перед началом учебника о магазине.
