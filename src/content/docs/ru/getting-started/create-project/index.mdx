## План страницы

На этой странице с помощью Neo CLI будет создано приложение с заданным именем. Будет объяснено, где запускать команду, и показан стартовый проект `Counter`, который появится в новой папке. Будут описаны обычный интерактивный сценарий и воспроизводимая команда для агента, первоначальный коммит Git и закреплённая версия фреймворка, а перед продолжением будет проверен созданный проект. Создание библиотек и полный набор параметров CLI останутся темами справочника.
