## План страницы

На этой странице будут указаны поддерживаемая среда и установка Neo CLI с необходимыми инструментами Nix и Git. Будет проведено различие между установкой CLI и получением компилятора и библиотек, которыми управляет проект, объяснена необязательная среда редактора и показаны проверки установленных инструментов. Инструкции будут привязаны к проверенному выпуску и платформе; там, где выбор двоичного кэша влияет на первую сборку, он будет объяснён. Также будут прямые ссылки на восстановление после проблем настройки.
