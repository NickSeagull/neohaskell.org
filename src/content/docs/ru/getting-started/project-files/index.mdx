## План страницы

На этой странице созданный проект будет сопоставлен с решениями, которые должны принять читатель и его агент. Будут указаны модель `Event` приложения, фича `Counter`, решения команд, события, обновления сущностей, запросы и тесты, а также проведено различие между авторскими файлами и файлами сборки, повторно создаваемыми из `neo.json`. Компактная карта каталогов объяснит назначение каждого расположения. Читатели узнают, где проверять предложенное изменение, не изучая каждый модуль фреймворка.
