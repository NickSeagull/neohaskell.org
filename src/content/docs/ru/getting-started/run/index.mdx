## План страницы

На этой странице приложение `Counter` будет собрано и запущено из корневой папки проекта. Будут указаны локальный HTTP-адрес и процесс, который должен продолжать работать, пока запросы отправляются из другого терминала. Будут разделены первоначальная загрузка зависимостей и запуск приложения, показаны остановка и повторный запуск процесса, а также объяснено, что история событий в памяти по умолчанию исчезает при завершении процесса. Режим наблюдения будет представлен только после первого успешного запуска.
