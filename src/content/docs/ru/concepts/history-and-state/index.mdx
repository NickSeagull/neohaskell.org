## План страницы

На этой странице будет объяснено, почему записанное событие и результат текущего запроса представляют собой разные вещи. Краткая история событий будет сопоставлена с состоянием, выведенным из неё, а затем будет показано, как ещё одна принятая команда меняет ответ, не переписывая предыдущие факты. Объяснение будет сопровождаться размеченным журналом и таблицей состояний. В будущем необязательный элемент управления может показывать последовательные состояния, при этом каждый результат также будет доступен в виде статичного текста. Настройка и перезапуск будут описаны в разделе [Сохранение данных после перезапуска](/guides/storage/).
