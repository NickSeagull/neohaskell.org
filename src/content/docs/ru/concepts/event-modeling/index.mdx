## План страницы <a id="page-plan" />

На этой странице будет объяснено, как модель `Event` объединяет поведение приложения в фичи, главы и срезы и почему у каждого среза своя узкая ответственность. Дерево фичи `Counter` с пояснениями свяжет срез команды и срез запроса с объявленными событиями. Будет проведено различие между организацией истории и обеспечением границы сущности, а затем добавлены ссылки на учебник по реализации и справочник по фреймворку по DSL.
