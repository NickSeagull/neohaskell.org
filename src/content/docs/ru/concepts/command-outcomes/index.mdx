## План страницы <a id="page-plan" />

На этой странице путь резервирования товара будет прослежен от намерения через решение в предметной области до сохранения. Компактная таблица исходов различит принятие с одним или несколькими событиями, принятие без событий, отклонение по правилам предметной области и сбой выполнения. Будет объяснено, почему отклонение команды из-за недостатка товара отличается от ошибки сохранения принятого изменения. Первый пример с магазином останется намеренно небольшим; для процедур будут ссылки на тестирование и устранение неполадок.
