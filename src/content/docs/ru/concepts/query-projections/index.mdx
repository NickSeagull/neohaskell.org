## План страницы

На этой странице состояние запроса будет описано как отдельно поддерживаемый ответ, полученный из выбранных источников событий. Запрос об активности корзины и запасов покажет, что запрос может объединять сущности, не сливая границы их команд. На схеме отдельно будут показаны история событий, обновления проекции и сохранённая позиция контрольной точки. Будет сопоставлено продолжение совместимого процесса с перестроением изменившегося состояния запроса, включая готовность во время повторного проигрывания, без превращения объяснения в инструкцию по восстановлению.
