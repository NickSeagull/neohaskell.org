## План страницы

На этой странице будут разделены создание решения, его интерпретация и выполнение эффектов. На схеме границы рядом с описанием решения будут показаны данные команды, текущее состояние сущности и контекст запроса; генерация UUID и операции с защищёнными значениями будут отнесены к интерпретатору. Будет объяснено, какие входные данные нужно контролировать для повторяемых тестов и почему чистота сама по себе не доказывает правильность бизнес-поведения. Сетевые интеграции приведут к объяснению рабочих процессов и руководству по задачам.
