<p class="docs-lead">Разберитесь в поведении. Создайте одну функцию. Проверьте результат.</p>

В разделах [Основные понятия](/learn/), [Настройка агента](/getting-started/) и [Материалы](/resources/) уже есть инструкции. На остальных страницах ниже представлены планы объяснений, примеров и иллюстраций, которые предстоит подготовить. В разделе «Материалы» собраны ссылки на существующие руководства по синтаксису, CLI, хранению данных, тестированию и авторизации.

Эта страница поможет читателям пройти короткий начальный путь, найти отдельные руководства по задачам, подробные объяснения и удобный для поиска справочник. Карта ссылок покажет, где искать ответы на разные вопросы. Учебный материал проведёт через создание одной функции магазина: от спецификации до проверенного поведения серверной части и вызываемого интерфейса. Для этого не потребуется курс по Haskell. Примеры и иллюстрации дополнят статьи там, где они помогут объяснить конкретную идею.
