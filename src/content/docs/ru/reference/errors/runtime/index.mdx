## План страницы <a id="page-plan" />

На этой странице будут разделены ошибки конфигурации при запуске, неверные настройки привязки, занятые порты прослушивания, отклонение команды, отказ в разрешении и сбой выполнения. Компактная таблица симптомов свяжет каждую категорию с соответствующей конфигурацией или общедоступным типом ответа и проверкой восстановления. Будет объяснено, почему отклонённая команда - допустимый исход бизнес-операции, а не обязательно дефект сервера. Сбои хранилища и провайдеров будут связаны с актуальными инструкциями по соответствующим задачам.
