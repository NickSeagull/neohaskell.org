## План страницы

На этой странице будут собраны распространённые сбои при настройке, сборке, выполнении приложения и работе с агентом, сгруппированные по признакам, которые может заметить читатель. Для каждого случая будут указаны исходное сообщение об ошибке, место возникновения, вероятная причина, простое исправление и проверка восстановления. Небольшие примеры команд или исходного кода до и после исправления будут расположены рядом с объяснением. В зависимости от проблемы страница будет ссылаться на [Neo CLI](/reference/cli/), [Конфигурацию](/reference/configuration/) и [Материалы](/resources/), где можно найти сведения о командах, инструкции проекта или помощь сообщества.
