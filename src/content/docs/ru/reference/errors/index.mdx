## План страницы

На этой странице будут собраны наблюдаемые сбои, например отсутствующая рабочая область, неверный `neo.json`, отсутствующие требования, недействительные зависимости, недоступные инструкции по фреймворку и сбой дочернего процесса. Для каждой записи будут указаны код диагностики и местоположение, минимальное исправление и проверка восстановления. В одном примере с пояснениями будут показаны диапазоны исходного кода и сохранённый вывод дочернего процесса. Сообщения, заданные в исходном коде, останутся отделены от фактически полученных результатов команд. Ссылки на параметры CLI и сообщения о проблемах сообщества помогут, когда для исправления нужны дополнительные данные.
