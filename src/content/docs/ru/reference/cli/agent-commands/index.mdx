## План страницы <a id="page-plan" />

На этой странице будут описаны выбор инструментов в `neo skills setup`, фильтрация навыков, параметры `all-tools`, `force`, `dry-run` и `refresh`, а также `neo guidance retry`. Общие навыки рабочего процесса будут отделены от инструкций по фреймворку, подобранных по исходному коду и синхронизируемых командами `build`, `run` и `test`. Компактная таблица путей и параметров объяснит, что записывается, а что сохраняется. Подробная подготовка агента останется в отдельном руководстве; команда общего назначения для создания фич подразумеваться не будет.
