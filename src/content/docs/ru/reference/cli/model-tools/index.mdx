## План страницы <a id="page-plan" />

На этой странице будут перечислены настройки хоста и порта `neo ide`, фильтры `inspect`, команда `inspect sync`, а также параметры пути и JSON для `validate`. Компактная таблица различит просмотр без изменений, синхронизацию исходного кода с моделью и редактирование в IDE. Будут указаны коды завершения проверки и показана структура результата, который можно будет сохранить в будущем; задачи создания модели будут связаны с другими страницами. Контракты `Command` будут привязаны к описанной версии, а не предполагаться доступными в старых двоичных файлах.
