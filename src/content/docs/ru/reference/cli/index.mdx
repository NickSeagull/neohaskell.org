## План страницы

На этой странице будет описан Neo CLI для указанной версии, включая команды создания проекта, сборки, запуска и тестирования. Для каждой команды будет указано, где её выполнять, какие аргументы обязательны, какие доступны параметры, какой вывод или код завершения ожидается, а также конкретный способ устранения неполадки. Примеры команд для копирования будут сопровождаться проверенными результатами. Варианты для разных платформ будут приведены, только если они различаются. В разделе [Настройка агента](/getting-started/) будет описана последовательность первого запуска целиком, а эта страница поможет быстро найти нужные сведения при дальнейшей работе.
