## План страницы <a id="page-plan" />

На этой странице в компактной таблице команд будут описаны `neo new`, `build`, `run`, `test` и `lock`, включая способ вызова, рабочую папку, входные данные, флаги и определённые исходным кодом результаты. Для общих параметров подробного вывода и CI, режима наблюдения, создания библиотек и проверки, которую `build` выполняет для `lock` будут предусмотрены якоря. Ссылки на инструменты модели и команды настройки агента приведут на отдельные тематические страницы, а установка и полный первый запуск останутся в разделе начала работы.
