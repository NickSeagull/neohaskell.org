## План страницы

На этой странице будут определены поля `Config`, обязательная документация, значения по умолчанию, обязательные значения, имена переменных среды, флаги команд, вложенные записи и скрытие секретов. В одной таблице приоритетов будут указаны командная строка, среда процесса, dotenv, затем значение по умолчанию, с небольшим гипотетическим примером для порта. Будут объяснены загрузка при запуске, фабрики конфигурации, порядок регистрации и отдельные варианты хранилищ. Ссылки на настройки конкретных провайдеров приведут к тематическим руководствам, а настройки сборки `neo.json` останутся на отдельной странице.
