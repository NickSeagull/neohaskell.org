## План страницы

На этой странице будут описаны поля `neo.json`: name, version, neo-version, тип проекта, метаданные, лицензия по умолчанию и зависимости. Они будут отделены от настроек среды выполнения. Небольшой полный манифест и таблица полей объяснят, за что отвечают созданные файлы Cabal и Nix, и приведут ссылки на поддерживаемые форматы зависимостей. В разделе выбора исходного кода локальная подмена фреймворка будет обозначена как расширенная настройка разработки, а совместимость выпусков будет указана явно, без отождествления main с опубликованной версией.
