## План страницы <a id="page-plan" />

На этой странице будут сопоставлены регистрации Web, CLI приложения и MCP. Будет показано, что команда должна разрешать свой транспорт, а модель должна его подключать. Будут указаны правила именования маршрутов, ответы команд, входные данные обработчиков запросов и регистрация схемы; для каждого будет приведена структура запроса и ответа. В отдельном расширенном разделе с якорем будет описан общедоступный интерфейс Transport. CLI приложения будет явно отделён от справочника по командам разработки neo.
