## План страницы

На этой странице будут определены `Query`, `QueryOf`, `EntitiesOf`, `queryId`, `combine` и исходы `Update`, `Delete` и `NoOp`. Небольшой пример связи сущности с запросом покажет различие между идентичностью строки и идентичностью потока событий. В разделах с якорями будут рассмотрены фильтрация `NeoQL`, входные данные и поля ответа для разбиения на страницы, ограничения результатов, проверка доступа до получения данных и видимость отдельных строк. Запрос `Counter` послужит конкретным примером потребителя; вместо повторения полных процедур будут ссылки на задачи HTTP-запросов, хранения и авторизации.
