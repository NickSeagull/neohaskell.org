## План страницы <a id="page-plan" />

На этой странице будут описаны запись команды, `EntityOf`, `getEntityId`, `decide`, `RequestContext`, разрешения транспорта и вспомогательные средства вывода. Авторские функции будут сопоставлены с общедоступными методами `Command`. В компактной таблице исходов будут сравнены `acceptNew`, `acceptExisting`, `acceptAny`, `acceptAfter` и `reject`. Случаи решений для `Counter` покажут принятие и отклонение на конкретных примерах. Для сигнатур с несколькими арендаторами и хуков авторизации будут созданы якоря, а подробная реализация и настройка политик доступа останутся в тематических руководствах.
