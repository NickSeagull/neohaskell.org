## План страницы <a id="page-plan" />

На этой странице `EventModel`, `FeatureAction`, `chapter`, `slice`, `entity`, `command`, `produces`, `query` и `readsFrom` будут сопоставлены с фичей `Counter`, объявленной в исходном коде. Компактная схема связей покажет объявление, проверку и сборку во время выполнения, не смешивая историю событий со строками `query`. Рядом с моделью будут указаны сигнатуры построителя и ограничения порядка. Прямая сборка `Service.Application` будет вынесена в ссылку на расширенный раздел; сначала будет представлена актуальная архитектура стартового проекта.
