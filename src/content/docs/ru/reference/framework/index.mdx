## План страницы

На этой странице сущности, команды, решения, события, запросы и композиция приложения будут сопоставлены с проверенными определениями фреймворка. Для каждого элемента будут указаны его назначение, связанные типы, обязательные поля и минимальный полный пример исходного кода, показывающий его роль. Компактная схема связей покажет, как компоненты связаны между собой, и отделит записи о событиях от результатов запросов. На определения будут ссылки из раздела [Основные понятия](/learn/) с объяснением модели и из [учебного материала по первой функции](/tutorial/first-feature/) с примером их использования в приложении.
