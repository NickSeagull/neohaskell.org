## План страницы <a id="page-plan" />

На этой странице `Nothing` и `Just` будут сопоставлены с `Err` и `Ok`, чтобы показать, когда отсутствие не требует объяснения, а когда нужна типизированная ошибка. Компактные сигнатуры и парные примеры охватят `map`, `andThen`, `withDefault`, `mapError` и преобразования между двумя контейнерами. В примере разбора или поиска ошибка будет сохранена, пока вызывающий намеренно не обработает её. Обработка с эффектами будет связана с `Task`.
