## План страницы

На этой странице будут собраны типы и операции Core, с которыми чаще всего сталкиваются разработчики приложений. Каждая документированная запись будет содержать сигнатуру, входные и выходные данные, минимальный проверенный пример, относящиеся к теме особые случаи и ссылку на исходное определение. Компактные таблицы помогут сравнивать похожие операции, а пары исходных данных и результатов явно покажут их поведение. На странице будет ссылка на раздел [Основы языка](/reference/language/) с описанием синтаксиса. Пока для разделения справочника по отдельным функциям не появится достаточно содержимого, страница будет оставаться общим обзором, без пустых разделов для каждой функции.
