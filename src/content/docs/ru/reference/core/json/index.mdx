## План страницы

На этой странице будут рассмотрены кодирование и декодирование `Json`, экземпляры `FromJSON` и `ToJSON`, ошибочный ввод как `Result` и отдельный контракт `Schema`, описывающий данные API. Небольшая запись будет сопоставлена со своей структурой JSON и одним неверным входным значением. Сериализация будет отделена от проверки и создания описаний API; для вспомогательных средств разбора будут предусмотрены якорные таблицы, а детали тела команды будут связаны со справочником по транспорту.
