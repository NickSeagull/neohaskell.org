## План страницы

На этой странице операции `Array` и `Map` будут сгруппированы по созданию, поиску, преобразованию, объединению и свёртке данных. Таблицы сигнатур явно покажут порядок аргументов в конвейере, а небольшие примеры охватят отсутствующий индекс или ключ, пустые коллекции и простую сумму. Для связанных операций будут созданы якоря на одной странице, указаны канонические определения и крайние случаи, вместо отдельного маршрута для каждой экспортируемой функции.
