## План страницы <a id="page-plan" />

На этой странице будут рассмотрены параметры типов, записи, конструкторы, типы-суммы, псевдонимы типов, ограничения классов, связанные типы, видимое применение типов и синтаксис вывода типов, используемые в коде приложения. В компактной аннотированной записи команды и сумме событий написание в исходном коде будет сопоставлено с возможными значениями. Рукописные определения будут отделены от вспомогательных средств вывода типов; вместо обучения метапрограммированию и пересказа руководства по Haskell будут даны ссылки на контракты фреймворка.
