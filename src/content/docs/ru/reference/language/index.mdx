## План страницы

На этой странице будет показано, как читать повседневный исходный код: модули и импорты, применение функций, сигнатуры, конвейеры, доступ к полям записей, условные выражения, выражения `case` и блоки `do`. Для каждой конструкции будет приведена компактная пара из исходного кода и результата, а для ссылок из учебника - стабильные якоря. Будут объяснены квалифицированные операции и генерируемые языковые расширения. Операторы `let` будут использоваться для локальных привязок внутри блоков `do`, а определения типов будут связаны со следующей страницей.
