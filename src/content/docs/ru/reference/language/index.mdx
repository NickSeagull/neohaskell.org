## План страницы

На этой странице будет приведён минимальный синтаксис, необходимый для прохождения [учебного материала по реализации функции](/tutorial/first-feature/), без необходимости изучать Haskell целиком. В небольших проверенных примерах с результатами рядом будут рассмотрены модули, значения, функции, типы, сопоставление с образцом, конвейеры и блоки do. Локальные привязки будут использовать инструкции let внутри блоков do. В примерах диагностики будет показана распространённая ошибка и её исправление. Постоянные ссылки на разделы позволят другим руководствам указывать на нужные конструкции, а в разделе [Библиотека Core](/reference/core/) будут описаны доступные операции.
